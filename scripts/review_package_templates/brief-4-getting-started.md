## Where it is in the package

- Context: `00-START-HERE.md`, `00-SITE-MAP.md`.

## Lens for this area (plus the shared rubric)
- **First 60 seconds** — a US-FSI M365 admin lands here for the first time. Do they
  understand what this is, whether it's for them, and what to do next?
- **The path to first value** — is there a clear, short, motivating first action
  (e.g., run the assessment, implement one control)? How many steps to "I did something"?
- **Sequencing** — index vs start-here vs quick-start vs checklist: is the order obvious
  and non-redundant, or confusing/overlapping?
- **Reassurance & scoping** — prerequisites, time/effort expectations, "you don't need
  to do all 79 controls at once."
- **Momentum** — does onboarding hand the user off cleanly to controls/playbooks/assessment?
