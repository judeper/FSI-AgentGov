Fix 5 critical/high runtime issues in the Deny Event Correlation solution covering schema mismatches, stale v1.x documentation, and hardcoded zone values.

## Tasks

### Task 1: Fix severity option set mismatch (RTF-06)
- **File:** `maintainers-local/solutions-staging/deny-event-correlation-report/scripts/Invoke-DenyEventCorrelation.ps1` (~L219-224)

### Task 2: Fix zone option set value mismatch (RTF-07)
- **Files:** `maintainers-local/solutions-staging/deny-event-correlation-report/scripts/Invoke-DenyEventCorrelation.ps1` (~L209-213), `maintainers-local/solutions-staging/deny-event-correlation-report/docs/SCHEMA.md` (~L88-95)
- **Change:** Align zone option set values to use simple ints (1=Zone 1, 2=Zone 2, 3=Zone 3) matching ACV/ELM convention; update scripts to use these values
- **Acceptance:** Zone mapping produces correct results when queried from Dataverse

### Task 3: Rewrite deployment guide for v2.0 (RTF-08)
- **File:** `docs/playbooks/advanced-implementations/deny-event-correlation-report/deployment-guide.md`
- **Change:** Replace 3-phase CSV/Blob architecture with v2.0 Dataverse architecture: (1) Dataverse schema deployment via `deploy.py`, (2) Azure Automation setup with DECClient module, (3) Power Automate flow import per FLOW_SETUP.md, (4) Teams/email alerting configuration

### Task 4: Update Power BI playbook to Dataverse (RTF-09)

### Task 5: Fix hardcoded zone in extraction scripts (RTF-10)
- **Files:** `maintainers-local/solutions-staging/deny-event-correlation-report/scripts/Export-CopilotDenyEvents.ps1` (~L340), `maintainers-local/solutions-staging/deny-event-correlation-report/scripts/Export-DlpCopilotEvents.ps1` (~L333)
