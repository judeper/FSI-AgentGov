**Methodology (same as Phase 2 audit):**

1. **Scan regulatory-mappings.md** — Verify every citation in the centralized reference:
   - FINRA Rules (4511, 3110, 3120, 2111, 2210) — verify rule numbers, titles, and requirement descriptions
   - SEC Rules (17a-3, 17a-4, 10b-5, Reg BI, Marketing Rule 206(4)-1, Reg S-ID) — verify section/subsection accuracy
   - SOX (302, 404) — verify section numbers and requirement descriptions
   - GLBA (501-505, 16 CFR Part 314) — verify Safeguards Rule elements and breach notification requirements
   - OCC 2011-12 / Fed SR 11-7 — verify bulletin/guidance document references
   - CFTC Rule 1.31 — verify 17 CFR section, retention periods, WORM requirement removal date
   - CFPB circulars (2022-03, 2023-03) — verify document numbers and ECOA/UDAAP guidance

2. **Scan all 62 controls** for regulatory citations using Grep:
   - Search patterns: `FINRA`, `SEC`, `SOX`, `GLBA`, `OCC`, `SR 11-7`, `CFTC`, `17a-4`, `17a-3`, `Rule 3110`, `Rule 4511`, `ECOA`, `UDAAP`, `CFPB`
   - For each citation found: verify section number, requirement description, and retention period accuracy
   - Check language compliance: search for "ensures compliance", "guarantees", "will prevent", "eliminates risk"
   - Verify every control uses "supports compliance with", "helps meet", "required for", "recommended to", "aids in"

3. **Check for 2025-2026 regulatory updates** via WebSearch:
   - FINRA: Search "FINRA rules amendments 2025 2026" — identify any rule changes
   - SEC: Search "SEC 17a-4 amendments 2025 2026", "SEC recordkeeping rules 2025 2026"
   - SOX: Search "SOX amendments 2025 2026" — verify sections 302/404 unchanged
   - GLBA: Search "GLBA Safeguards Rule amendments 2025 2026", "FTC Safeguards Rule 2025"
   - OCC: Search "OCC 2011-12 update 2025 2026", "model risk management guidance 2025"
   - Fed: Search "SR 11-7 update 2025 2026", "Federal Reserve model risk 2025"
   - CFTC: Search "CFTC Rule 1.31 amendments 2025 2026"

4. **Identify specific discrepancies to document:**
   - Control coverage summary uses "61" instead of "62" — this is a known count discrepancy to flag
   - SEC 17a-3/4 overview says "6 years" generically but retention varies by record type (3yr vs 6yr)
   - "Agent Communications" section under SEC 17a-3/4 says "6 years" — should distinguish per Retention Period Matrix
   - FINRA AI Supervision section references FINRA 2026 Report but may need content verification
   - Any regulations cited without effective dates for amendments
   - Any controls duplicating regulation details that should reference regulatory-mappings.md instead
