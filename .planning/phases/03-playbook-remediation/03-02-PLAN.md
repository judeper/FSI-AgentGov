```markdown
## SSPM Configuration Verification

    The following test cases validate configuration points flagged by security posture assessments. Each test maps to a specific setting in the [Configuration Hardening Baseline](../../playbooks/advanced-implementations/configuration-hardening-baseline/index.md).

| Test ID | Configuration Point | Expected Result | Portal Path | Evidence |
|---------|-------------------|-----------------|-------------|----------|
| SSPM-X.X-01 | {setting name} | {expected value} | {admin portal > section > setting} | Screenshot |

### Test Procedures

**SSPM-X.X-01: {Setting Name}**

1. Navigate to {portal path}
2. Verify {setting} is set to {expected value}
3. **Pass criteria:** {condition}
4. **Evidence:** Screenshot showing {what to capture}
```
