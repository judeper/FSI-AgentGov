# Plan 03-01: Flow Template Core — Enumeration, Policy Lookup, Evaluation

## Objective

Create `src/detect-inactivity-timeout-noncompliance.json` — the Cloud Flow template with environment enumeration via BAP Admin API, `fsi_environmentpolicy` lookup, per-environment privacy settings retrieval, compliance evaluation logic, and immutable Dataverse compliance record writes. This plan creates the complete flow structure including trigger, connection references, variables, and the Scope_Try with all evaluation logic. Plan 03-02 will add the post-loop notification guard, Scope_Catch, and flow metadata.

## Must-Haves Addressed

| # | Must-Have | How Addressed |
|---|----------|---------------|
| 1 | Environment enumeration + policy lookup | `List_Environments` via BAP API + `Load_Environment_Policies` from Dataverse + `Resolve_Policy` filter array |
| 2 | Per-env compliance evaluation | `Check_Policy_Exists` → `Get_Privacy_Settings` → `Evaluate_Compliance` with all 5 outcomes |
| 3 | Configurable concurrency (default 5) | `runtimeConfiguration.concurrency.repetitions: 5` on `Apply_to_Each_Environment` |
| 5 | Service principal auth + daily schedule | MSI audience `https://api.bap.microsoft.com`, Recurrence 06:00 UTC |

## Tasks

### Task 1: Create flow template with envelope, connection references, trigger, and variables

**File:** `src/detect-inactivity-timeout-noncompliance.json` (CREATE)

Create the JSON flow template with:

1. **Connection references** (2 connectors):
   - `shared_commondataserviceforapps` → `fsi_cr_dataverse_inactivitytimeout`
   - `shared_office365` → `fsi_cr_office365_inactivitytimeout`

2. **Definition parameters:**
   - `$connections` (Object, default `{}`)
   - `$authentication` (SecureObject, default `{}`)

3. **Trigger:** `Recurrence_Daily_0600_UTC` — daily at 06:00 UTC (reuse pattern from UASD/CAA)

4. **Variable initialization chain** (sequential `runAfter`):
   - `Initialize_DataverseUrl` (string, `""`) — env var `fsi_ITE_DataverseUrl`
   - `Initialize_NotificationRecipients` (string, `""`) — env var `fsi_ITE_NotificationRecipients`
   - `Initialize_ScanRunId` (string, `@{guid()}`) — unique scan correlation ID
   - `Initialize_ConcurrencyLimit` (integer, `5`) — env var `fsi_ITE_ConcurrencyLimit` (informational; actual limit is in runtimeConfiguration)

**Patterns reused:** UASD/CAA trigger, variable chain, connection reference naming

**Acceptance criteria:**
- [ ] JSON envelope matches established schema (connectionReferences, definition, parameters)
- [ ] Connection references use `fsi_cr_{connector}_inactivitytimeout` naming
- [ ] Trigger fires daily at 06:00 UTC with correct recurrence specification
- [ ] Variables chain sequentially via `runAfter`
- [ ] All variable descriptions reference their environment variable name
- [ ] `Initialize_NotificationRecipients` references env var `fsi_ITE_NotificationRecipients` (aligned with Phase 2)

### Task 2: Implement Scope_Try with policy load and environment enumeration

Add to the `actions` object (inside the definition), after the last variable initialization:

1. **`Scope_Try`** (type: Scope, `runAfter: { Initialize_ConcurrencyLimit: ["Succeeded"] }`)

2. **Inside Scope_Try:**

   a. **`Load_Environment_Policies`** — Dataverse ListRecords:
      - `entityName`: `fsi_environmentpolicies`
      - `$select`: `fsi_environmentid,fsi_environmentdisplayname,fsi_zone,fsi_requiredmaxduration`
      - `runAfter`: `{}`

   b. **`Compose_Policy_Array`** — Extract value array:
      - `inputs`: `@body('Load_Environment_Policies')?['value']`
      - `runAfter`: `Load_Environment_Policies`

   c. **`List_Environments`** — HTTP GET to BAP Admin API:
      - URI: `https://api.bap.microsoft.com/providers/Microsoft.BusinessAppPlatform/scopes/admin/environments?api-version=2016-11-01`
      - Auth: `ManagedServiceIdentity`, audience `https://api.bap.microsoft.com`
      - `runAfter`: `Compose_Policy_Array`
      - **Design decision:** Uses HTTP action (consistent with UASD v16 `List_Environments`) rather than the Power Platform for Admins V2 connector. Both the environment listing and the privacy settings endpoint require HTTP calls with MSI auth — using HTTP for both is consistent. The PP for Admins V2 connector could be used for enumeration but adds an unnecessary connector dependency when HTTP+MSI achieves the same result. Connection reference `fsi_cr_powerplatformforadmins_inactivitytimeout` from Phase 2 may be omitted if this approach is confirmed.

   d. **`Apply_to_Each_Environment`** — Foreach:
      - `foreach`: `@body('List_Environments')?['value']`
      - `runtimeConfiguration.concurrency.repetitions`: `5`
      - `runAfter`: `List_Environments`

**Acceptance criteria:**
- [ ] Scope_Try wraps all main logic
- [ ] Policy load retrieves all active policies with correct `$select`
- [ ] Environment enumeration uses BAP Admin API with MSI auth
- [ ] forEach has `concurrency.repetitions: 5` in runtimeConfiguration

### Task 3: Implement per-environment evaluation logic inside forEach

Inside `Apply_to_Each_Environment.actions`:

1. **`Set_EnvironmentName`** — Compose: `@items('Apply_to_Each_Environment')?['name']`
   - Description: "Extract canonical EnvironmentName (Power Platform Environment Name) from BAP API response."

2. **`Set_EnvironmentDisplayName`** — Compose: `@items('Apply_to_Each_Environment')?['properties']?['displayName']`

3. **`Set_EnvironmentType`** — Compose: `@items('Apply_to_Each_Environment')?['properties']?['environmentSku']`

4. **`Resolve_Policy`** — Query (Filter Array):
   - `from`: `@outputs('Compose_Policy_Array')`
   - `where`: `@equals(item()?['fsi_environmentid'], outputs('Set_EnvironmentName'))`

5. **`Check_Policy_Exists`** — If condition:
   - Expression: `@greater(length(body('Resolve_Policy')), 0)`
   - **False branch (no policy):**
     - `Create_Unknown_NoPolicyRecord` — Dataverse CreateRecord in `fsi_inactivitytimeoutcompliances`:
       - `fsi_environmentid`: EnvironmentName
       - `fsi_environmentname`: DisplayName
       - `fsi_environmenttype`: EnvironmentType
       - `fsi_zone`: null (no policy, zone unknown)
       - `fsi_inactivitytimeoutenabled`: null
       - `fsi_timeoutduration`: null
       - `fsi_requiredmaxduration`: null
       - `fsi_compliancestatus`: 2 (Unknown)
       - `fsi_lastscandate`: `@utcNow()`
       - `fsi_scanrunid`: `@variables('ScanRunId')`
       - `fsi_notes`: "No explicit policy found for environment"
     - `Create_MissingPolicyErrorLog` — Dataverse CreateRecord in `fsi_inactivitytimeouterrorlogs`:
       - `fsi_environmentid`: EnvironmentName
       - `fsi_errortype`: "MissingPolicy"
       - `fsi_errorraw`: "No fsi_environmentpolicy row exists for EnvironmentName: {name}"
       - `fsi_timestamp`: `@utcNow()`
   - **True branch (policy exists):** proceed to Task 4 actions

**Acceptance criteria:**
- [ ] EnvironmentName extracted from `name` property (canonical ID, not display name)
- [ ] Policy lookup uses Filter Array (Query) on the pre-loaded policy array
- [ ] Missing policy results in Unknown compliance row + MissingPolicy error log
- [ ] Compliance records include `fsi_scanrunid` for post-loop aggregation

### Task 4: Implement BAP API privacy settings call and compliance determination

Inside `Check_Policy_Exists` **true branch**:

1. **`Set_RequiredMaxDuration`** — Compose: `@first(body('Resolve_Policy'))?['fsi_requiredmaxduration']`

2. **`Set_Zone`** — Compose: `@first(body('Resolve_Policy'))?['fsi_zone']`

3. **`Scope_BAP_API_Try`** — Scope (inner try for per-environment error isolation):

   a. **`Get_Privacy_Settings`** — HTTP GET:
      - URI: `https://api.bap.microsoft.com/providers/Microsoft.BusinessAppPlatform/scopes/admin/environments/@{outputs('Set_EnvironmentName')}/settings/privacy?api-version=2021-04-01`
      - Auth: `ManagedServiceIdentity`, audience `https://api.bap.microsoft.com`

   b. **`Parse_Privacy_Response`** — ParseJson with schema for `properties.inactivityTimeoutEnabled` (boolean) and `properties.inactivityTimeoutDuration` (string, ISO 8601)

   c. **`Set_TimeoutEnabled`** — Compose: `@body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutEnabled']`

   d. **`Parse_Duration_Minutes`** — Compose:
      ```
      @if(
        equals(outputs('Set_TimeoutEnabled'), false),
        0,
        if(
          and(
            contains(coalesce(body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutDuration'], 'PT0M'), 'H'),
            contains(coalesce(body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutDuration'], 'PT0M'), 'M')
          ),
          add(
            mul(int(first(split(replace(coalesce(body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutDuration'], 'PT0M'), 'PT', ''), 'H'))), 60),
            int(replace(last(split(coalesce(body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutDuration'], 'PT0M'), 'H')), 'M', ''))
          ),
          if(
            contains(coalesce(body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutDuration'], 'PT0M'), 'H'),
            mul(int(first(split(replace(coalesce(body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutDuration'], 'PT0M'), 'PT', ''), 'H'))), 60),
            int(replace(replace(coalesce(body('Parse_Privacy_Response')?['properties']?['inactivityTimeoutDuration'], 'PT0M'), 'PT', ''), 'M', ''))
          )
        )
      )
      ```
      Handles three ISO 8601 formats: `PTnM` (minutes only), `PTnH` (hours only), and `PTnHnM` (hours + minutes).

   e. **`Evaluate_Compliance`** — Compose:
      ```
      @if(
        equals(outputs('Set_TimeoutEnabled'), false),
        'Non-Compliant',
        if(
          greater(outputs('Parse_Duration_Minutes'), outputs('Set_RequiredMaxDuration')),
          'Non-Compliant',
          'Compliant'
        )
      )
      ```

   f. **`Set_Compliance_Notes`** — Compose:
      ```
      @if(
        equals(outputs('Set_TimeoutEnabled'), false),
        'Inactivity timeout is disabled',
        if(
          greater(outputs('Parse_Duration_Minutes'), outputs('Set_RequiredMaxDuration')),
          concat('Duration ', outputs('Parse_Duration_Minutes'), 'm exceeds maximum ', outputs('Set_RequiredMaxDuration'), 'm'),
          concat('Compliant: ', outputs('Parse_Duration_Minutes'), 'm within ', outputs('Set_RequiredMaxDuration'), 'm maximum')
        )
      )
      ```

   g. **`Create_Compliance_Record`** — Dataverse CreateRecord in `fsi_inactivitytimeoutcompliances`:
      - `fsi_environmentid`: EnvironmentName
      - `fsi_environmentname`: DisplayName
      - `fsi_environmenttype`: EnvironmentType
      - `fsi_zone`: `@outputs('Set_Zone')` (persisted from policy lookup for post-loop notification)
      - `fsi_inactivitytimeoutenabled`: `@outputs('Set_TimeoutEnabled')`
      - `fsi_timeoutduration`: `@outputs('Parse_Duration_Minutes')`
      - `fsi_requiredmaxduration`: `@outputs('Set_RequiredMaxDuration')`
      - `fsi_compliancestatus`: Map from string to Choice value (0=Compliant, 1=Non-Compliant)
      - `fsi_lastscandate`: `@utcNow()`
      - `fsi_scanrunid`: `@variables('ScanRunId')`
      - `fsi_notes`: `@outputs('Set_Compliance_Notes')`

4. **`Scope_BAP_API_Catch`** — Scope (`runAfter: { Scope_BAP_API_Try: ["Failed", "TimedOut"] }`):

   a. **`Determine_Error_Type`** — Compose:
      ```
      @coalesce(
        if(equals(outputs('Get_Privacy_Settings')?['statusCode'], 401), 'Unauthorized',
        if(equals(outputs('Get_Privacy_Settings')?['statusCode'], 403), 'Forbidden',
        if(equals(outputs('Get_Privacy_Settings')?['statusCode'], 404), 'NotFound',
        if(equals(outputs('Get_Privacy_Settings')?['statusCode'], 429), 'Throttled', null)))),
        'ParseError'
      )
      ```

   b. **`Create_API_Error_Log`** — Dataverse CreateRecord in `fsi_inactivitytimeouterrorlogs`:
      - `fsi_environmentid`: EnvironmentName
      - `fsi_errortype`: `@outputs('Determine_Error_Type')`
      - `fsi_errorraw`: `@coalesce(body('Get_Privacy_Settings'), string(result('Scope_BAP_API_Try')))`
      - `fsi_timestamp`: `@utcNow()`

   c. **`Create_Unknown_APIErrorRecord`** — Dataverse CreateRecord in `fsi_inactivitytimeoutcompliances`:
      - Same fields as Create_Unknown_NoPolicyRecord but with note: "BAP API call failed: {errortype}"
      - `fsi_zone`: `@outputs('Set_Zone')` (persisted from policy lookup)
      - `fsi_compliancestatus`: 2 (Unknown)

**Acceptance criteria:**
- [ ] BAP API privacy endpoint uses correct URL with EnvironmentName interpolation
- [ ] ISO 8601 duration parsed to minutes (handles PTnM and PTnH formats)
- [ ] Compliance determination follows exact spec logic: disabled→Non-Compliant, duration>max→Non-Compliant, else→Compliant
- [ ] Each compliance record is immutable (CreateRecord, never update)
- [ ] API failures result in Unknown compliance + error log entry
- [ ] Error types correctly mapped from HTTP status codes
- [ ] Per-environment errors don't abort the scan (isolated in Scope_BAP_API_Try/Catch)

## Notes

- The flow template is a structural JSON document. It will be imported into a Power Platform solution where the Dataverse tables exist. No compile-time dependency on Phase 2.
- Concurrency is set to 5 in `runtimeConfiguration`. The `Initialize_ConcurrencyLimit` variable is informational — changing the actual concurrency requires editing the flow definition in the Power Automate designer.
- The compliance status Choice values (0=Compliant, 1=Non-Compliant, 2=Unknown) must align with the Phase 2 schema definition.
- Environment enumeration uses HTTP GET to BAP Admin API (consistent with UASD v16) rather than the Power Platform for Admins V2 connector. Both environment listing and privacy settings require HTTP+MSI; using HTTP for both is consistent and avoids an unnecessary connector dependency.
