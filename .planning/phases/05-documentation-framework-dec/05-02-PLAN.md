### Task 2: Create EVIDENCE_EXPORT.md

**File:** `maintainers-local/solutions-staging/deny-event-correlation-report/docs/EVIDENCE_EXPORT.md`
**Action:** CREATE

**Content outline:**
1. **Overview** — Purpose of evidence export for regulatory examinations
2. **Export-DenyEventEvidence.ps1 Usage**
   - Parameters: `-StartDate`, `-EndDate`, `-OutputPath`, `-IncludeTrends`, `-Zone`
   - Output: timestamped directory with deny events CSV, correlation summary CSV, trend analysis JSON
3. **SHA-256 Integrity Hashing**
   - Each exported file gets a companion `.sha256` file
   - Manifest file lists all hashes for package integrity verification
4. **Regulatory Alignment Mapping**
   - Output includes `regulatory-alignment.json` mapping deny events to FINRA/SEC requirements
   - Maps deny event types to applicable regulation sections
5. **Test-EvidenceIntegrity.ps1**
   - Verifies SHA-256 hashes against manifest
   - Usage: `Test-EvidenceIntegrity -PackagePath <path>`
   - Returns pass/fail status for each file
6. **Unified Evidence Integration**
   - Registration with `Export-UnifiedComplianceEvidence.ps1` via IntegrationConfig
   - DEC evidence feeds into unified compliance packages
7. **Retention and Archival**
   - Zone-based export recommendations (Zone 1: quarterly, Zone 2: monthly, Zone 3: weekly)
   - Long-term storage guidance for SEC 17a-4 compliance

### Task 3: Create TROUBLESHOOTING.md

**File:** `maintainers-local/solutions-staging/deny-event-correlation-report/docs/TROUBLESHOOTING.md`
**Action:** CREATE

**Content outline:**
1. **Authentication Issues**
   - Certificate not found in Key Vault
   - Insufficient Graph API permissions
   - Token expiration during long extraction runs
2. **Extraction Failures**
   - No Purview Audit data returned (licensing, retention)
   - Application Insights query timeout
   - DLP events missing for agent activities
3. **Dataverse Issues**
   - Connection failures (environment variables misconfigured)
   - Schema deployment errors (missing tables/columns)
   - Ingestion throttling (batch size adjustment)
4. **Power Automate Flow Issues**
   - Azure Automation job failures
   - Connector authentication expired
   - Flow run timeout (extended extraction windows)
5. **Alerting Issues**
   - Teams adaptive card not delivered
   - False positive volume anomalies (baseline adjustment)
   - Missing email notifications (mail flow rules)
6. **Evidence Export Issues**
   - SHA-256 hash mismatch (file modified post-export)
   - Large export file sizes (date range filtering)
   - Unified evidence integration errors
7. **Common Error Messages Table**
   - Error message → Cause → Resolution mapping

**Acceptance criteria:**
- [ ] 6 troubleshooting categories covered
- [ ] Each issue has cause and resolution
- [ ] Common error messages table included
- [ ] References to relevant configuration files and scripts
