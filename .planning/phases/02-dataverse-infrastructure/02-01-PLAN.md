**Option Sets:**
Only define SSC-specific option sets. The shared ACV option sets (fsi_acv_zone, fsi_acv_severity) are NOT redefined here — they are checked for existence and reused.

SSC-specific option set:

OPTIONSETS = {

        "Name": "fsi_ssc_validationtype",

        "Description": {"LocalizedLabels": [{"Label": "Type of session security validation", "LanguageCode": 1033}]},
        "OptionSetType": "Picklist",
        "IsGlobal": True,
        "Options": [
            {"Value": 1, "Label": {"LocalizedLabels": [{"Label": "SessionControls", "LanguageCode": 1033}]}},

Also define fsi_acv_zone and fsi_acv_severity in a SHARED_OPTIONSETS dict (same definitions as ACV) — these are created ONLY if they don't already exist. The create_optionsets() function must handle both:
1. Check shared option sets (fsi_acv_zone, fsi_acv_severity) — create only if missing
2. Check SSC option sets (fsi_ssc_validationtype) — create only if missing

**Table 1: fsi_SessionBaseline**
- OwnershipType: UserOwned (operators manage baselines)
- IsAuditEnabled: True
- PrimaryNameAttribute: fsi_name
- Primary name attribute: fsi_Name (String, max 200, required, "Baseline ID like Zone1-2026-02-07")
- Additional columns:
  - fsi_Zone (Picklist, required, GlobalOptionSet@odata.bind fsi_acv_zone)
  - fsi_SignInFrequencyMinutes (Integer, required, min 0, max 999999, "Expected sign-in frequency in minutes")
  - fsi_AuthStrength (String, optional, max 200, "Expected auth strength: standard, passwordless, phishing-resistant")
  - fsi_RequireCompliantDevice (Boolean, optional, default false)
  - fsi_PIMMaxActivationHours (Integer, optional, min 0, max 999999, "Max PIM activation duration in hours")
  - fsi_PIMRequireApproval (Boolean, optional, default false)
  - fsi_PIMRequireAuthContext (Boolean, optional, default false)
  - fsi_IsActive (Boolean, required, default true, "Whether this baseline is the current active baseline for the zone")
  - fsi_CapturedOn (DateTime, required, DateAndTime, "When baseline was captured")
  - fsi_RawJson (Memo, optional, max 100000, "Full JSON snapshot of CA session settings at capture time")

**Table 2: fsi_ValidationHistory (IMMUTABLE)**
- OwnershipType: OrganizationOwned — CRITICAL for immutability
- IsAuditEnabled: True
- PrimaryNameAttribute: fsi_name
- Primary name attribute: fsi_Name (String, max 200, required, "Validation ID like Zone3-2026-02-07T14:30:00Z")
- Additional columns:
  - fsi_RunId (String, required, max 36, "GUID correlating all records in one execution run")
  - fsi_Zone (Picklist, required, GlobalOptionSet@odata.bind fsi_acv_zone)
  - fsi_Severity (Picklist, required, GlobalOptionSet@odata.bind fsi_acv_severity)
  - fsi_ValidationType (Picklist, required, GlobalOptionSet@odata.bind fsi_ssc_validationtype)
  - fsi_RawValue (String, optional, max 4000, "Actual config values checked")
  - fsi_Reason (String, optional, max 4000, "Human-readable explanation")
  - fsi_RemediationHint (String, optional, max 2000, "Suggested fix for alerting")
  - fsi_Timestamp (DateTime, required, DateAndTime, "When validation ran")
  - fsi_CheckCount (Integer, optional, min 0, max 999999, "Number of individual checks")
  - fsi_BaselineId (String, optional, max 200, "Reference to baseline used for comparison")

**Table 3: fsi_DriftViolation**
- OwnershipType: UserOwned (operators need to manage/acknowledge violations)
- IsAuditEnabled: True
- PrimaryNameAttribute: fsi_name
- Primary name attribute: fsi_Name (String, max 200, required, "Violation ID like Zone2-DRIFT-2026-02-07T14:30:00Z")
- Additional columns:
  - fsi_Zone (Picklist, required, GlobalOptionSet@odata.bind fsi_acv_zone)
  - fsi_Severity (Picklist, required, GlobalOptionSet@odata.bind fsi_acv_severity)
  - fsi_DriftType (String, required, max 200, "SignInFrequencyWeakened, AuthStrengthDowngraded, PolicyDisabled, ExclusionAdded")
  - fsi_ExpectedValue (String, required, max 2000, "Expected configuration per baseline")
  - fsi_ActualValue (String, required, max 2000, "Actual configuration found")
  - fsi_PolicyId (String, optional, max 200, "CA policy ID that drifted")
  - fsi_PolicyName (String, optional, max 500, "CA policy display name")
  - fsi_DetectedOn (DateTime, required, DateAndTime, "When drift was detected")
  - fsi_Acknowledged (Boolean, optional, default false, "Whether operator has reviewed")
  - fsi_AcknowledgedBy (String, optional, max 200, "UPN of acknowledging operator")
  - fsi_AcknowledgedOn (DateTime, optional, DateAndTime, "When acknowledged")
  - fsi_Notes (Memo, optional, max 2000, "Operator notes on violation")
