Create a new private helper script that queries Dataverse Web API for SSC environment variable values.

**Function: Get-DataverseThreshold**

Parameters:
- `[string]$DataverseUrl` (Mandatory) — Dataverse environment URL (e.g., "https://org.crm.dynamics.com")
- `[string]$Zone` (Mandatory) — Zone identifier: Zone1, Zone2, or Zone3
- `[string]$AccessToken` (Optional) — Pre-acquired bearer token. If not provided, attempts to get token from current Graph context via `Get-MgContext`

**Behavior:**
1. Build authorization headers using either the provided $AccessToken or by extracting the token from the current Microsoft Graph session. Use `(Get-MgContext).AccessToken` if available, otherwise fall back to acquiring a Dataverse-scoped token. NOTE: Since the Graph token may not have Dataverse scope, the script should use `Invoke-RestMethod` with the provided access token. If no token is available, throw a descriptive error.

2. Query environment variable values for the specified zone:
   ```
   GET $DataverseUrl/api/data/v9.2/environmentvariabledefinitions?$filter=startswith(schemaname,'fsi_SSC_$Zone')&$select=schemaname&$expand=environmentvariablevalues($select=value)
   ```
   This single query retrieves all env vars for the zone (e.g., fsi_SSC_Zone3SignInFrequencyMinutes and fsi_SSC_Zone3AuthStrength).

3. Parse results into a hashtable:
   ```powershell
   @{
       SignInFrequencyMinutes = [int]$zone3FreqValue   # e.g., 60
       AuthStrength = $zone3AuthValue                   # e.g., "phishing-resistant"
       Source = "Dataverse"                              # indicates values came from Dataverse
   }
   ```

4. If the query returns no results (env vars not deployed), return `$null` and write a verbose warning.

5. If the API call fails (network error, auth error), catch the exception and return `$null` with a Write-Warning explaining the failure. Do NOT throw — the caller handles fallback.

**Error handling strategy:** This helper is designed to fail gracefully. The caller (Test-SessionCompliance.ps1) always has local JSON baselines as fallback. The helper should never cause the validation script to abort.

**Script structure:** Follow the same pattern as other private helpers (Compare-SessionBaseline.ps1, Test-BreakGlassExclusion.ps1):
- Script-level param block for direct execution
- Internal function definition with CmdletBinding
- Export-ModuleMember at bottom for dot-source usage
- Full comment-based help with .SYNOPSIS, .DESCRIPTION, .PARAMETER, .EXAMPLE, .OUTPUTS, .NOTES

**Notes section should include:**
- Version: 1.0.0
- Requires: Dataverse environment with SSC environment variables deployed (Plan 02-02)
- The Dataverse Web API scope is different from Graph API scope; callers must provide an appropriate token
- Environment variables queried: fsi_SSC_Zone{1,2,3}SignInFrequencyMinutes, fsi_SSC_Zone{1,2,3}AuthStrength

3. **Add Dataverse threshold override** after the baseline is loaded from JSON (after line ~218, after `$baseline = Get-Content ...`) but before the results object is initialized. Insert a new section:
   ```powershell
   # Optionally override baseline thresholds from Dataverse environment variables
   if ($DataverseUrl) {
       Write-Host "Querying Dataverse for zone thresholds..." -ForegroundColor Cyan

       $dvParams = @{
           DataverseUrl = $DataverseUrl
           Zone = $Zone
       }
       if ($DataverseToken) {
           $dvParams.AccessToken = $DataverseToken
       }

       $dvThresholds = Get-DataverseThreshold @dvParams

       if ($dvThresholds) {
           Write-Host "Dataverse thresholds loaded (source: $($dvThresholds.Source)):" -ForegroundColor Green
           if ($dvThresholds.SignInFrequencyMinutes) {
               Write-Host "  SignInFrequencyMinutes: $($baseline.signInFrequencyMinutes) -> $($dvThresholds.SignInFrequencyMinutes)" -ForegroundColor Cyan
               $baseline.signInFrequencyMinutes = $dvThresholds.SignInFrequencyMinutes
           }
           if ($dvThresholds.AuthStrength) {
               Write-Host "  AuthStrength: $($baseline.authenticationStrength) -> $($dvThresholds.AuthStrength)" -ForegroundColor Cyan
               $baseline.authenticationStrength = $dvThresholds.AuthStrength
           }
       }
       else {
           Write-Warning "Dataverse thresholds unavailable. Falling back to local baseline: $baselineFile"
       }
   }
   ```
