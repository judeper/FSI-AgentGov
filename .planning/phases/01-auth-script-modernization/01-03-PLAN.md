# Plan 01-03: Script Hardening (AUTH-03)

## Goal

Modernize all 4 DEC extraction scripts to match v4-v8 security standards: add `#Requires` statements, replace all hardcoded credential patterns with Azure Key Vault retrieval, add structured error handling, import and use `DECClient.psm1` for all connections, and add parameter validation. Eliminate the `ConvertTo-SecureString -AsPlainText -Force` anti-pattern from all scripts.

## Context

- **Depends on:** Plan 01-01 (Entra ID auth pattern), Plan 01-02 (DECClient.psm1 module)
- **Scripts to update:** `Export-CopilotDenyEvents.ps1`, `Export-DlpCopilotEvents.ps1`, `Export-RaiTelemetry.ps1`, `Invoke-DailyDenyReport.ps1`
- **Anti-patterns to remove:** `ConvertTo-SecureString ... -AsPlainText -Force`, hardcoded `$ApiKey`, interactive `Get-Credential` prompts
- **Pattern source:** v4-v8 scripts with `#Requires`, Key Vault, structured error handling
- **Note:** `Export-RaiTelemetry.ps1` already has `#Requires` and Key Vault from Plan 01-01; this plan adds remaining standardization and refactors it to use DECClient.psm1

## Tasks

### Task 1: Add #Requires Statements to All Scripts

**What:** Declare PowerShell version and module dependencies at the top of every script.

**Acceptance criteria:**
- [ ] `Export-CopilotDenyEvents.ps1`: `#Requires -Version 7.0` + `#Requires -Modules @{ ModuleName="ExchangeOnlineManagement"; ModuleVersion="3.0.0" }`
- [ ] `Export-DlpCopilotEvents.ps1`: `#Requires -Version 7.0` + `#Requires -Modules @{ ModuleName="ExchangeOnlineManagement"; ModuleVersion="3.0.0" }`
- [ ] `Export-RaiTelemetry.ps1`: Verify `#Requires` from Plan 01-01 are correct (already added)
- [ ] `Invoke-DailyDenyReport.ps1`: `#Requires -Version 7.0` + `#Requires -Modules @{ ModuleName="Az.Accounts"; ModuleVersion="3.0.0" }, @{ ModuleName="Az.KeyVault"; ModuleVersion="5.0.0" }, @{ ModuleName="ExchangeOnlineManagement"; ModuleVersion="3.0.0" }`
- [ ] All `#Requires` use version-pinned `@{ ModuleName=...; ModuleVersion=... }` syntax consistently
- [ ] All `#Requires` appear before any other code (after comment header)

### Task 2: Refactor Credential Handling to Key Vault

**What:** Replace all hardcoded credential patterns with Azure Key Vault retrieval.

**Acceptance criteria:**
- [ ] Remove all `ConvertTo-SecureString ... -AsPlainText -Force` patterns
- [ ] Remove all inline `$password = "..."` or `$apiKey = "..."` assignments
- [ ] Remove any interactive `Get-Credential` calls
- [ ] `Export-CopilotDenyEvents.ps1`: Add `-KeyVaultName` parameter; retrieve EXO cert/secret from Key Vault
- [ ] `Export-DlpCopilotEvents.ps1`: Add `-KeyVaultName` parameter; retrieve EXO cert/secret from Key Vault
- [ ] `Invoke-DailyDenyReport.ps1`: Centralize all Key Vault retrievals; pass credentials to sub-scripts via DECClient
- [ ] Document required Key Vault secrets in script help comments

### Task 3: Refactor Scripts to Use DECClient.psm1

**What:** Replace direct connection logic with DECClient.psm1 module calls.

**Acceptance criteria:**
- [ ] All 4 scripts import DECClient: `Import-Module "$PSScriptRoot/private/DECClient.psm1" -Force`
- [ ] `Export-CopilotDenyEvents.ps1`: Use `Connect-DECExchangeOnline` instead of inline `Connect-ExchangeOnline`
- [ ] `Export-DlpCopilotEvents.ps1`: Use `Connect-DECExchangeOnline` instead of inline `Connect-ExchangeOnline`
- [ ] `Export-RaiTelemetry.ps1`: Use `Connect-DECAppInsights` and `Invoke-DECAppInsightsQuery` instead of inline REST calls
- [ ] `Invoke-DailyDenyReport.ps1`: Use `Connect-DECServices -Services @('ExchangeOnline','AppInsights')` for master connection

### Task 4: Add Structured Error Handling

**What:** Implement consistent error handling pattern across all scripts.

**Acceptance criteria:**
- [ ] Wrap each major operation in try/catch blocks
- [ ] Error results return `[PSCustomObject]@{ Status = 'Error'; ErrorType; Message; Script; Timestamp }`
- [ ] Success results return `[PSCustomObject]@{ Status = 'Success'; EventCount; OutputPath; Duration; Timestamp }`
- [ ] Add `$ErrorActionPreference = 'Stop'` at script level
- [ ] Use `Write-Error` for terminating errors, `Write-Warning` for recoverable issues
- [ ] Add `-Verbose` checkpoints for each operation phase (connect, extract, export)

### Task 5: Add Parameter Validation

**What:** Add proper parameter validation and CmdletBinding to all scripts.

**Acceptance criteria:**
- [ ] All scripts have `[CmdletBinding()]` attribute
- [ ] All string parameters have `[ValidateNotNullOrEmpty()]`
- [ ] `-DaysBack` parameters have `[ValidateRange(1, 90)]`
- [ ] `-OutputPath` parameters have `[ValidateScript({ Test-Path (Split-Path $_) })]`
- [ ] `-OutputFormat` parameter added to all extraction scripts: `[ValidateSet('CSV','JSON')]`
- [ ] `Invoke-DailyDenyReport.ps1`: Add `-DryRun` switch parameter

### Task 6: Add Script Help Comments

**What:** Add comprehensive comment-based help to all scripts following PowerShell conventions.

**Acceptance criteria:**
- [ ] `.SYNOPSIS`, `.DESCRIPTION`, `.PARAMETER`, `.EXAMPLE`, `.NOTES` for all 4 scripts
- [ ] `.NOTES` includes: Required Key Vault secrets, required Azure RBAC roles, module dependencies
- [ ] `.EXAMPLE` shows both interactive and automated (Azure Automation) invocation patterns
- [ ] Help text uses FSI regulatory language (hedged language, no overclaims)

### Task 7: Update Framework Playbooks

**What:** Update DEC playbook pages to reflect modernized scripts.

**Acceptance criteria:**
- [ ] `purview-audit-extraction.md`: Update inline script with `#Requires`, Key Vault, DECClient import
- [ ] `dlp-event-extraction.md`: Update inline script with `#Requires`, Key Vault, DECClient import
- [ ] `deployment-guide.md`: Remove `ConvertTo-SecureString` examples; add Key Vault + DECClient setup
- [ ] Add "Key Vault Prerequisites" section to `deployment-guide.md`
- [ ] Validate with `mkdocs build --strict`
