# Phase 1 Plan 01: Dataverse Schema & Creation Script

## Goal

Create the Dataverse data foundation for ASARD — two tables (`fsi_AgentSharingCompliance` for sharing compliance tracking and `fsi_ApprovedSecurityGroupPolicy` for approved security groups per zone), two solution-specific option sets (`fsi_ASARD_compliancestatus` and `fsi_ASARD_violationtype`), and an idempotent Python schema creation script following the existing UASD pattern.

This plan delivers **DVS-01** (Dataverse tables) and **DVS-02** (schema creation script) from ROADMAP.md.

## Notes

- This plan creates the ASARD-specific schema — **separate from UASD tables**
- UASD has 5 tables (`fsi_AgentSharingSetting`, `fsi_SharingViolation`, `fsi_SharingException`, `fsi_ApprovedSecurityGroup`, `fsi_SharingPolicy`)
- ASARD has 2 tables (`fsi_AgentSharingCompliance`, `fsi_ApprovedSecurityGroupPolicy`)
- ASARD **complements** UASD — UASD detects unrestricted sharing; ASARD enforces approved-group access
- Zone rules and classification logic are in Plan 01-02 (depends on this plan's schema)
