# Plan 03-02: Teams Adaptive Card Template

## Objective
Create a Teams adaptive card template for file upload violation alerts with zone summary, violation details, and drift detection sections.

## Requirements Covered
- **DDA-05**: Teams adaptive card alerts for file upload violations

## Tasks
1. Create `src/adaptive-card-fileupload-alert.json` following CMM card pattern
2. Header: [ALERT] File Upload Security Configurator with severity badge
3. Run Summary: Status, Total Agents, Environments, File Upload Enabled Count, Severity, Reason
4. Zone Summary: 3-row table (Zone 1/2/3) with Compliant/Total columns
5. Violations: ViolationType, Agent, Environment, Zone, FileUploadExpected/Actual, Moderation, Severity, RegulatoryContext
6. Drift Detection: Drifted agents, baseline vs current file upload status, direction
7. Actions: View in Power Platform Admin, Run Manual Check, View Documentation

## Verification
- [ ] Valid Adaptive Card v1.4 schema
- [ ] All template variables use ${} syntax
- [ ] File-upload-specific fields (ViolationType, FileUploadExpected/Actual)
- [ ] Zone summary table matches FUS output format
- [ ] Action URLs are correct for FUS context
