# Plan 03-03: Azure Automation Runbook Wrapper

## Objective
Create an Azure Automation runbook that adapts Test-FileUploadCompliance.ps1 for unattended execution with certificate-based auth, structured JSON output, and per-agent drift detection.

## Requirements Covered
- **DDA-06**: Azure Automation runbook wrapper for scheduled execution

## Tasks
1. Create `scripts/Start-FileUploadValidationRunbook.ps1` following CMM runbook pattern
2. Certificate-based authentication (no interactive prompts)
3. All-zone scan in single run
4. JSON output to pipeline (captured by Get-AzAutomationJobOutput)
5. Per-agent drift detection: binary file upload enabled/disabled comparison against baselines
6. Drift direction: Enabled→Disabled = Strengthened, Disabled→Enabled = Weakened
7. AlertRequired flag based on violations or weakened drift
8. AlertSeverity: Zone 3 weakened drift → Critical
9. Error handling with structured error output
10. Read operational parameters from Dataverse environment variables (GracePeriodHours, IncludeSandbox, IncludeDrafts)

## Verification
- [ ] Certificate-based auth flow
- [ ] Batch baseline query with hashtable lookup
- [ ] Binary drift detection (enabled/disabled)
- [ ] AlertRequired and AlertSeverity flags
- [ ] Zone 3 weakened drift escalates to Critical
- [ ] Structured JSON output matching flow Parse_Results schema
- [ ] Error catch block emits valid JSON with AlertRequired=true
