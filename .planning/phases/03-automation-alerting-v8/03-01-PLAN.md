# Plan 03-01: Power Automate Daily Validation Flow

## Objective
Create a Power Automate flow definition (JSON) that runs daily, triggers file upload compliance validation via Azure Automation, writes results to Dataverse, and routes alerts based on severity.

## Requirements Covered
- **DDA-04**: Power Automate daily validation flow

## Tasks
1. Create `src/fileupload-validation-flow.json` following CMM flow pattern
2. Configure daily recurrence trigger (06:00 UTC)
3. Initialize variables: DataverseUrl, TenantId, ClientId, CertificateThumbprint, SubscriptionId, ResourceGroup, AutomationAccount, TeamsGroupId, TeamsChannelId, ComplianceDistributionList
4. Scope_Try: Create Automation Job → Wait → Check Failure → Get Output → Parse Results → Write History → Check Alert → Route (Teams + Email)
5. Scope_Catch: Send CRITICAL error email on flow failure
6. Connection references: fsi_cr_dataverse_fileuploadsecurity, fsi_cr_office365_fileuploadsecurity, fsi_cr_teams_fileuploadsecurity
7. Parse Results schema matches FUS runbook output (includes FileUploadEnabledCount, ViolationType fields)

## Verification
- [ ] Flow JSON validates against Logic App schema
- [ ] Daily recurrence at 06:00 UTC
- [ ] Automation job creation with correct runbook name
- [ ] Job polling loop with 30s delay, 2h timeout
- [ ] Validation history written before alerting (audit-first)
- [ ] Teams card only for Critical/Failed/Error
- [ ] Email for all alert-required results
- [ ] Error scope catches flow failures
