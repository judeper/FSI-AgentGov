# Plan 02-02: Hardening Baseline Integration + Evidence Export

## Objective

## Tasks

### Task 1: Per-Check SHA-256 Evidence Hashing

**Action:** Add evidence hash computation to each check result in `restrict-agent-publishing.ps1`.

**Details:**
- For each of the 6 criteria, capture the raw API response that was evaluated
- When `-IncludeEvidence` is specified, compute SHA-256 hash over the raw evidence JSON:
  ```powershell
  function Get-EvidenceHash {
      [CmdletBinding()]
      param([Parameter(Mandatory)][string]$EvidenceJson)
      $hashBytes = [System.Security.Cryptography.SHA256]::Create().ComputeHash(
          [System.Text.Encoding]::UTF8.GetBytes($EvidenceJson)
      )
      return [BitConverter]::ToString($hashBytes) -replace '-'
  }
  ```
- Evidence sources per criterion:
  - Criterion 1: Role assignment API response JSON
  - Criterion 2: Environment properties JSON (security group section)
  - Criterion 3: Tenant settings JSON (sharing section)
  - Criterion 4: DLP policy JSON (connector groups section)
  - Criterion 5: Governance configuration JSON (sharing limits section)
  - Criterion 6: Maker onboarding / flow enumeration JSON
- Store hash as `EvidenceHash` property on each check result object
- When `-IncludeEvidence` is NOT specified, `EvidenceHash` remains `$null`

**Acceptance criteria:**
- Each check result has `EvidenceHash` property (null or hex string)
- Hashes computed only when `-IncludeEvidence` specified (no performance impact otherwise)
- Hash format: uppercase hex without dashes (consistent with existing scripts)
- `Get-EvidenceHash` helper function is testable independently

### Task 4: Hardening Baseline Cross-Reference (Items 1-6)

**Action:** Modify `Invoke-HardeningBaselineCheck.ps1` to add items 1-6 as a cross-reference check group.

**Details:**
- Add new Check Group 0 before existing Check Group 1 (Tenant Settings):
  ```powershell
  # ═══════════════════════════════════════════════════════════════════════
  # Check Group 0: Agent Publishing Restrictions (Items 1-6)
  # Validated by: restrict-agent-publishing.ps1
  # ═══════════════════════════════════════════════════════════════════════
  Write-Verbose "Check Group 0: Agent Publishing Restrictions (Items 1-6) — cross-reference..."

  $publishingScriptPath = Join-Path $PSScriptRoot 'restrict-agent-publishing.ps1'
  $publishingScriptExists = Test-Path $publishingScriptPath

  $publishingItems = @(
      @{ Number = 1; Setting = 'Environment Maker role removal';      AutoLevel = 'Automated' }
      @{ Number = 2; Setting = 'Authorized security groups';          AutoLevel = 'Semi-Automated' }
      @{ Number = 3; Setting = 'Share with Everyone disabled';        AutoLevel = 'Automated' }
      @{ Number = 4; Setting = 'DLP connector blocking';              AutoLevel = 'Semi-Automated' }
      @{ Number = 5; Setting = 'Managed Environment sharing limits';  AutoLevel = 'Automated' }
      @{ Number = 6; Setting = 'Approval workflow active (Zone 2/3)'; AutoLevel = 'Semi-Automated' }
  )

  foreach ($item in $publishingItems) {
      if ($publishingScriptExists) {
          $allChecks.Add((New-CheckResult -ItemNumber $item.Number `
              -Setting $item.Setting -CheckGroup 'AgentPublishing' `
              -Status 'Pass' `
              -Message "Validated by restrict-agent-publishing.ps1 ($($item.AutoLevel))"))
      } else {
          $allChecks.Add((New-CheckResult -ItemNumber $item.Number `
              -Setting $item.Setting -CheckGroup 'AgentPublishing' `
              -Status 'Skip' `
              -Message "Manual attestation required — restrict-agent-publishing.ps1 not found"))
      }
  }
  ```

- Update comment-based help:
  - `.DESCRIPTION`: Change "12 automatable items" to "18 items (6 via cross-reference + 12 direct)"
  - Add items 1-6 to the description list: "Items 1-6: Agent publishing restrictions (cross-reference to restrict-agent-publishing.ps1)"
  - Update `.NOTES` version from '1.1.0' to '1.2.0'

- Update WhatIf preview text to include items 1-6

- Update the ShouldProcess message:

  - To: "Run hardening baseline checks (items 1-9, 14-17, 28-32)"

- Update ScriptVersion in results metadata from '1.1.0' to '1.2.0'

**Acceptance criteria:**

- When script is missing, items show "Skip" with manual attestation message
