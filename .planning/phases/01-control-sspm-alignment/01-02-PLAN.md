## Goal

Add GLIC (General Licensing & Identity Controls) cross-reference advisory notes to Controls 1.1 and 1.11 acknowledging that tenant-wide guest access restriction and MFA enforcement are complementary identity controls that strengthen the agent governance posture, without expanding the framework's control scope.

## Context

SSPM Refs 39 (Guest User Access) and 41 (MFA for All Users) are valid security posture checks excluded from the 27 in-scope alerts because they are identity-layer controls outside the Power Platform / Copilot agent governance perimeter. Advisory notes acknowledge these as complementary controls per the design decision to not expand framework scope.

Research recommends placement as `!!! info` admonitions in Section 4 (Key Configuration Points) of each control. Must use hedged language and must not reference any third-party SSPM tool by name.

### Task 1: Add Guest User access advisory to Control 1.1 (CTL-03)
- **File:** `docs/controls/pillar-1-security/1.1-restrict-agent-publishing-by-authorization.md`

- **Content:** Advisory noting that restricting Entra ID guest user access level to the most restrictive setting is a complementary identity control that limits what external users can discover and access, including AI agents.
