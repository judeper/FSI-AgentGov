## Goal

Bump Control 3.7 from v1.2 to v1.3 (the only SSPM-mapped control still at v1.2) and close the one remaining verification criteria gap (Ref 38 — Desktop Flow RPA admin roles in Control 1.18).

## Context

Research found that 26 of 27 SSPM alerts already have explicit matching verification criteria. Only Ref 38 (Desktop Flow RPAs Should Not Have Admin-Level Roles → Control 1.18) has partial coverage through general admin governance criteria (#8/#9). Control 3.7's SSPM-driven content (hardening table, verification criteria) is already in place — only the footer metadata needs updating.
