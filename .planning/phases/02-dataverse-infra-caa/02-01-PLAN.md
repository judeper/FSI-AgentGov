# Plan 02-01: CAA Dataverse Client, Requirements, and Three-Table Schema

Create the Python Dataverse Web API client (`CAAClient` class), define the three Dataverse tables (CA policy baseline, validation history, violations) with shared option set reuse, and establish the Python dependency file. This is the foundation layer — all subsequent Phase 2 plans depend on it.

### Task 2: Create `caa_client.py` — Dataverse Web API Client

**Create** `scripts/caa_client.py`

Adapt from proven AAMClient/CMMClient pattern with CAA-specific customizations:

**Class: `CAAClient`**

| Method | Purpose |
|--------|---------|
| `__init__(tenant_id, environment_url, client_id, client_secret, interactive, dry_run)` | MSAL auth setup, retry strategy (3 retries, backoff on 429/5xx) |
| `_get_token()` | Silent cache → interactive / service principal fallback |
| `_get_headers()` | Authorization bearer, OData v4 headers, `Prefer: odata.include-annotations="*"` |
| `test_connection()` | `GET /api/data/v9.2/organizations` — validates connectivity |
| `query(entity_set, select, filter, orderby, top)` | OData query with parameter building |
| `create_record(entity_set, data)` | POST with ID extraction from OData-EntityId header |
| `update_record(entity_set, record_id, data)` | PATCH for record updates |
| `get_entity_metadata(logical_name)` | GET entity metadata by logical name |
| `create_entity(definition)` | POST entity definition to metadata |
| `create_attribute(entity_name, attribute)` | POST attribute to entity metadata |
| `get_attribute_metadata(entity_name, attribute_name)` | GET attribute metadata |
| `create_global_optionset(definition)` | POST global option set definition |
| `get_global_optionset(name)` | GET global option set by name |
| `check_table_exists(logical_name)` | Boolean helper wrapping `get_entity_metadata` |
| `create_table(definition)` | Idempotent table creation (check → skip/create) |
| `create_column(entity_name, column)` | Idempotent column creation (check → skip/create) |

**Auth environment variables:** `CAA_TENANT_ID`, `CAA_ENVIRONMENT_URL`, `CAA_CLIENT_ID`, `CAA_CLIENT_SECRET`

**Retry:** `urllib3.util.retry.Retry(total=3, backoff_factor=1, status_forcelist=[429, 500, 502, 503, 504])`

**Dry-run:** All mutating methods print `[DRY-RUN] Would {action}` and return early without API calls

**Acceptance criteria:**
- All methods listed above are implemented
- `--dry-run` mode prevents all POST/PATCH/DELETE calls
- MSAL auth supports both interactive and service principal flows
- Retry strategy handles 429 (throttling) and 5xx errors
- `test_connection()` validates environment URL accessibility

**Table 1: `fsi_CAPolicyBaseline`** (UserOwned)
- Primary purpose: Store CA policy configuration snapshots for drift comparison
- EntitySetName: `fsi_capolicybaselines`

| Column | Schema Name | Type | Required | Description |
|--------|------------|------|----------|-------------|
| Policy ID | `fsi_policy_id` | String(100) | Yes | Entra ID CA policy GUID |
| Policy Display Name | `fsi_policy_display_name` | String(256) | Yes | CA policy display name |
| Policy State | `fsi_policy_state` | String(50) | Yes | enabled / reportOnly / disabled |
| Zone | `fsi_zone` | Picklist (fsi_acv_zone) | Yes | Zone classification |
| Conditions JSON | `fsi_conditions_json` | Memo | Yes | Full conditions object (users, apps, platforms, locations, risk) |
| Grant Controls JSON | `fsi_grant_controls_json` | Memo | Yes | Grant control configuration |
| Session Controls JSON | `fsi_session_controls_json` | Memo | No | Session control configuration |
| Break Glass Exclusions | `fsi_break_glass_exclusions` | Memo | No | Break-glass account GUIDs excluded from policy |
| Baseline Hash | `fsi_baseline_hash` | String(64) | Yes | SHA-256 hash of policy configuration for quick comparison |
| Is Active | `fsi_is_active` | Boolean | Yes | Whether this is the current active baseline (only one per policy) |
| Captured At | `fsi_captured_at` | DateTime | Yes | UTC timestamp of baseline capture |
| Captured By | `fsi_captured_by` | String(256) | Yes | UPN of user/SPN who captured baseline |
| Tenant ID | `fsi_tenant_id` | String(50) | Yes | Entra ID tenant GUID |

**Table 2: `fsi_CAPolicyValidationHistory`** (OrganizationOwned — immutable)
- Primary purpose: Immutable audit trail of compliance scan results
- EntitySetName: `fsi_capolicyvalidationhistory` (explicit — avoid pluralization)

| Column | Schema Name | Type | Required | Description |
|--------|------------|------|----------|-------------|
| Run ID | `fsi_run_id` | String(50) | Yes | Unique validation run identifier (GUID) |
| Validation Time | `fsi_validation_time` | DateTime | Yes | UTC timestamp of validation execution |
| Total Policies | `fsi_total_policies` | Integer | Yes | Number of CA policies evaluated |
| Passed Count | `fsi_passed_count` | Integer | Yes | Policies passing all checks |
| Warning Count | `fsi_warning_count` | Integer | Yes | Policies with warnings |
| Failed Count | `fsi_failed_count` | Integer | Yes | Policies failing validation |
| Drift Count | `fsi_drift_count` | Integer | Yes | Policies with detected drift |
| Overall Severity | `fsi_overall_severity` | Picklist (fsi_acv_severity) | Yes | Worst-case severity across all policies |
| Results JSON | `fsi_results_json` | Memo | Yes | Full validation results payload |
| Validated By | `fsi_validated_by` | String(256) | Yes | UPN/SPN that executed validation |
| Tenant ID | `fsi_tenant_id` | String(50) | Yes | Entra ID tenant GUID |

**Table 3: `fsi_CAPolicyViolation`** (UserOwned)
- Primary purpose: Individual policy-level violation records
- EntitySetName: `fsi_capolicyviolations`

| Column | Schema Name | Type | Required | Description |
|--------|------------|------|----------|-------------|
| Run ID | `fsi_run_id` | String(50) | Yes | Links to validation history run |
| Policy ID | `fsi_policy_id` | String(100) | Yes | Entra ID CA policy GUID |
| Policy Display Name | `fsi_policy_display_name` | String(256) | Yes | CA policy display name |
| Violation Type | `fsi_violation_type` | String(100) | Yes | PolicyDisabled, ConditionWeakened, GrantControlRemoved, ExclusionAdded, SessionControlChanged |
| Zone | `fsi_zone` | Picklist (fsi_acv_zone) | Yes | Zone classification of violated policy |
| Severity | `fsi_severity` | Picklist (fsi_acv_severity) | Yes | Violation severity (with Zone 3 escalation) |
| Expected Value | `fsi_expected_value` | Memo | No | What the baseline expected |
| Actual Value | `fsi_actual_value` | Memo | No | What was found in the tenant |
| Description | `fsi_description` | Memo | No | Human-readable violation description |
| Is Resolved | `fsi_is_resolved` | Boolean | Yes | Whether violation has been addressed |
| Resolved At | `fsi_resolved_at` | DateTime | No | UTC timestamp of resolution |
| Resolved By | `fsi_resolved_by` | String(256) | No | UPN of resolver |
| Tenant ID | `fsi_tenant_id` | String(50) | Yes | Entra ID tenant GUID |

**Functions:**
- `create_shared_optionsets(client, dry_run)` — Idempotent: check existence → reuse/create
- `create_baseline_table(client, dry_run)` — Create table + all columns
- `create_validation_history_table(client, dry_run)` — Create table + all columns (OrganizationOwned)
- `create_violation_table(client, dry_run)` — Create table + all columns
- `create_schema(client, dry_run)` — Orchestrator calling all above in order
- `main()` — CLI with `--dry-run`, `--verbose`, auth args

**Picklist column binding pattern:**
```python
{
    "SchemaName": "fsi_zone",
    "@odata.type": "#Microsoft.Dynamics.CRM.PicklistAttributeMetadata",
    "GlobalOptionSet@odata.bind": "/GlobalOptionSetDefinitions(Name='fsi_acv_zone')"
}
```

**Acceptance criteria:**
- All 3 tables defined with correct column types and requirements
- Shared option sets use existence-check pattern (never create duplicates)
- OrganizationOwned on validation history table (immutable)
- `EntitySetName` explicitly set on all tables (especially history to avoid `fsi_capolicyvalidationhistorys`)
- `create_schema()` is idempotent — safe to re-run
- `--dry-run` reports what would be created without making API calls
- Table/column names use `fsi_` prefix throughout
