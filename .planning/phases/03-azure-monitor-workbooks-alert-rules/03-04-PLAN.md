Create ARM templates for ALRT-01 and ALRT-02 using Microsoft.Insights/scheduledQueryRules API version 2023-12-01.

**Common structure for both alerts:**

Parameters:
- `alertName` (string, alert-specific default)
- `applicationInsightsId` (string, no default -- scope for queries)
- `actionGroupZone1Id` (string, Zone 1 action group resource ID)
- `actionGroupZone2Id` (string, Zone 2 action group resource ID)
- `actionGroupZone3Id` (string, Zone 3 action group resource ID)
- `enabled` (bool, default: true)
- `location` (string, default: "[resourceGroup().location]")

Each template deploys **3 alert rules** (one per zone) as separate resources in the same template:

**ALRT-01: High Failure Rate Alert (ALRT-01-high-failure-rate.json):**

Resource 1 - Zone 1 (Personal Productivity):
- name: "ALRT-01-High-Failure-Rate-Zone1"
- displayName: "High Failure Rate - Zone 1 (Personal Productivity)"
- description: "Agent failure rate exceeds dynamic baseline. Zone 1 uses Low sensitivity for personal productivity agents."
- severity: 2 (Warning)
- evaluationFrequency: "PT5M"
- windowSize: "PT15M"
- criteria.allOf[0]:
  - query: KQL that calculates error rate percentage for Zone 1 agents. Use customEvents filtered by timestamp > ago(15m), name == 'BotMessageSend', Zone == 'zone1' or derived from customDimensions. Calculate: todouble(countif(isnotempty(errorCodeText))) / count() * 100. Filter on physical columns first, then extend.
  - timeAggregation: "Average"
  - criterionType: "DynamicThresholdCriterion"
  - operator: "GreaterThan"
  - alertSensitivity: "Low"
  - failingPeriods: { numberOfEvaluationPeriods: 4, minFailingPeriodsToAlert: 3 }
- actions.actionGroups: [Zone 1 action group]
- actions.customProperties:
  - RunbookUrl: "https://judeper.github.io/FSI-AgentGov/playbooks/control-implementations/3.4/troubleshooting/"
  - ControlReference: "3.4 - Incident Reporting and Root Cause Analysis"
  - Zone: "Zone 1 - Personal Productivity"
  - Severity: "Warning"
- autoMitigate: true

Resource 2 - Zone 2 (Team Collaboration):
- Same pattern, alertSensitivity: "Medium", severity: 1 (Error)
- Zone: "Zone 2 - Team Collaboration", actionGroup: Zone 2

Resource 3 - Zone 3 (Enterprise Managed):
- Same pattern, alertSensitivity: "High", severity: 0 (Critical)
- Zone: "Zone 3 - Enterprise Managed", actionGroup: Zone 3

**ALRT-02: Latency Regression Alert (ALRT-02-latency-regression.json):**

Same 3-resource structure (one per zone). Differences:
- name pattern: "ALRT-02-Latency-Regression-Zone{N}"
- query: KQL that calculates P95 latency. Use customEvents filtered by timestamp, name == 'BotMessageSend', extract DurationMs from customDimensions["duration"]. Calculate percentile(DurationMs, 95).
- criterionType: "DynamicThresholdCriterion"
- operator: "GreaterThan"
- Zone 1: alertSensitivity "Low", severity 2 (Warning)
- Zone 2: alertSensitivity "Medium", severity 1 (Error)
- Zone 3: alertSensitivity "High", severity 0 (Critical)
- failingPeriods: { numberOfEvaluationPeriods: 4, minFailingPeriodsToAlert: 2 } (more sensitive for latency)
- customProperties:
  - RunbookUrl: "https://judeper.github.io/FSI-AgentGov/playbooks/control-implementations/2.9/troubleshooting/"
  - ControlReference: "2.9 - Agent Performance Monitoring and Optimization"

Both templates include outputs exposing the resource IDs of all 3 alert rules.

**ALRT-03: Abnormal Usage Pattern Alert:**

Per-zone resources with naming: "ALRT-03-Abnormal-Usage-Zone{N}"

KQL query for each zone:
- Count distinct sessions in 15-minute window for agents in the specified zone
- Use customEvents, filter by timestamp > ago(15m), name in ('BotMessageReceived', 'BotMessageSend')
- Filter by zone in customDimensions
- Summarize: dcount(session_Id) as SessionCount by AgentId
- The dynamic threshold detects when session count is anomalously high OR low (both directions matter)

Alert configuration per zone:
- evaluationFrequency: "PT5M"
- windowSize: "PT15M"
- criterionType: "DynamicThresholdCriterion"
- operator: "GreaterOrLessThan" (detect both spikes and drops)
- Zone 1: alertSensitivity "Low", severity 3 (Informational)
- Zone 2: alertSensitivity "Medium", severity 2 (Warning)
- Zone 3: alertSensitivity "High", severity 1 (Error)
- failingPeriods: { numberOfEvaluationPeriods: 4, minFailingPeriodsToAlert: 3 }

customProperties for all zones:
- RunbookUrl: "https://judeper.github.io/FSI-AgentGov/playbooks/control-implementations/3.2/troubleshooting/"
- ControlReference: "3.2 - Usage Analytics and Activity Monitoring"
- Zone: zone-specific label
- Severity: zone-specific severity name

autoMitigate: true
