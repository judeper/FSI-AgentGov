**Logic App ARM Template (logic-app-teams-notification.json):**

Create ARM template deploying a Logic App (Consumption, API version 2019-05-01) that:
1. Triggers on HTTP request (common alert schema)
2. Parses the alert payload to extract: alertRule name, severity, description, firedDateTime, customProperties (RunbookUrl, Zone, ControlReference)
3. Formats an HTML message body for Teams:
   - Alert rule name as heading
   - Severity level with color coding (Sev 0 = red, Sev 1 = orange, Sev 2 = yellow)
   - Zone information
   - Runbook link (from customProperties.RunbookUrl)
   - Control reference (from customProperties.ControlReference)
   - Fired time
4. Posts to Teams channel via Teams connector (ApiConnection type)
5. Uses `parameters('$connections')` for Teams connection configuration

Parameters:
- `logicAppName` (string, default: "fsi-agent-alert-teams-notification")
- `location` (string, default: "[resourceGroup().location]")
- `teamsConnectionName` (string, default: "teams")

Include placeholder TEAM_ID and CHANNEL_ID with comments indicating customer must configure these values.

**Action Group ARM Templates (one per zone):**

Create 3 action group templates (API version 2023-01-01), each with:

Common structure:
- `type`: "Microsoft.Insights/actionGroups"
- `location`: "global" (action groups are always global)
- `properties.enabled`: true

Parameters (all three share):
- `actionGroupName` (string, zone-specific default)
- `groupShortName` (string, max 12 chars, zone-specific)
- `emailAddress` (string, placeholder email)
- `teamsLogicAppId` (string, Logic App resource ID -- references the logic-app-teams-notification deployment)
- `teamsLogicAppCallbackUrl` (string, Logic App trigger URL)

Receivers per zone:

**Zone 1 (action-group-zone1.json):**
- groupShortName: "z1-general"
- emailReceivers: "Zone 1 General Ops" using emailAddress parameter, useCommonAlertSchema: true
- logicAppReceivers: "Teams General Channel" using teamsLogicAppId and callbackUrl parameters, useCommonAlertSchema: true

**Zone 2 (action-group-zone2.json):**

- emailReceivers: "Zone 2 Team Ops" using emailAddress parameter, useCommonAlertSchema: true
- logicAppReceivers: "Teams Team Ops Channel" using teamsLogicAppId and callbackUrl parameters, useCommonAlertSchema: true

**Zone 3 (action-group-zone3.json):**
- groupShortName: "z3-ent-ops"
- emailReceivers: "Zone 3 Enterprise Ops" using emailAddress parameter, useCommonAlertSchema: true
- logicAppReceivers: "Teams Enterprise Ops Channel" using teamsLogicAppId and callbackUrl parameters, useCommonAlertSchema: true

All templates include outputs with the resource ID of the created action group (needed by alert rules in Plan 04).

Follow the ARM template structure pattern from diagnostic-settings.json (schema, contentVersion, metadata, parameters, resources, outputs).
