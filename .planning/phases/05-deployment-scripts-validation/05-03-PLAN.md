- WORM policy: Must be configured manually (see docs/worm-configuration.md)
- Cost monitoring: Review cost alerts at 50%/75%/90% thresholds
- Runbook URLs: Verify custom property URLs point to correct documentation site

**Section 5: Troubleshooting Quick Reference**

Table of common errors and resolutions:
| Error | Cause | Resolution |
|-------|-------|------------|
| "Not authenticated" | Azure CLI not logged in | Run `az login` |
| "Resource group not found" | RG doesn't exist | Run Phase 1 provisioning or create RG |
| "Application Insights not found" | Phase 1 not completed | Run `python scripts/provision.py` first |
| "Template validation failed" | ARM syntax error | Run `az deployment group validate ...` |
| "Duplicate workbook" | Non-fixed GUID in parameters | Verify parameter files use fixed GUIDs |
| "Action group not found" (alert deployment) | Phase 2 skipped | Re-run deploy-alerts.ps1 (deploys in order) |
