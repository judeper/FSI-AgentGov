## Tasks

### Task 1: Create `create_timeout_dataverse_schema.py` — Option Sets + Policy Table

**Action:** Create `scripts/create_timeout_dataverse_schema.py` with module docstring, imports, and the following components:

1. **Module docstring** listing all tables, usage examples (matching CAA/UASD pattern)
2. **Imports:** `argparse`, `logging`, `sys`, `typing.Any/Dict/List`, `caa_client.CAAClient`
3. **Solution option sets** (`SOLUTION_OPTIONSETS` dict):
   - `fsi_ITE_compliancestatus`: Compliant(0), Non-Compliant(1), Unknown(2)
   - `fsi_ITE_environmenttype`: Default(0), Sandbox(1), Production(2), Developer(3), Trial(4)
4. **Column helper functions** (copy from CAA pattern): `_label`, `_string_col`, `_memo_col`, `_boolean_col`, `_datetime_col`, `_integer_col`, `_picklist_col`
5. **`fsi_environmentpolicy` table definition:**
   - `SchemaName`: `fsi_EnvironmentPolicy`
   - `PrimaryNameAttribute`: `fsi_environmentid` (String 100, required)
   - `OwnershipType`: `OrganizationOwned`
   - `EntitySetName`: `fsi_environmentpolicies`
6. **`fsi_environmentpolicy` columns:**
   - `fsi_environmentdisplayname` (String 200)
   - `fsi_zone` (Picklist → `fsi_acv_zone`, required) — reference only, do not create
   - `fsi_requiredmaxduration` (Integer, required)
   - `fsi_notes` (Memo)
7. **Comment block** noting `fsi_acv_zone` is a prerequisite (created by CAA schema script)

**Acceptance criteria:**
- [ ] Option sets follow `fsi_ITE_` naming convention
- [ ] `fsi_environmentpolicy` uses `fsi_environmentid` as PrimaryNameAttribute
- [ ] `fsi_zone` references `fsi_acv_zone` via `_picklist_col` without recreating it
- [ ] Column helpers match CAA/UASD signatures exactly
