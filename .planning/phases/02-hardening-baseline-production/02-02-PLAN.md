### Task 2: Implement Check Group 1 — Tenant Settings (Items 14–16)

**Files:** `scripts/governance/Invoke-HardeningBaselineCheck.ps1`

Implement checks using `Get-TenantSettings`:

```powershell
# ─── Check Group 1: Tenant Settings ─────────────────────────────────
$tenantSettings = Get-TenantSettings
```

**Item 14 — Environment Creation Restriction:**
- Query: `$tenantSettings` for environment creation policies
- Property: `powerPlatform.environments` settings for dev/prod/trial creation restrictions
- Expected: Only specific admins can create environments
- Pass: All three environment types restricted to admins
- Fail: Any type allows non-admin creation

**Item 15 — Environment Routing:**
- Query: `$tenantSettings` for environment routing configuration
- Expected: Environment routing configured
- Pass: Routing is enabled/configured
- Fail: Routing disabled or not configured

**Item 16 — Tenant Isolation:**
- Query: `$tenantSettings` for tenant isolation settings
- Property: `powerPlatform.tenantIsolation` or equivalent
- Expected: Cross-tenant connections restricted
- Pass: Isolation enabled
- Fail: Isolation disabled

**Acceptance criteria:**
- [ ] Items 14, 15, 16 produce pass/fail results
- [ ] Failed items include descriptive gap messages

### Task 3: Implement Check Group 2 — Environment Settings (Items 7–8, 17)

**Files:** `scripts/governance/Invoke-HardeningBaselineCheck.ps1`

Implement per-environment checks:

```powershell
# ─── Check Group 2: Environment Settings ────────────────────────────
$environments = Get-AdminPowerAppEnvironment
if ($EnvironmentFilter) {
    $environments = $environments | Where-Object {
        $EnvironmentFilter -contains $_.EnvironmentName -or
        $EnvironmentFilter -contains $_.DisplayName
    }
}
```

**Item 7 — Environment-Level Auditing (per environment):**
- Query: Dataverse Organization entity via REST API using environment's linked Dataverse URL
- API: `GET {envUrl}/api/data/v9.2/organizations?$select=isauditenabled`
- Expected: `isauditenabled = true`
- Skip environments without linked Dataverse instance (with warning)
- Zone requirement: All zones

**Item 8 — Audit Log Retention Period (per environment):**
- Query: Dataverse Organization entity `auditretentionperiodv2`
- API: `GET {envUrl}/api/data/v9.2/organizations?$select=auditretentionperiodv2`
- Expected thresholds (zone-dependent):
  - Zone 1: ≥ 180 days
  - Zone 2: ≥ 365 days
  - Zone 3: ≥ 730 days
  - Default (no zone mapping): ≥ 180 days
- Use `$ZoneMapping` parameter to determine zone; fall back to Zone 1 threshold

**Item 17 — Environment Security Groups (per environment):**
- Query: `Get-AdminPowerAppEnvironment` → `SecurityGroupId` property
- Expected: Non-null/non-empty for Zone 2/3 environments
- Zone 1 environments: Pass with advisory note if no security group
- Use `$ZoneMapping` parameter to determine zone

**Acceptance criteria:**
- [ ] Items 7, 8, 17 produce per-environment pass/fail results
- [ ] Environments without Dataverse are skipped with warning (items 7–8)
- [ ] Zone-specific thresholds applied for item 8
- [ ] Security group check uses zone context for item 17

### Task 5: Implement Output and Evidence Export

**Files:** `scripts/governance/Invoke-HardeningBaselineCheck.ps1`

1. **Results aggregation:**
   ```powershell
   $baselineResults = [PSCustomObject]@{
       Metadata = [PSCustomObject]@{
           CheckedAt     = [DateTime]::UtcNow
           ScriptVersion = '1.0.0'
           EnvironmentsScanned = $environments.Count
           IntegrityHash = $null
       }
       Summary = [PSCustomObject]@{
           TotalChecks   = $totalChecks
           Passed        = $passCount
           Failed        = $failCount
           Skipped       = $skipCount
           OverallStatus = if ($failCount -eq 0) { 'Passed' } else { 'GapsFound' }
       }
       Checks = $allCheckResults
       Gaps   = $gaps
   }
   ```

2. **SHA-256 evidence hash** (when `-IncludeEvidence` specified):
   ```powershell
   $resultsJson = $baselineResults | ConvertTo-Json -Depth 10 -Compress
   $hashBytes = [System.Security.Cryptography.SHA256]::Create().ComputeHash(
       [System.Text.Encoding]::UTF8.GetBytes($resultsJson)
   )
   $baselineResults.Metadata.IntegrityHash = [BitConverter]::ToString($hashBytes) -replace '-'
   ```

3. **Console summary** following `Test-PolicyCompliance.ps1` pattern:
   ```
   ── Hardening Baseline Summary ──────────────────────────────
     Items checked:     7
     Passed:            5
     Failed:            2
     Environments:      3
   ────────────────────────────────────────────────────────────
   ```

4. **Output switch** (Table/JSON/Object) with optional `-OutputPath` file export

- [ ] JSON output includes metadata with integrity hash
- [ ] Object output returns PSCustomObject for pipeline use
