**For each PowerShell script, check these patterns using Python regex:**

1. **Structure validation:**
   - Has `Param(` block (mandatory for reusable scripts) or `param(` (case insensitive)
   - Has `#Requires -Modules` statement (checks declared dependencies)
   - Has CmdletBinding attribute `[CmdletBinding()]`
   - Uses approved verbs in function names (Get-, Set-, New-, Invoke-, Export-, Import-, Test-, etc.)

2. **Security anti-patterns (CRITICAL):**
   - `ConvertTo-SecureString.*-AsPlainText` (plaintext password conversion)
   - `x-api-key` usage (deprecated per TECH-08, deadline March 31 2026)
   - Hardcoded secrets: regex for `password\s*=\s*["']`, `secret\s*=\s*["']`, `key\s*=\s*["']` in non-param context
   - `Get-Credential` without comment explaining Entra ID auth flow
   - Missing `-TenantId` parameter for multi-tenant environments

3. **Error handling:**
   - Count `try {` / `catch {` blocks
   - Flag scripts with zero error handling as HIGH severity
   - Check for `$ErrorActionPreference = 'Stop'` (recommended for deployment scripts)
   - Check for `-ErrorAction Stop` on critical cmdlets

4. **Deprecated patterns:**
   - `x-api-key` header usage (Phase 1 TECH-08)
   - `outlook.office365.com/EWS` (deprecated)
   - `/_api/web/` SharePoint REST (deprecated)
   - `Invoke-RestMethod` without `-Authentication` parameter (older auth pattern)

5. **Module dependencies:**
   - Extract `Import-Module`, `#Requires -Modules`, and cmdlet prefixes (Az., Microsoft.Graph., ExchangeOnline)
   - Cross-reference with README prerequisites section
