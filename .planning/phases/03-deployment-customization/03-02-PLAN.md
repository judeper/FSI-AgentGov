**Content structure:**

```markdown
# Agent Usage & Performance Workbook — Customization Guide

**Status:** February 2026 — FSI-AgentGov v1.2.38
**Related Controls:** 3.1, 3.2, 3.3, 3.7, 3.8

---

## Overview
- Purpose: extend and customize the workbook for org-specific requirements
- Prerequisites: workbook deployed per deployment guide
- Skill level: familiarity with Azure Monitor Workbooks and KQL

## Workbook Structure Reference
### Item Types
- Type 1 (Markdown): headers, caveats — 4 items
- Type 3 (KQL Query): data visualizations — 23 queries (Q01-Q23)
- Type 9 (Parameters): global filter parameters — 5 params
- Type 11 (Tab Links): tab navigation — 3 tabs
- Type 12 (Groups): tab content containers — 3 groups with conditionalVisibility

### Tab Architecture
- Tab 1 (Usage & Business Value): Q01-Q08
- Tab 2 (Performance & Errors): Q09-Q16 (Q15 dual: Q15a/Q15b)
- Tab 3 (Operational Health): Q17-Q23 (Q22 dual: Q22a/Q22b)

### Parameter Flow
- TimeRange (type 4): time picker feeding timeContextFromParameter
- AgentFilter (type 2): KQL-populated multi-select
- ChannelFilter (type 2): KQL-populated multi-select
- MinutesSaved (type 1): numeric input for business value
- HourlyRate (type 1): numeric input for business value

## Adjusting Zone-Specific Thresholds
### Current Defaults (Zone 3 — Enterprise Managed)
- Table: Metric / Green / Amber / Red for all 6 threshold-enabled items
### Recommended Thresholds by Zone
- Zone 1 (Personal Productivity): relaxed thresholds
- Zone 2 (Team Collaboration): moderate thresholds
- Zone 3 (Enterprise Managed): strict thresholds (defaults)
### Portal-Based Threshold Editing
- Step-by-step: Edit workbook > select tile/grid > Column Settings > Custom Formatting
- Screenshot-free instructions with portal navigation paths
### JSON-Based Threshold Editing
- tileSettings.thresholds structure for tile items
- gridSettings.formatters[].thresholdsGrid structure for grid items
- Example JSON snippet with operator/thresholdValue/representation

## Adding Custom KQL Panels
### Query Template
- JSON template for type 3 item with placeholder KQL
- Required patterns: designMode filter, parameter references, regulatory comments
### Conventions
- Query naming: query-QNN-kebab-case-description
- Time context: timeContextFromParameter: "TimeRange"
- Filter patterns: AgentFilter, ChannelFilter (when to include/omit)
### Visualization Types
- Table: timechart, barchart, table, tiles, piechart
- When to use each (timechart for trends, tiles for KPIs, table for details)

## Adding New Tabs
### Step 1: Add Tab Link
- Insert linkLabel in type 11 item with new cellValue
### Step 2: Add Group Container
- Create type 12 group with conditionalVisibility matching new tab value
### Step 3: Insert in items Array
- Place after last tab group, before fallbackResourceIds

## Integrating Organization-Specific KPIs
### CSAT Scores
- Custom survey topic that logs satisfaction via custom event
- KQL: customEvents | where name == "CustomerSatisfaction" | summarize avg(score)
### SLA Compliance Tracking
- Extend Q09 latency with SLA threshold lines
- KQL: extend SLATarget parameter
### Cost Per Conversation
- Parameter-driven like existing MinutesSaved/HourlyRate
- Formula: sessions × estimated cost per session
### Regulatory Escalation Tracking
- Filter TopicStart for regulation-tagged topics
- Custom event taxonomy recommendations

## JSON Editing Best Practices
- Always edit in Advanced Editor (not the raw file)
- Back up current workbook JSON before changes
- Test changes in a draft/private workbook first
- Validate JSON syntax after edits
- Maintain regulatory comments in KQL queries

## Additional Resources
- Azure Monitor Workbooks documentation (Microsoft Learn links)
- KQL reference (Microsoft Learn links)
- Telemetry Schema Reference (link to telemetry-schema.md)
- Deployment Guide (link to deployment-guide.md)
```
