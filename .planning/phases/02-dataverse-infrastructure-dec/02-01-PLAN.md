### Task 3: Create Schema Creation Script (create_dataverse_schema.py)

**File:** `maintainers-local/solutions-staging/deny-event-correlation-report/scripts/create_dataverse_schema.py`

Creates 4 tables with all columns:

**Table 1: `fsi_DenyEvent`** (UserOwned, IsAuditEnabled=True)
- Primary key: `fsi_deny_event_id` (GUID, auto)
- `fsi_agent_id` — StringType, MaxLength=100, Required
- `fsi_session_id` — StringType, MaxLength=100, Required
- `fsi_filter_reason` — StringType, MaxLength=500, Required
- `fsi_filter_category` — StringType, MaxLength=200
- `fsi_filter_severity` — PicklistType → `fsi_acv_severity` (reuse via GlobalOptionSetName)
- `fsi_event_timestamp` — DateTimeType, DateTimeBehavior=UserLocal, Required
- `fsi_zone` — PicklistType → `fsi_acv_zone` (reuse via GlobalOptionSetName)
- `fsi_source_type` — StringType, MaxLength=50, Required (RaiTelemetry, PurviewAudit, PurviewDlp)
- `fsi_details_json` — MemoType, MaxLength=100000
- EntitySetName: `fsi_denyevents`

**Table 2: `fsi_DenyCorrelation`** (UserOwned, IsAuditEnabled=True)
- Primary key: `fsi_deny_correlation_id` (GUID, auto)
- `fsi_correlation_date` — DateTimeType, DateTimeBehavior=UserLocal, Required
- `fsi_agent_id` — StringType, MaxLength=100, Required
- `fsi_zone` — PicklistType → `fsi_acv_zone` (reuse)
- `fsi_event_count` — IntegerType, Required
- `fsi_severity_distribution_json` — MemoType, MaxLength=10000
- `fsi_trend_7day_json` — MemoType, MaxLength=10000
- `fsi_time_window_start` — DateTimeType, DateTimeBehavior=UserLocal, Required
- `fsi_time_window_end` — DateTimeType, DateTimeBehavior=UserLocal, Required
- `fsi_correlation_details_json` — MemoType, MaxLength=100000
- EntitySetName: `fsi_denycorrelations`

**Table 3: `fsi_DenyAlert`** (UserOwned, IsAuditEnabled=True)
- Primary key: `fsi_deny_alert_id` (GUID, auto)
- `fsi_alert_type` — StringType, MaxLength=50 (VolumeAnomaly, NewAgent, ZoneCritical)
- `fsi_alert_severity` — PicklistType → `fsi_acv_severity` (reuse)
- `fsi_agent_id` — StringType, MaxLength=100
- `fsi_zone` — PicklistType → `fsi_acv_zone` (reuse)
- `fsi_alert_timestamp` — DateTimeType, DateTimeBehavior=UserLocal
- `fsi_alert_message` — MemoType, MaxLength=10000
- `fsi_acknowledged` — BooleanType, Default=false
- `fsi_details_json` — MemoType, MaxLength=100000
- EntitySetName: `fsi_denyalerts`

**Table 4: `fsi_DenyValidationHistory`** (OrganizationOwned, IsAuditEnabled=True)
- Primary key: `fsi_deny_validation_id` (GUID, auto)
- `fsi_validation_run_id` — StringType, MaxLength=100, Required
- `fsi_validation_type` — StringType, MaxLength=50, Required
- `fsi_records_processed` — IntegerType
- `fsi_records_passed` — IntegerType
- `fsi_records_failed` — IntegerType
- `fsi_validation_details_json` — MemoType, MaxLength=100000
- `fsi_run_timestamp` — DateTimeType, DateTimeBehavior=UserLocal, Required
- EntitySetName: `fsi_denyvalidationhistory`

**Option set handling:**
- Check if `fsi_acv_zone` exists → reuse (don't create)
- Check if `fsi_acv_severity` exists → reuse (don't create)
- If neither exists (fresh environment) → create with canonical values from research

**Acceptance criteria:**
- [ ] 4 tables created with all columns matching research column mapping
- [ ] `fsi_acv_zone` and `fsi_acv_severity` reused (not duplicated)
- [ ] `fsi_DenyValidationHistory` is OrganizationOwned; other 3 are UserOwned
- [ ] All tables have IsAuditEnabled=True
- [ ] Explicit EntitySetName set on all tables
- [ ] Idempotent: re-running does not error

### Task 6: Create Deployment Orchestrator (deploy.py)

**File:** `maintainers-local/solutions-staging/deny-event-correlation-report/scripts/deploy.py`

Orchestrates deployment in correct order:
1. Create/reuse option sets (schema script)
2. Create tables and columns (schema script)
3. Create environment variables
4. Create connection references
5. Create bulk delete jobs for retention (3 jobs, one per zone)

Supports:
- `--dry-run` — logs all operations without executing
- `--schema-only` — tables and columns only
- `--env-vars-only` — environment variables only
- `--retention-only` — bulk delete jobs only
- Full deployment (default)

**Retention bulk delete jobs** (NEW capability):
- 3 `BulkDeleteRequest` calls via Web API
- Each targets `fsi_denyevents` filtered by `fsi_zone` and `fsi_event_timestamp`
- Recurring daily at 02:00 UTC
- Retention days read from environment variables

**Acceptance criteria:**
- [ ] deploy.py orchestrates all 5 deployment phases
- [ ] `--dry-run` logs without executing
- [ ] Selective deployment flags work
- [ ] Bulk delete jobs created for 3 zones with correct FetchXML filters
- [ ] Exit code 0 on success, non-zero on failure
