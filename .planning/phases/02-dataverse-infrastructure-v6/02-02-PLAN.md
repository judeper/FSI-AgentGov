# Plan 02-02: Environment Variables, Connection References, and deploy.py Orchestrator

## Goal

Deploy the operational configuration layer — environment variables that externalize runtime parameters, connection references for Power Automate integration, and the orchestrator script that runs the full deployment pipeline. Together with Plan 02-01, this completes the Python deployment infrastructure.

## Tasks

### Task 1: Create create_environment_variables.py

Create `agent-access-monitor/scripts/create_environment_variables.py`.

**Environment Variables (fsi_AAM_* prefix):**

| Schema Name | Display Name | Type | Default | Purpose |
|------------|-------------|------|---------|---------|
| `fsi_AAM_GracePeriodHours` | AAM - Grace Period (Hours) | Decimal (100000001) | 48 | Hours to exclude newly provisioned environments |
| `fsi_AAM_ScanFrequencyHours` | AAM - Scan Frequency (Hours) | Decimal (100000001) | 24 | Automated scan interval |
| `fsi_AAM_IncludeSandbox` | AAM - Include Sandbox Environments | String (100000000) | false | Whether to include sandbox environments |
| `fsi_AAM_BaselineMaxAgeDays` | AAM - Maximum Baseline Age (Days) | Decimal (100000001) | 30 | Alert threshold for stale baselines |
| `fsi_AAM_TeamsGroupId` | AAM - Teams Alert Group ID | String (100000000) | (blank) | Teams group GUID for alerts |
| `fsi_AAM_TeamsChannelId` | AAM - Teams Alert Channel ID | String (100000000) | (blank) | Teams channel GUID for alerts |

**Function signatures:**
- `ENV_VAR_DEFINITIONS` — list of dictionaries with schema_name, display_name, type, default_value, description
- `create_environment_variable(client, definition, dry_run)` — idempotent create with existence check
- `create_environment_variables(client, dry_run)` — iterate all definitions
- `main()` — CLI entry with auth args

**Dataverse query pattern:**
```python
# Check existence
existing = client.query(
    "environmentvariabledefinitions",
    filter=f"schemaname eq '{schema_name}'"
)
if existing.get("value"):
    print(f"  {schema_name}: already exists, skipping")
    return
# Create definition, then create value record
```

**Acceptance Criteria:**
- [ ] Six environment variables created with correct types and defaults
- [ ] Each variable has definition + value records
- [ ] Existence check prevents duplicates on re-run
- [ ] Dry-run mode shows "would create" messages

**File:** `agent-access-monitor/scripts/create_environment_variables.py` (CREATE)

### Task 3: Create deploy.py orchestrator

Create `agent-access-monitor/scripts/deploy.py` — the single entry point for deploying all Dataverse infrastructure.

**Deployment pipeline:**
```
deploy.py
├── Step 1: Test Connection
├── Step 2: Dataverse Schema (create_dataverse_schema.create_schema)
├── Step 3: Environment Variables (create_environment_variables.create_environment_variables)
├── Step 4: Connection References (create_connection_references.create_connection_references)
└── Post-Deployment Guidance
    ├── Security: Remove Write/Delete on fsi_AccessValidationHistory
    ├── Connections: Bind connection references in Power Automate
    └── Verification: Run --dry-run to confirm all components exist
```

**CLI arguments:**
- `--tenant-id` — Entra tenant (or AAM_TENANT_ID env var)
- `--client-id` — App registration (or AAM_CLIENT_ID)
- `--client-secret` — Client secret (or AAM_CLIENT_SECRET)
- `--environment-url` — Dataverse URL (or AAM_ENVIRONMENT_URL)
- `--interactive` — Use interactive auth
- `--dry-run` — Preview without deploying
- `--tables-only` — Deploy schema only
- `--vars-only` — Deploy environment variables only
- `--refs-only` — Deploy connection references only

**Post-deployment output:**
```
═══════════════════════════════════════════════════
  Agent Access Governance Monitor — Deployment Complete
═══════════════════════════════════════════════════

  ✓ Dataverse Schema: 3 tables, 2 shared option sets
  ✓ Environment Variables: 6 variables (fsi_AAM_*)
  ✓ Connection References: 3 references (fsi_cr_*_accessmonitor)

  POST-DEPLOYMENT STEPS:
  1. Security: Remove Write/Delete privileges on fsi_AccessValidationHistory
     for all roles except System Administrator
  2. Connections: Bind connection references in Power Automate
  3. Verify: Run 'python deploy.py --dry-run' to confirm all components
```

**Acceptance Criteria:**
- [ ] Full deployment runs schema → env vars → connection refs in order
- [ ] Selective modes (--tables-only, --vars-only, --refs-only) work
- [ ] Dry-run mode previews all operations
- [ ] Post-deployment guidance printed on completion
- [ ] All operations idempotent (safe to re-run)
- [ ] Errors are caught and reported without aborting other steps

**File:** `agent-access-monitor/scripts/deploy.py` (CREATE)
