# Plan 02-01: AAM Dataverse Client, Requirements, and Three-Table Schema Deployment

## Goal

Create the Python infrastructure foundation for the Agent Access Governance Monitor — the shared Dataverse client, Python dependencies, and schema deployment script for three tables. This is the foundation all subsequent Phase 2 plans depend on.

## Tasks

### Task 1: Create aam_client.py

Create `agent-access-monitor/scripts/aam_client.py` adapting the proven SSCClient/ACVClient pattern.

**Class AAMClient:**

| Method | Purpose |
|--------|---------|
| `__init__(tenant_id, environment_url, client_id, client_secret, interactive, dry_run)` | MSAL auth setup with retry strategy |
| `_get_token()` | Token acquisition: silent cache → interactive/SP fallback |
| `_get_headers()` | Authorization bearer, OData headers, Prefer annotations |
| `test_connection()` | GET organizations endpoint |
| `query(entity_set, select, filter, orderby, top)` | OData query with parameters |
| `create_record(entity_set, data)` | POST to entity set, extract ID from OData-EntityId header |
| `get_entity_metadata(logical_name)` | Table metadata lookup |
| `create_entity(definition)` | Create table from definition |
| `create_attribute(entity_name, definition)` | Create column |
| `get_attribute_metadata(entity_name, attribute)` | Column metadata lookup |
| `create_global_optionset(definition)` | Create global option set |
| `get_global_optionset(name)` | Option set metadata lookup |
| `check_table_exists(logical_name)` | Idempotent table existence check |
| `create_table(name, display, plural, description, ownership, columns)` | Idempotent table creation |
| `create_option_set(name, options)` | Idempotent option set creation |
| `create_column(entity, name, type, definition)` | Idempotent column creation |

**Environment variable prefix:** `AAM_` (AAM_TENANT_ID, AAM_ENVIRONMENT_URL, AAM_CLIENT_ID, AAM_CLIENT_SECRET)

**Retry strategy:** `Retry(total=3, backoff_factor=1, status_forcelist=[429, 500, 502, 503, 504])`

**CLI entry point:** `main()` with args: `--tenant-id`, `--client-id`, `--client-secret`, `--environment-url`, `--interactive`, `--test-connection`, `--dry-run`

**Acceptance Criteria:**
- [ ] AAMClient authenticates with MSAL (interactive + service principal modes)
- [ ] All mutating operations respect dry_run flag
- [ ] Retry strategy handles 429/5xx responses
- [ ] main() CLI entry point works standalone for testing
- [ ] Follows SSCClient/ACVClient structure exactly with AAM naming

**File:** `agent-access-monitor/scripts/aam_client.py` (CREATE)

### Task 3: Create create_dataverse_schema.py

Create `agent-access-monitor/scripts/create_dataverse_schema.py` with three-table schema.

**Shared Option Sets (existence check before create):**

| Name | Values |
|------|--------|
| `fsi_acv_zone` | 0=Unclassified, 1=Zone 1, 2=Zone 2, 3=Zone 3 |
| `fsi_acv_severity` | 1=Passed, 2=Warning, 3=GracePeriod, 4=Failed, 5=Error |

**Table 1: fsi_AccessBaseline (UserOwned)**

Stores per-environment access setting snapshots.

| SchemaName | Type | Required | Description | AAMClient.psm1 Key |
|------------|------|----------|-------------|---------------------|
| `fsi_name` | String(200) | Yes | Baseline ID | (primary name) |
| `fsi_environment_guid` | String(100) | Yes | Power Platform environment GUID | `fsi_environment_guid` |
| `fsi_environment_name` | String(500) | Yes | Environment display name | `fsi_environment_name` |
| `fsi_zone` | Picklist (fsi_acv_zone) | Yes | Zone classification | `fsi_zone` |
| `fsi_bot_limit_sharing_mode` | String(200) | Yes | Captured bot-limitSharingMode | `fsi_bot_limit_sharing_mode` |
| `fsi_bot_authoring_sharing_disabled` | Boolean | Yes | Captured bot-authoringSharingDisabled | `fsi_bot_authoring_sharing_disabled` |
| `fsi_bot_published_bot_limit_sharing_mode` | String(200) | Yes | Captured bot-publishedBotLimitSharingMode | `fsi_bot_published_bot_limit_sharing_mode` |
| `fsi_is_active` | Boolean | Yes | Active baseline flag | `fsi_is_active` |
| `fsi_captured_at` | DateTime | Yes | Capture timestamp | `fsi_captured_at` |
| `fsi_captured_by` | String(200) | No | Capture operator UPN | `fsi_captured_by` |
| `fsi_raw_json` | Memo(100000) | No | Full JSON snapshot | `fsi_raw_json` |

> **CRITICAL:** All SchemaName values use snake_case to match the property keys in AAMClient.psm1. Dataverse is case-insensitive on logical names.

**Table 2: fsi_AccessValidationHistory (OrganizationOwned — IMMUTABLE)**

Immutable audit log for FINRA 4511/SEC 17a-3.

| SchemaName | Type | Required | Description | AAMClient.psm1 Key |
|------------|------|----------|-------------|---------------------|
| `fsi_name` | String(200) | Yes | Validation ID | (primary name) |
| `fsi_run_id` | String(36) | Yes | Scan execution GUID | `fsi_run_id` |
| `fsi_zone` | Picklist (fsi_acv_zone) | Yes | Zone classification | `fsi_zone` |
| `fsi_severity` | Picklist (fsi_acv_severity) | Yes | Overall severity | `fsi_severity` |
| `fsi_total_environments` | Integer | No | Environments scanned | `fsi_total_environments` |
| `fsi_compliant_count` | Integer | No | Passing environments | `fsi_compliant_count` |
| `fsi_violation_count` | Integer | No | Violated environments | `fsi_violation_count` |
| `fsi_overall_status` | String(50) | Yes | Passed/Warning/Review/Failed | `fsi_overall_status` |
| `fsi_summary_json` | Memo(100000) | No | Full JSON result | `fsi_summary_json` |
| `fsi_validation_time` | DateTime | Yes | Validation timestamp | `fsi_validation_time` |

> **NOTE:** Column `fsi_validation_time` matches the AAMClient.psm1 property name exactly (not `fsi_Timestamp`).

**Table 3: fsi_AccessViolation (UserOwned)**

Per-environment, per-setting violations.

| SchemaName | Type | Required | Description | AAMClient.psm1 Key |
|------------|------|----------|-------------|---------------------|
| `fsi_name` | String(200) | Yes | Violation ID | (primary name) |
| `fsi_environment_guid` | String(100) | Yes | Environment GUID | `fsi_environment_guid` |
| `fsi_environment_name` | String(500) | Yes | Environment display name | `fsi_environment_name` |
| `fsi_zone` | Picklist (fsi_acv_zone) | Yes | Zone classification | `fsi_zone` |
| `fsi_severity` | Picklist (fsi_acv_severity) | Yes | Violation severity | `fsi_severity` |
| `fsi_violation_type` | String(200) | Yes | Setting key (e.g., bot-limitSharingMode) | `fsi_violation_type` |
| `fsi_expected_value` | String(2000) | Yes | Zone requirement | `fsi_expected_value` |
| `fsi_actual_value` | String(2000) | Yes | Found value | `fsi_actual_value` |
| `fsi_regulatory_context` | String(2000) | No | FINRA/SOX impact | `fsi_regulatory_context` |
| `fsi_detected_at` | DateTime | Yes | Detection timestamp | `fsi_detected_at` |
| `fsi_acknowledged` | Boolean | No | Operator reviewed flag | — (future) |
| `fsi_acknowledged_by` | String(200) | No | Acknowledging operator UPN | — (future) |
| `fsi_acknowledged_on` | DateTime | No | Acknowledgement timestamp | — (future) |
| `fsi_resolved_at` | DateTime | No | Remediation timestamp | — (future) |
| `fsi_notes` | Memo(2000) | No | Operator notes | — (future) |

**Functions:**
- `create_shared_optionsets(client, dry_run)` — existence check, then create if missing
- `create_access_baseline_table(client, dry_run)` — UserOwned, IsAuditEnabled
- `create_validation_history_table(client, dry_run)` — OrganizationOwned, IsAuditEnabled
- `create_access_violation_table(client, dry_run)` — UserOwned, IsAuditEnabled
- `create_schema(client, dry_run)` — orchestrator calling all above
- `main()` — CLI entry with auth args

**Acceptance Criteria:**
- [ ] Three tables created with correct ownership types
- [ ] AccessValidationHistory is OrganizationOwned
- [ ] Shared option sets checked before creation
- [ ] All operations are idempotent (safe to re-run)
- [ ] Dry-run mode previews all operations
- [ ] Column SchemaNames use snake_case matching AAMClient.psm1 property keys exactly
- [ ] IsAuditEnabled=True on all tables
- [ ] fsi_validation_time column (not fsi_Timestamp) matches AAMClient.psm1

**File:** `agent-access-monitor/scripts/create_dataverse_schema.py` (CREATE)
