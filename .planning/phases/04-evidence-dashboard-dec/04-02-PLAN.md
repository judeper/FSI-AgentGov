# Plan 04-02: Unified Evidence Integration and IntegrationConfig Extension

### Task 2: Extend Get-SolutionTableConfig

**File:** `maintainers-local/solutions-staging/cross-solution-integration/scripts/powershell/IntegrationConfig.psm1`

**Action:** MODIFY

**Details:**
Add DEC table configuration:

```powershell
'DEC' = @{
    PrimaryTable    = 'fsi_denycorrelations'
    KeyColumns      = @('fsi_correlation_date', 'fsi_agent_id', 'fsi_zone')
    StatusColumn    = $null  # DEC derives status from alert severity
    AlertTable      = 'fsi_denyalerts'
    AlertKeyColumns = @('fsi_alert_timestamp', 'fsi_severity')
    QueryPattern    = 'fsi_denycorrelations?$filter=fsi_correlation_date ge {date}&$orderby=fsi_correlation_date desc'
    AlertQueryPattern = 'fsi_denyalerts?$filter=fsi_alert_timestamp ge {date}&$orderby=fsi_alert_timestamp desc'
    StatusDerivation = 'AlertBased'  # Signals to Sync script: use alert severity, not status column
}
```

**Acceptance criteria:**
- [ ] DEC config references `fsi_denycorrelations` as primary table
- [ ] Alert table (`fsi_denyalerts`) included for status derivation
- [ ] `StatusDerivation = 'AlertBased'` signals novel status logic to Sync script

### Task 3: Extend ConvertTo-DashboardStatus

**File:** `maintainers-local/solutions-staging/cross-solution-integration/scripts/powershell/IntegrationConfig.psm1`

**Action:** MODIFY

**Details:**
Add DEC-specific status translation in the switch block:

```powershell
'DEC' {
    # DEC uses alert-severity-based status derivation
    # $InputStatus expected as hashtable: @{ Critical=N; High=N; Warning=N; Info=N }
    if ($InputStatus.Critical -gt 0 -or $InputStatus.High -gt 0) {
        return 3  # Non-Compliant
    }
    elseif ($InputStatus.Warning -gt 0) {
        return 2  # Partially Compliant
    }
    else {
        return 1  # Compliant
    }
}
```

**Acceptance criteria:**
- [ ] Critical/High alerts → 3 (Non-Compliant)
- [ ] Warning alerts → 2 (Partially Compliant)
- [ ] Info-only or no alerts → 1 (Compliant)
- [ ] Input format documented (hashtable with severity counts)
