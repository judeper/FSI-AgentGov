# Plan 04-03: Sync-SolutionAssessments.ps1 Extension for DEC Dashboard Feed

## Objective

Extend the Compliance Dashboard sync script to query DEC's `fsi_denycorrelation` daily summaries and `fsi_denyalert` records, derive zone-level compliance status from alert severity distribution, and upsert assessment records for Controls 1.5, 1.7, and 3.4 — wiring deny event governance data into the Compliance Dashboard.

## Tasks

### Task 1: Add DEC Query Block to Solution Processing Loop

**File:** `maintainers-local/solutions-staging/cross-solution-integration/scripts/powershell/Sync-SolutionAssessments.ps1`

**Action:** MODIFY

**Details:**
Add DEC-specific processing block within the per-solution iteration:

```powershell
'DEC' {
    # Step 1: Query today's correlations
    $decTableConfig = Get-SolutionTableConfig -Solution 'DEC'
    $correlationFilter = "fsi_correlation_date ge $($today.ToString('yyyy-MM-dd'))"
    $correlations = Invoke-DataverseQuery -Url $DataverseUrl -Token $token `
        -EntitySet $decTableConfig.PrimaryTable `
        -Filter $correlationFilter

    # Step 2: Query today's alerts for severity distribution
    $alertFilter = "fsi_alert_timestamp ge $($today.ToString('yyyy-MM-ddT00:00:00Z'))"
    $alerts = Invoke-DataverseQuery -Url $DataverseUrl -Token $token `
        -EntitySet $decTableConfig.AlertTable `
        -Filter $alertFilter

    # Step 3: Group correlations by zone
    $zoneGroups = $correlations | Group-Object -Property fsi_zone

    # Step 4: For each zone, derive status from alerts
    foreach ($zoneGroup in $zoneGroups) {
        $zone = Get-CanonicalZoneValue -Value $zoneGroup.Name
        $zoneAlerts = $alerts | Where-Object { (Get-CanonicalZoneValue -Value $_.fsi_zone) -eq $zone }

        # Build severity distribution for ConvertTo-DashboardStatus
        $severityDist = @{ Critical = 0; High = 0; Warning = 0; Info = 0 }
        foreach ($alert in $zoneAlerts) {
            $sev = $alert.fsi_severity  # Map from option set value to name
            if ($severityDist.ContainsKey($sev)) { $severityDist[$sev]++ }
        }

        $status = ConvertTo-DashboardStatus -Solution 'DEC' -InputStatus $severityDist
        $eventCount = ($zoneGroup.Group | Measure-Object -Property fsi_event_count -Sum).Sum
        $alertCount = $zoneAlerts.Count

        # Step 5: Upsert assessment for each mapped control
        $controlIds = Get-SolutionControlMapping | Select-Object -ExpandProperty 'DEC'
        foreach ($controlId in $controlIds) {
            $notes = "Automated: DenyEventCorrelation — $eventCount events, $alertCount alerts"

            # Check for existing same-day assessment
            # Upsert (PATCH if exists, POST if new)
            Invoke-AssessmentUpsert -DataverseUrl $DataverseUrl -Token $token `
                -ControlId $controlId -Zone $zone -Status $status `
                -Notes $notes -AssessmentDate $today
        }
    }

    # Step 6: Handle zones with no correlations today → Not Assessed
    $allZones = @('1', '2', '3')
    $assessedZones = $zoneGroups | ForEach-Object { Get-CanonicalZoneValue -Value $_.Name }
    $unassessedZones = $allZones | Where-Object { $_ -notin $assessedZones }
    foreach ($zone in $unassessedZones) {
        foreach ($controlId in $controlIds) {
            Invoke-AssessmentUpsert -DataverseUrl $DataverseUrl -Token $token `
                -ControlId $controlId -Zone $zone -Status 4 `
                -Notes "Automated: DenyEventCorrelation — No correlations for today" `
                -AssessmentDate $today
        }
    }
}
```

**Acceptance criteria:**
- [ ] Queries `fsi_denycorrelations` with today's date filter
- [ ] Queries `fsi_denyalerts` for severity-based status derivation
- [ ] Groups correlations by zone
- [ ] Derives CD status: Critical/High→3, Warning→2, Info/none→1, no data→4
- [ ] Upserts assessment records for all 3 controls (1.5, 1.7, 3.4) per zone
- [ ] Notes include event count and alert count
