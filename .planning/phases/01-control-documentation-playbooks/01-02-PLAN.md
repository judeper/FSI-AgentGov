# Plan 01-02: Playbooks & Screenshot Specification

## Goal

Create 4 implementation playbooks in `docs/playbooks/control-implementations/1.25/` and the screenshot specification in `docs/images/1.25/EXPECTED.md`, following established patterns from Control 1.24.

## Context

- **Exemplar playbooks:** `docs/playbooks/control-implementations/1.24/` (all 4 types)
- **EXPECTED.md exemplar:** `docs/images/1.24/EXPECTED.md`
- **Module reference:** FsiMimeControl.psm1 (Phase 2 deliverable — reference design in playbook)
- **Portal:** Power Platform Admin Center (PPAC) — Privacy + Security settings

## Tasks

### Task 1: Create portal-walkthrough playbook

**File:** `docs/playbooks/control-implementations/1.25/portal-walkthrough.md`

**Acceptance criteria:**

1. Title: `# Portal Walkthrough: Control 1.25 - MIME Type Restrictions for File Uploads`
2. Metadata: Last Updated (February 2026), Portal (Power Platform Admin Center), Estimated Time (20-30 minutes)
3. Prerequisites checkbox list:
   - Power Platform Admin or Entra Global Admin role
   - Access to Power Platform Admin Center
   - Knowledge of organizational file type requirements per zone
4. Step-by-step sections (`### Step N:`) covering:
   - Navigate to PPAC Environment Security settings
   - Configure blocked file extensions
   - Configure blocked MIME types (Zone 2+)
   - Configure allowed MIME types allowlist (Zone 2+)
   - Review and apply zone-appropriate template
5. Governance settings table by zone (Baseline / Recommended / Regulated)
6. Validation checklist at bottom
7. Footer nav: links to control doc, powershell-setup, verification-testing, troubleshooting

### Task 2: Create powershell-setup playbook

**File:** `docs/playbooks/control-implementations/1.25/powershell-setup.md`

**Acceptance criteria:**

1. Title: `# PowerShell Setup: Control 1.25 - MIME Type Restrictions for File Uploads`
2. Metadata: Last Updated (February 2026), Modules Required (FsiMimeControl)
3. Prerequisites with Install-Module / Import-Module instructions
4. Script sections with comment-based help:
   - Get current MIME configuration (`Get-FsiMimeConfig`)
   - Apply zone template (`Set-FsiMimeConfig -ZoneTemplate zone2 -WhatIf`)
   - Validate compliance (`Test-FsiMimeCompliance -Zone 2`)
5. Validation script with `[PASS]`/`[FAIL]`/`[INFO]` output pattern
6. Complete configuration script with `param()`, `try/catch/finally`, `-OutputFormat`/`-OutputPath` parameters
7. Footer nav: links to control doc, portal-walkthrough, verification-testing, troubleshooting

### Task 3: Create verification-testing playbook

**File:** `docs/playbooks/control-implementations/1.25/verification-testing.md`

**Acceptance criteria:**

1. Title: `# Verification & Testing: Control 1.25 - MIME Type Restrictions for File Uploads`
2. Metadata: Last Updated (February 2026)
3. Manual verification tests (`### Test N:`) with `**EXPECTED:**` results:
   - Test 1: Verify blocked extensions list matches zone template
   - Test 2: Verify blocked MIME types configured (Zone 2+)
   - Test 3: Verify allowed MIME types allowlist (Zone 2+)
   - Test 4: Attempt upload of blocked file type — confirm rejection
   - Test 5: Verify DLP policy generating alerts (Zone 2+)
   - Test 6: Verify Sentinel queries returning data (Zone 3)
4. Test cases table: `Test ID | Scenario | Expected Result | Pass/Fail` (TC-1.25-01 through TC-1.25-06+)
5. Evidence collection checklist (screenshots, PS output exports)
6. Attestation statement template for compliance sign-off
7. Zone-specific testing requirements table (frequency by zone)
8. KQL queries for automated evidence collection
9. Footer nav: links to control doc, portal-walkthrough, powershell-setup, troubleshooting

### Task 4: Create troubleshooting playbook

**File:** `docs/playbooks/control-implementations/1.25/troubleshooting.md`

**Acceptance criteria:**

1. Title: `# Troubleshooting: Control 1.25 - MIME Type Restrictions for File Uploads`
2. Metadata: Last Updated (February 2026)
3. Common issues summary table (Issue / Cause / Resolution):
   - Blocked file type still uploadable
   - MIME type not recognized by platform
   - Zone template application fails
   - DLP policy not triggering on file uploads
   - Sentinel query returns no results
   - FsiMimeControl module import errors
4. Detailed `### Issue:` sections with Symptoms, Resolution steps, Portal Path
5. Escalation path (Power Platform Admin → Security Operations → Microsoft Support)
6. Known limitations table (Limitation / Impact / Workaround)
7. Diagnostic commands (PowerShell snippets for quick MIME config checks)
8. Related documentation links (Microsoft Learn)
9. Footer nav: links to control doc, portal-walkthrough, powershell-setup, verification-testing

### Task 5: Create EXPECTED.md screenshot specification

**Acceptance criteria:**

     - Portal Path: same as above
     - What to capture: blocked MIME types configuration
   - Screenshot 3: PPAC Allowed MIME Types Field
     - Portal Path: same as above
     - What to capture: allowed MIME types allowlist
   - Screenshot 4: Compliance Test Output
     - What to capture: `Test-FsiMimeCompliance` terminal output showing pass/fail per zone
3. Notes for verification section with capture guidelines
