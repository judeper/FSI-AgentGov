    Create Power Automate flow definition JSON files implementing the logic from docs/flow-configuration.md.

    1. CD-ScoreCalculator.json:
       - Trigger: Recurrence (daily at 06:00 UTC)
       - Actions:
         a. Initialize TotalWeightedScore (Float, 0)
         b. Initialize TotalWeight (Float, 0)
         c. Initialize PillarScores (Object)
         d. List rows from fsi_controlassessment (latest per control)
         e. Apply to each: Calculate weighted score
         f. Compose: Calculate final scores
         g. Create row in fsi_compliancescore
       - Error handling: Send notification on failure
       - Connection references: Dataverse, Office 365 Outlook

    2. CD-ExceptionMonitor.json:
       - Trigger: Recurrence (hourly)
       - Actions:
         a. List rows from fsi_complianceexception (status IN 1,2,3)
         b. Apply to each:
            - Calculate DaysOpen
            - Determine SLA based on severity (Critical=7, High=14, Medium=30, Low=90)
            - Set fsi_slastatus based on thresholds (Breached if >SLA, At Risk if >80%)
            - Update row
            - Condition: Send notification if status changed to Breached
       - Connection references: Dataverse, Office 365 Outlook, Microsoft Teams

    Use Power Automate JSON schema:
    - Definition structure with triggers, actions, outputs
    - Connection references for Dataverse operations
    - Environment variables for CD_NotificationEmail, CD_TeamsWebhook
    - Proper OData filter expressions

    Note: Flow JSON uses specific schema format. Reference:
    - https://learn.microsoft.com/en-us/power-automate/workflow-definition-language
    - Include $schema, contentVersion, triggers, actions sections
