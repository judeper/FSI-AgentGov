# Phase 1 Plan B: Pester 5 Unit Tests

## Goal

Create comprehensive Pester 5 unit tests for the AuditComplianceHelpers module covering all critical paths.

## Tasks

### Task 1: Invoke-WithRetry Tests

**Acceptance criteria:**
- Test successful first-attempt execution
- Test retry on 429, 503, 504 with eventual success
- Test throw after exhausting max retries
- Test immediate throw on non-retryable errors (400, 401, 403, 404)
- Test immediate throw on non-HTTP errors

### Task 2: Get-ManagedIdentityToken Tests

**Acceptance criteria:**
- Test throw when IDENTITY_ENDPOINT is not set
- Test throw when IDENTITY_HEADER is not set
- Test successful token acquisition with mocked endpoint

### Task 3: Write-DataverseComplianceRecord Tests

**Acceptance criteria:**
- Test upsert — create new when no existing record (GET returns empty, POST called)
- Test upsert — update existing when record found (GET returns record, PATCH called)
- Test invalid ComplianceStatus rejection

### Task 4: Send-ComplianceNotification Tests

**Acceptance criteria:**
- Test correct Graph sendMail payload structure
- Test attachment handling (base64 encoding, contentType)
- Test multiple recipients

### Task 5: Status Mapping Tests

**Acceptance criteria:**
- Test all 4 ComplianceStatusMap entries
- Test all 4 ComplianceStatusReverseMap entries
