    **Step 2 — ARCH-02: Convert Implementation Guides to INFO admonition for controls 1.1 through 1.12.**

    For each control file, find the existing `## Implementation Guides` section and replace it with an INFO admonition box. The existing section follows this pattern:

    ```markdown
    ## Implementation Guides

    > For step-by-step implementation, see the playbooks:

    - [Portal Walkthrough](../../playbooks/control-implementations/{id}/portal-walkthrough.md) - Step-by-step portal configuration
    - [PowerShell Setup](../../playbooks/control-implementations/{id}/powershell-setup.md) - Scripts for automation
    - [Verification & Testing](../../playbooks/control-implementations/{id}/verification-testing.md) - Test cases and evidence collection
    - [Troubleshooting](../../playbooks/control-implementations/{id}/troubleshooting.md) - Common issues and resolutions
    ```

    Replace it with this INFO admonition format:

    ```markdown
    ## Implementation Playbooks

    !!! info "Step-by-Step Implementation"

        This control has detailed playbooks for implementation, automation, testing, and troubleshooting:

        - [Portal Walkthrough](../../playbooks/control-implementations/{id}/portal-walkthrough.md) — Step-by-step portal configuration
        - [PowerShell Setup](../../playbooks/control-implementations/{id}/powershell-setup.md) — Automation scripts
        - [Verification & Testing](../../playbooks/control-implementations/{id}/verification-testing.md) — Test cases and evidence collection
        - [Troubleshooting](../../playbooks/control-implementations/{id}/troubleshooting.md) — Common issues and resolutions
    ```

    Key details:
    - Section heading changes from `## Implementation Guides` to `## Implementation Playbooks`
    - The blockquote line and bullet list are replaced by the `!!! info` admonition
    - All lines inside the admonition are indented with 4 spaces
    - Use em-dash (—) not hyphen (-) as separator between link text and description
    - Preserve the `{id}` as the actual control number (1.1, 1.2, etc.) — the relative paths already exist and work
    - Read each file first before editing to get the exact old_string match (some files may have slight variations in the blockquote or bullet text)
    - The `---` separator lines above and below the section should be preserved
  </action>
