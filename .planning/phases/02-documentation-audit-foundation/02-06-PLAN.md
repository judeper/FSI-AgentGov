Read AUDIT-PILLAR-1.md and the 02-05-SUMMARY.md (which contains any user exclusions or adjustments).

For each Critical and Moderate finding:
1. Read the affected file(s)
2. Locate the specific content flagged in the finding
3. Apply the correction specified in "Should Say"
4. If Microsoft renamed or removed a capability, add a transition note (e.g., "Previously known as X" or "Replaced by Y in [date]")
5. Verify the correction makes sense in context (don't blindly apply — read surrounding paragraphs)

**Correction categories to apply:**
- **Content accuracy:** Update factually incorrect statements to match current Microsoft Learn documentation
- **Regulatory citations:** Fix imprecise or inaccurate regulation references to include specific subsections
- **Microsoft Learn URLs:** Replace broken/redirected URLs with current equivalents; remove if no equivalent exists
- **Role naming:** Replace non-canonical role names with canonical versions from role-catalog.md
- **Language compliance:** Replace prohibited phrases with approved alternatives
- **PowerShell cmdlets:** Update deprecated cmdlets in playbooks to current equivalents

**Do NOT apply:**
- Any findings the user excluded in 02-05-SUMMARY.md
- New features or capabilities not currently documented (that's Phase 4 scope)
- New controls or playbooks (out of audit scope)
