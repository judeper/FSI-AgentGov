Audit all 21 Pillar 2 controls (docs/controls/pillar-2-management/2.1-*.md through 2.21-*.md) and their 84 playbooks (docs/playbooks/control-implementations/2.1/ through 2.21/) for structural and formatting issues.

**Step 1 — Run structural validation:**
Run `python scripts/verify_controls.py` and capture output. Record any Pillar 2 failures.

**Step 2 — Check 10-section template compliance for each control:**
Read each control file. Verify all 10 required sections exist in correct order:
1. Objective, 2. Why This Matters for FSI, 3. Control Description, 4. Key Configuration Points, 5. Zone-Specific Requirements, 6. Roles & Responsibilities, 7. Related Controls, 8. Implementation Guides, 9. Verification Criteria, 10. Additional Resources

Also verify header metadata block and footer metadata.

**Step 3 — Check formatting consistency:**
Use grep to scan all Pillar 2 controls for:
- Admonition usage patterns (grep for "^!!!")
- Blockquote usage (grep for "^>")
- Table formatting consistency
- Code block language identifiers
- Link patterns

Apply the same formatting standard as Pillar 1 audit (derived from controls 2.1, 3.1, 1.1).

**Step 4 — Scan all 84 Pillar 2 playbooks:**
For each control's 4 playbooks:
- Verify file exists and is non-empty
- Check for consistent heading structure
- Verify PowerShell cmdlets are current (Microsoft.Graph not AzureAD)
- Check portal navigation paths reference current admin centers
- Flag deprecated patterns

**Step 5 — Begin writing AUDIT-PILLAR-2.md:**
Start the audit report with structural and formatting findings. Classify as Critical/Moderate/Minor.

**Special attention for Pillar 2:**
- Control 2.1 (Managed Environments): Already has Phase 1 updates (pipeline deadline). Verify these were applied correctly.
- Control 2.6 (Model Risk Management): Complex OCC/Fed SR references need careful citation verification.
- Control 2.12 (FINRA 3110): Primary FINRA supervision control — citations are critical.
- Controls 2.16-2.21 (newer controls): May have less formatting consistency than older controls.
