## Goal

## Tasks

### Task 1: Create Get-EnvironmentAccessSettings.ps1

Create `scripts/Get-EnvironmentAccessSettings.ps1`:

```powershell
<#
.SYNOPSIS
    Queries Power Platform environments and retrieves agent access settings.

.DESCRIPTION
    Enumerates all Power Platform environments accessible to the current user
    and extracts agent access configuration from governanceConfiguration.settings.extendedSettings.
    
    Supports filtering by environment type, creation date (grace period), and naming patterns.

.PARAMETER IncludeEnvironments
    Array of environment IDs or display names to include. Mutually exclusive with ExcludeEnvironments.

.PARAMETER ExcludeEnvironments
    Array of environment IDs or display names to exclude. Mutually exclusive with IncludeEnvironments.

.PARAMETER ExcludeSandbox
    Exclude Sandbox environment types from results.

.PARAMETER ExcludeDefault
    Exclude the Default environment from results.

.PARAMETER ExcludeTrial
    Exclude Trial environment types from results.

.PARAMETER GracePeriodHours
    Exclude environments created within this many hours (default: 48).

.PARAMETER DataverseUrl
    Optional Dataverse environment URL for zone classification lookup via ELM.

.EXAMPLE
    Get-EnvironmentAccessSettings -ExcludeSandbox -ExcludeTrial
    
    Queries all environments except sandbox and trial types.

.EXAMPLE
    Get-EnvironmentAccessSettings -GracePeriodHours 24 -DataverseUrl "https://org.crm.dynamics.com"
    
    Queries environments created more than 24 hours ago with ELM zone lookup.
#>
#Requires -Modules Microsoft.PowerApps.Administration.PowerShell

[CmdletBinding()]
param(
    [Parameter()]
    [string[]]$IncludeEnvironments,
    
    [Parameter()]
    [string[]]$ExcludeEnvironments,
    
    [Parameter()]
    [switch]$ExcludeSandbox,
    
    [Parameter()]
    [switch]$ExcludeDefault,
    
    [Parameter()]
    [switch]$ExcludeTrial,
    
    [Parameter()]
    [ValidateRange(0, 168)]
    [int]$GracePeriodHours = 48,
    
    [Parameter()]
    [string]$DataverseUrl,
    
    [Parameter()]
    [string]$AccessToken
)

# Import private helpers
. "$PSScriptRoot/private/Get-ZoneClassification.ps1"
. "$PSScriptRoot/private/Test-ParameterValidation.ps1"

# Validate parameters
if ($IncludeEnvironments -and $ExcludeEnvironments) {
    throw "IncludeEnvironments and ExcludeEnvironments are mutually exclusive."
}

# Get all environments
Write-Verbose "Querying Power Platform environments..."
$environments = Get-AdminPowerAppEnvironment

# Apply filters
$filteredEnvs = $environments | Where-Object {
    $include = $true
    
    # Inclusion filter
    if ($IncludeEnvironments) {
        $include = ($_.EnvironmentName -in $IncludeEnvironments) -or 
                   ($_.DisplayName -in $IncludeEnvironments)
    }
    
    # Exclusion filter
    if ($ExcludeEnvironments) {
        $include = $include -and 
                   ($_.EnvironmentName -notin $ExcludeEnvironments) -and
                   ($_.DisplayName -notin $ExcludeEnvironments)
    }
    
    # Type filters
    if ($ExcludeSandbox -and $_.EnvironmentType -eq 'Sandbox') { $include = $false }
    if ($ExcludeDefault -and $_.EnvironmentType -eq 'Default') { $include = $false }
    if ($ExcludeTrial -and $_.EnvironmentType -eq 'Trial') { $include = $false }
    
    # Grace period filter
    if ($GracePeriodHours -gt 0) {
        $createdDate = [datetime]$_.CreatedTime
        $graceCutoff = (Get-Date).AddHours(-$GracePeriodHours)
        if ($createdDate -gt $graceCutoff) { $include = $false }
    }
    
    $include
}

Write-Verbose "Found $($filteredEnvs.Count) environments after filtering"

# Extract settings for each environment
$results = foreach ($env in $filteredEnvs) {
    $extendedSettings = $env.governanceConfiguration.settings.extendedSettings
    
    # Get zone classification
    $zone = Get-ZoneClassification -EnvironmentId $env.EnvironmentName `
                                   -EnvironmentDisplayName $env.DisplayName `
                                   -DataverseUrl $DataverseUrl `
                                   -AccessToken $AccessToken
    
    [PSCustomObject]@{
        EnvironmentId              = $env.EnvironmentName
        EnvironmentDisplayName     = $env.DisplayName
        EnvironmentType            = $env.EnvironmentType
        CreatedTime                = $env.CreatedTime
        Zone                       = $zone
        BotLimitSharingMode        = $extendedSettings.'bot-limitSharingMode'
        BotAuthoringSharingDisabled = [bool]$extendedSettings.'bot-authoringSharingDisabled'
        BotPublishedLimitSharingMode = $extendedSettings.'bot-publishedBotLimitSharingMode'
        RawSettings                = $extendedSettings
    }
}

$results
```

**Acceptance Criteria:**
- [ ] Queries all environments using Get-AdminPowerAppEnvironment
- [ ] Extracts bot-* settings from extendedSettings
- [ ] Applies all filter types (include/exclude, type, grace period)
- [ ] Includes zone classification for each environment
- [ ] Returns structured PSCustomObject array

### Task 2: Create Compare-ZoneCompliance.ps1

Create `scripts/Compare-ZoneCompliance.ps1`:

```powershell
<#
.SYNOPSIS
    Compares environment agent access settings against zone-specific requirements.

.DESCRIPTION
    Takes environment settings from Get-EnvironmentAccessSettings.ps1 and compares
    them against expected values per governance zone. Returns violations with
    severity classification and regulatory context.

.PARAMETER EnvironmentSettings
    Array of environment settings objects from Get-EnvironmentAccessSettings.ps1.
    Can also be piped.

.PARAMETER BaselinePath
    Path to zone-settings-baseline.json. Defaults to ../templates/zone-settings-baseline.json.

.PARAMETER IncludeCompliant
    Include compliant environments in output (default: violations only).

.EXAMPLE
    Get-EnvironmentAccessSettings | Compare-ZoneCompliance
    
    Compares all environments against zone requirements.

.EXAMPLE
    $settings = Get-EnvironmentAccessSettings -ExcludeSandbox
    Compare-ZoneCompliance -EnvironmentSettings $settings -IncludeCompliant
    
    Compares with compliant environments included in output.
#>

[CmdletBinding()]
param(
    [Parameter(Mandatory, ValueFromPipeline)]
    [PSObject[]]$EnvironmentSettings,
    
    [Parameter()]
    [string]$BaselinePath = "$PSScriptRoot/../templates/zone-settings-baseline.json",
    
    [Parameter()]
    [switch]$IncludeCompliant
)

begin {
    # Load baseline
    if (-not (Test-Path $BaselinePath)) {
        throw "Baseline file not found: $BaselinePath"
    }
    $baseline = Get-Content $BaselinePath | ConvertFrom-Json
    
    $results = @()
}

process {
    foreach ($env in $EnvironmentSettings) {
        $zone = $env.Zone
        $zoneConfig = $baseline.zones.$zone
        
        if (-not $zoneConfig) {
            Write-Warning "No zone configuration for: $zone"
            $zoneConfig = $baseline.zones.Unknown
        }
        
        $violations = @()
        $isCompliant = $true
        
        # Check each expected setting
        foreach ($setting in $zoneConfig.expected.PSObject.Properties) {
            $settingName = $setting.Name
            $expectedValue = $setting.Value
            
            # Map setting name to property
            $actualValue = switch ($settingName) {
                'bot-limitSharingMode' { $env.BotLimitSharingMode }
                'bot-authoringSharingDisabled' { $env.BotAuthoringSharingDisabled }
                'bot-publishedBotLimitSharingMode' { $env.BotPublishedLimitSharingMode }
            }
            
            if ($actualValue -ne $expectedValue) {
                $isCompliant = $false
                $violationKey = "${settingName}_${actualValue}"
                $severity = $zoneConfig.violations.$violationKey
                if (-not $severity) { $severity = 'Warning' }
                
                $violations += [PSCustomObject]@{
                    Setting       = $settingName
                    Expected      = $expectedValue
                    Actual        = $actualValue
                    Severity      = $severity
                    RegulatoryContext = $baseline.regulatory_context.$severity
                }
            }
        }
        
        # Handle unknown zone
        if ($zone -eq 'Unknown') {
            $isCompliant = $false
            $violations += [PSCustomObject]@{
                Setting       = 'Zone Classification'
                Expected      = 'Zone1, Zone2, or Zone3'
                Actual        = 'Unknown'
                Severity      = 'Warning'
                RegulatoryContext = $baseline.regulatory_context.Warning
            }
        }
        
        # Add to results if violation or IncludeCompliant
        if (-not $isCompliant -or $IncludeCompliant) {
            $results += [PSCustomObject]@{
                EnvironmentId          = $env.EnvironmentId
                EnvironmentDisplayName = $env.EnvironmentDisplayName
                EnvironmentType        = $env.EnvironmentType
                Zone                   = $zone
                IsCompliant            = $isCompliant
                ViolationCount         = $violations.Count
                HighestSeverity        = ($violations | Sort-Object { 
                    switch ($_.Severity) { 'Critical' { 0 } 'High' { 1 } 'Warning' { 2 } 'Info' { 3 } default { 4 } }
                } | Select-Object -First 1).Severity
                Violations             = $violations
            }
        }
    }
}

end {
    $results
}
```

**Acceptance Criteria:**
- [ ] Accepts pipeline input from Get-EnvironmentAccessSettings
- [ ] Loads zone baseline from JSON file
- [ ] Compares each setting against expected values
- [ ] Classifies violations by severity from baseline
- [ ] Includes regulatory context for each violation
- [ ] Handles unknown zones with Warning severity
- [ ] Returns structured violation report

### Task 4: Add severity classification helper

Create `scripts/private/Get-ExpectedSettings.ps1`:

```powershell
<#
.SYNOPSIS
    Retrieves expected settings and severity mappings for a zone.
.DESCRIPTION
    Loads zone configuration from baseline JSON and provides helper methods
    for comparing settings and determining violation severity.
#>
function Get-ExpectedSettings {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]
        [ValidateSet('Zone1', 'Zone2', 'Zone3', 'Unknown')]
        [string]$Zone,
        
        [Parameter()]
        [string]$BaselinePath = "$PSScriptRoot/../../templates/zone-settings-baseline.json"
    )
    
    $baseline = Get-Content $BaselinePath | ConvertFrom-Json
    $zoneConfig = $baseline.zones.$Zone
    
    [PSCustomObject]@{
        Zone          = $Zone
        Description   = $zoneConfig.description
        Expected      = $zoneConfig.expected
        Violations    = $zoneConfig.violations
        GetSeverity   = {
            param([string]$SettingKey, [string]$ActualValue)
            $key = "${SettingKey}_${ActualValue}"
            $this.Violations.$key ?? 'Warning'
        }.GetNewClosure()
    }
}
```

**Acceptance Criteria:**
- [ ] Loads zone configuration from baseline
- [ ] Returns structured settings object
- [ ] Includes GetSeverity method for lookup
- [ ] Handles missing violation mappings with Warning default
