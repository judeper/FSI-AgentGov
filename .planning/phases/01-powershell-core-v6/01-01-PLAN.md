### Task 3: Create zone lookup helper

Create `scripts/private/Get-ZoneClassification.ps1`:

```powershell
<#
.SYNOPSIS
    Retrieves zone classification for a Power Platform environment.
.DESCRIPTION
    Looks up zone classification via:
    1. ELM Dataverse table (fsi_environment) if -DataverseUrl provided
    2. Naming convention fallback (-z1-, -z2-, -z3- in display name)
    3. Returns 'Unknown' if neither method resolves
#>
function Get-ZoneClassification {
    [CmdletBinding()]
    param(
        [Parameter(Mandatory)]
        [string]$EnvironmentId,
        
        [Parameter(Mandatory)]
        [string]$EnvironmentDisplayName,
        
        [Parameter()]
        [string]$DataverseUrl,
        
        [Parameter()]
        [string]$AccessToken
    )
    
    # Implementation:
    # 1. Try ELM lookup if DataverseUrl provided
    # 2. Fall back to naming convention
    # 3. Return 'Unknown' if no match
}
```

**Acceptance Criteria:**
- [ ] ELM Dataverse lookup when DataverseUrl provided
- [ ] Naming convention fallback (-z1-, -z2-, -z3-, Zone1, Zone2, Zone3)
- [ ] Returns 'Unknown' for unclassified environments
- [ ] Includes verbose output for debugging
