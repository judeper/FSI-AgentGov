# Plan 01-03: Test-AgentAccessCompliance.ps1 validation orchestrator

## Goal

Create the main orchestrator script that combines environment querying, zone compliance comparison, and reporting into a single validation workflow with dry-run mode and multiple output formats.

## Tasks

### Task 1: Create Test-AgentAccessCompliance.ps1

Create `scripts/Test-AgentAccessCompliance.ps1`:

```powershell
<#
.SYNOPSIS
    Validates Power Platform environment agent access settings against governance zone requirements.

.DESCRIPTION
    Orchestrates the full agent access compliance validation workflow:
    1. Queries all Power Platform environments for agent access settings
    2. Determines zone classification for each environment
    3. Compares settings against zone-specific requirements
    4. Reports violations with severity and regulatory context
    
    Supports dry-run mode for safe previewing without persisting results.

.PARAMETER ExcludeSandbox
    Exclude Sandbox environment types from validation.

.PARAMETER ExcludeTrial
    Exclude Trial environment types from validation.

.PARAMETER ExcludeDefault
    Exclude the Default environment from validation.

.PARAMETER GracePeriodHours
    Exclude environments created within this many hours (default: 48).

.PARAMETER DataverseUrl
    Optional Dataverse URL for ELM zone lookup and result persistence.

.PARAMETER WhatIf
    Dry-run mode: preview validation results without persisting to Dataverse.

.PARAMETER OutputFormat
    Output format: Table (default), JSON, or Object.

.PARAMETER IncludeCompliant
    Include compliant environments in output (default: violations only).

.EXAMPLE
    Test-AgentAccessCompliance -ExcludeSandbox -WhatIf
    
    Dry-run validation excluding sandbox environments.

.EXAMPLE
    Test-AgentAccessCompliance -OutputFormat JSON | Out-File compliance-report.json
    
    Full validation with JSON output for archival.

.EXAMPLE
    Test-AgentAccessCompliance -DataverseUrl "https://org.crm.dynamics.com" -IncludeCompliant
    
    Full validation with ELM zone lookup and all environments in output.
#>
#Requires -Modules Microsoft.PowerApps.Administration.PowerShell

[CmdletBinding(SupportsShouldProcess)]
param(
    [Parameter()]
    [switch]$ExcludeSandbox,
    
    [Parameter()]
    [switch]$ExcludeTrial,
    
    [Parameter()]
    [switch]$ExcludeDefault,
    
    [Parameter()]
    [ValidateRange(0, 168)]
    [int]$GracePeriodHours = 48,
    
    [Parameter()]
    [string]$DataverseUrl,
    
    [Parameter()]
    [ValidateSet('Table', 'JSON', 'Object')]
    [string]$OutputFormat = 'Table',
    
    [Parameter()]
    [switch]$IncludeCompliant,
    
    [Parameter()]
    [string]$BaselinePath
)

# Script setup
$ErrorActionPreference = 'Stop'
$startTime = Get-Date

# Import dependencies
. "$PSScriptRoot/Get-EnvironmentAccessSettings.ps1"
. "$PSScriptRoot/Compare-ZoneCompliance.ps1"

Write-Verbose "Starting Agent Access Compliance validation..."
Write-Verbose "WhatIf mode: $WhatIfPreference"

#region Query Environments

$queryParams = @{
    ExcludeSandbox    = $ExcludeSandbox
    ExcludeTrial      = $ExcludeTrial
    ExcludeDefault    = $ExcludeDefault
    GracePeriodHours  = $GracePeriodHours
}

if ($DataverseUrl) {
    $queryParams['DataverseUrl'] = $DataverseUrl
}

Write-Verbose "Querying environments with filters: $($queryParams | ConvertTo-Json -Compress)"

$environments = Get-EnvironmentAccessSettings @queryParams

if (-not $environments) {
    Write-Warning "No environments found matching criteria."
    return
}

Write-Verbose "Retrieved $($environments.Count) environments"

#endregion

#region Compare Zone Compliance

$comparisonParams = @{
    EnvironmentSettings = $environments
    IncludeCompliant    = $IncludeCompliant
}

if ($BaselinePath) {
    $comparisonParams['BaselinePath'] = $BaselinePath
}

$complianceResults = Compare-ZoneCompliance @comparisonParams

#endregion

#region Generate Summary

$summary = [PSCustomObject]@{
    ValidationTime      = $startTime
    TotalEnvironments   = $environments.Count
    CompliantCount      = ($environments.Count - $complianceResults.Where({ -not $_.IsCompliant }).Count)
    ViolationCount      = $complianceResults.Where({ -not $_.IsCompliant }).Count
    CriticalViolations  = ($complianceResults.Violations | Where-Object Severity -eq 'Critical').Count
    HighViolations      = ($complianceResults.Violations | Where-Object Severity -eq 'High').Count
    WarningViolations   = ($complianceResults.Violations | Where-Object Severity -eq 'Warning').Count
    InfoViolations      = ($complianceResults.Violations | Where-Object Severity -eq 'Info').Count
    ZoneSummary         = @{
        Zone1 = @{
            Total     = ($environments | Where-Object Zone -eq 'Zone1').Count
            Compliant = ($environments | Where-Object Zone -eq 'Zone1').Count - 
                       ($complianceResults | Where-Object { $_.Zone -eq 'Zone1' -and -not $_.IsCompliant }).Count
        }
        Zone2 = @{
            Total     = ($environments | Where-Object Zone -eq 'Zone2').Count
            Compliant = ($environments | Where-Object Zone -eq 'Zone2').Count - 
                       ($complianceResults | Where-Object { $_.Zone -eq 'Zone2' -and -not $_.IsCompliant }).Count
        }
        Zone3 = @{
            Total     = ($environments | Where-Object Zone -eq 'Zone3').Count
            Compliant = ($environments | Where-Object Zone -eq 'Zone3').Count - 
                       ($complianceResults | Where-Object { $_.Zone -eq 'Zone3' -and -not $_.IsCompliant }).Count
        }
        Unknown = @{
            Total = ($environments | Where-Object Zone -eq 'Unknown').Count
        }
    }
    OverallStatus       = if ($complianceResults.Where({ $_.HighestSeverity -eq 'Critical' }).Count -gt 0) { 'Failed' }
                          elseif ($complianceResults.Where({ $_.HighestSeverity -eq 'High' }).Count -gt 0) { 'Warning' }
                          elseif ($complianceResults.Where({ -not $_.IsCompliant }).Count -gt 0) { 'Review' }
                          else { 'Passed' }
    Duration            = (Get-Date) - $startTime
}

#endregion

#region Output Results

$output = [PSCustomObject]@{
    Summary           = $summary
    Violations        = $complianceResults | Where-Object { -not $_.IsCompliant }
    CompliantIfShown  = if ($IncludeCompliant) { $complianceResults | Where-Object IsCompliant } else { $null }
}

switch ($OutputFormat) {
    'JSON' {
        $output | ConvertTo-Json -Depth 10
    }
    'Object' {
        $output
    }
    'Table' {
        # Summary header
        Write-Host "`n=== Agent Access Compliance Report ===" -ForegroundColor Cyan
        Write-Host "Validation Time: $($summary.ValidationTime)"
        Write-Host "Total Environments: $($summary.TotalEnvironments)"
        Write-Host "Overall Status: " -NoNewline
        switch ($summary.OverallStatus) {
            'Failed'  { Write-Host $_ -ForegroundColor Red }
            'Warning' { Write-Host $_ -ForegroundColor Yellow }
            'Review'  { Write-Host $_ -ForegroundColor DarkYellow }
            'Passed'  { Write-Host $_ -ForegroundColor Green }
        }
        Write-Host ""
        
        # Zone summary table
        Write-Host "Zone Summary:" -ForegroundColor Cyan
        Write-Host "  Zone 1 (Personal):   $($summary.ZoneSummary.Zone1.Compliant)/$($summary.ZoneSummary.Zone1.Total) compliant"
        Write-Host "  Zone 2 (Team):       $($summary.ZoneSummary.Zone2.Compliant)/$($summary.ZoneSummary.Zone2.Total) compliant"
        Write-Host "  Zone 3 (Enterprise): $($summary.ZoneSummary.Zone3.Compliant)/$($summary.ZoneSummary.Zone3.Total) compliant"
        if ($summary.ZoneSummary.Unknown.Total -gt 0) {
            Write-Host "  Unknown:             $($summary.ZoneSummary.Unknown.Total) unclassified" -ForegroundColor Yellow
        }
        Write-Host ""
        
        # Violations by severity
        if ($summary.ViolationCount -gt 0) {
            Write-Host "Violations by Severity:" -ForegroundColor Cyan
            if ($summary.CriticalViolations -gt 0) {
                Write-Host "  Critical: $($summary.CriticalViolations)" -ForegroundColor Red
            }
            if ($summary.HighViolations -gt 0) {
                Write-Host "  High:     $($summary.HighViolations)" -ForegroundColor Yellow
            }
            if ($summary.WarningViolations -gt 0) {
                Write-Host "  Warning:  $($summary.WarningViolations)" -ForegroundColor DarkYellow
            }
            if ($summary.InfoViolations -gt 0) {
                Write-Host "  Info:     $($summary.InfoViolations)" -ForegroundColor Gray
            }
            Write-Host ""
            
            # Violation details
            Write-Host "Violation Details:" -ForegroundColor Cyan
            $output.Violations | ForEach-Object {
                $color = switch ($_.HighestSeverity) {
                    'Critical' { 'Red' }
                    'High'     { 'Yellow' }
                    'Warning'  { 'DarkYellow' }
                    'Info'     { 'Gray' }
                    default    { 'White' }
                }
                Write-Host "`n  [$($_.HighestSeverity)] $($_.EnvironmentDisplayName) (Zone: $($_.Zone))" -ForegroundColor $color
                foreach ($v in $_.Violations) {
                    Write-Host "    - $($v.Setting): Expected '$($v.Expected)', Found '$($v.Actual)'"
                    Write-Host "      Regulatory: $($v.RegulatoryContext)" -ForegroundColor DarkGray
                }
            }
        } else {
            Write-Host "No violations found. All environments comply with zone requirements." -ForegroundColor Green
        }
        
        Write-Host "`nDuration: $($summary.Duration.TotalSeconds.ToString('F2'))s" -ForegroundColor DarkGray
        
        # Return object for pipeline
        $output
    }
}

#endregion

#region Persist Results (if not WhatIf)

if (-not $WhatIfPreference -and $DataverseUrl) {
    if ($PSCmdlet.ShouldProcess("Dataverse at $DataverseUrl", "Write validation results")) {
        Write-Verbose "Persisting validation results to Dataverse..."
        # Dataverse persistence will be added in Phase 2
        Write-Warning "Dataverse persistence not yet implemented. Results shown but not saved."
    }
}

#endregion
```

```markdown
# Agent Access Governance Monitor

Automated validation of Power Platform environment agent access settings against zone-specific governance requirements.

## Quick Start

```powershell
# 1. Install required modules
Install-Module -Name Microsoft.PowerApps.Administration.PowerShell -Force

# 2. Connect to Power Platform
Add-PowerAppsAccount

# 3. Run validation (dry-run mode)
./scripts/Test-AgentAccessCompliance.ps1 -ExcludeSandbox -WhatIf

# 4. Run full validation
./scripts/Test-AgentAccessCompliance.ps1 -ExcludeSandbox
```

## Features

- **Zone Compliance Validation**: Validates agent access settings (sharing mode, authoring restrictions) against zone requirements
- **Multiple Output Formats**: Table (human-readable), JSON (archival), Object (pipeline)
- **Dry-Run Mode**: Preview violations without persisting results
- **Severity Classification**: Critical/High/Warning/Info per zone and violation type
- **Regulatory Context**: FINRA 4511, SOX 404 context for each violation
- **Environment Filtering**: Exclude sandbox, trial, default, or newly provisioned environments

## Zone Requirements

| Setting | Zone 1 | Zone 2 | Zone 3 |
|---------|--------|--------|--------|
| bot-limitSharingMode | noLimit | ExcludeSharingToSecurityGroups | ExcludeSharingToSecurityGroups |
| bot-authoringSharingDisabled | false | false | true |
| bot-publishedBotLimitSharingMode | noLimit | ExcludeSharingToSecurityGroups | ExcludeSharingToSecurityGroups |
