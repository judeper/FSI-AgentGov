# Plan 03-02: Teams Adaptive Card Template

## Objective

Create a Teams adaptive card template (JSON) for CA policy compliance alerts with severity badges, zone compliance summary, violation details, drift detection items, and action buttons — following the proven ACV/CMM/FUS card pattern.

## Requirements Covered

- **AUT-03**: Teams adaptive card alerts with severity classification (Zone 3 CRITICAL, Zone 2 HIGH, Zone 1 WARNING) and violation details

## Must-Haves Covered

| # | Must-Have | How |
|---|----------|-----|
| 3 | Teams adaptive card with zone-based severity classification | Card header shows severity badge (CRITICAL/HIGH/WARNING), zone summary table with per-zone pass/total, violation list with zone attribution |

## Tasks

### Task 1: Create adaptive card JSON
**File:** `src/adaptive-card-caa-alert.json`
- Adaptive Card schema v1.4
- All template variables use `${variableName}` syntax

### Task 2: Header section
- Title: `[ALERT] CA Policy Compliance — ${OverallStatus}`
- Severity badge with color mapping:
  - CRITICAL → attention (red)
  - HIGH/Failed → warning (orange)
  - WARNING → accent (yellow)
  - Passed → good (green)
- Subtitle: `Conditional Access Automation · ${CheckedAt}`

### Task 3: Run Summary section
- ColumnSet with key metrics:
  - Status: `${OverallStatus}`
  - Checked: `${CheckedAt}`
  - Total Policies: `${TotalPolicies}`
  - Passed: `${PassedCount}`
  - Failed: `${FailedCount}`
  - Drift Count: `${DriftCount}`
  - Compliance Rate: `${ComplianceRate}%`
  - Overall Severity: `${OverallSeverity}`

### Task 4: Zone Compliance table
- 3-row FactSet or table:
  - Zone 1 (Personal Productivity): `${Zone1Passed}/${Zone1Total}` — WARNING threshold
  - Zone 2 (Team Collaboration): `${Zone2Passed}/${Zone2Total}` — HIGH threshold
  - Zone 3 (Enterprise Managed): `${Zone3Passed}/${Zone3Total}` — CRITICAL threshold
- Color-coded severity indicators per zone

### Task 5: Violations section
- Container with violation items (conditionally visible when `${ViolationCount}` > 0)
- Per-violation row:
  - ViolationType badge (`PolicyDisabled`, `GrantControlRemoved`, etc.)
  - PolicyName: `${ViolationPolicyName}`
  - Zone: `${ViolationZone}`
  - Expected: `${ViolationExpected}`
  - Actual: `${ViolationActual}`
  - Severity: `${ViolationSeverity}`
  - Regulatory context: `${ViolationRegulatoryContext}`

### Task 6: Drift Detection section
- Container with drift items (conditionally visible when `${DriftCount}` > 0)
- Per-drift row:
  - DriftType badge
  - PolicyName: `${DriftPolicyName}`
  - Dimension: `${DriftDimension}` (state/conditions/grants/sessions)
  - Direction: `${DriftDirection}` (Weakened/Strengthened)
  - Zone: `${DriftZone}`

### Task 7: Action buttons
- `View in Entra Portal` → `https://entra.microsoft.com/#view/Microsoft_AAD_ConditionalAccess/ConditionalAccessBlade/~/Policies`
- `Run Manual Check` → link to Azure Automation runbook (parameterized URL)
- `View Documentation` → link to Control 1.11 docs page
