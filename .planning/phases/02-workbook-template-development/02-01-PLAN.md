# Plan 02-01: Workbook Shell + Usage & Business Value Tab + Performance & Errors Tab

**Phase:** 2 — Workbook Template Development
**Requirements:** WBK-01, WBK-02
**Wave:** 1 (no dependencies — foundational)

## Goal

Create the deployable Azure Monitor Workbook JSON file (`src/agent-usage-workbook.json`) with the complete workbook shell (metadata, global parameters, tab structure) and the first two tabs: Usage & Business Value (8 visualizations) and Performance & Errors (8 visualizations). All 16 KQL queries come from the Phase 1 KQL query library (Q01-Q16).

## Tasks

**Acceptance Criteria:**
- [x] Root structure: `$schema`, `version: "Notebook/1.0"`, `items[]`, `fallbackResourceIds[]`, `isLocked: false`

- [x] All parameter names match `{ParameterName}` references in KQL queries

- [x] Include descriptive labels for each parameter
