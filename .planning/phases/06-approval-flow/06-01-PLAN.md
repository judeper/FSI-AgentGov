# Phase 6, Plan 1: Approval Flow

## Goal

Create a Power Automate approval flow specification and JSON template for governance-approved remediation execution. The flow queries Dataverse for non-compliant environments, requests approval, then triggers the Enable-AuditLogging runbook.

## Tasks

### Task 1: Flow Template JSON
**Acceptance:** Complete Power Automate flow definition JSON with:
- Recurrence trigger (weekly, Monday 7:00 AM after detection at 6:00 AM)
- HTTP action to query Dataverse for non-compliant environments
- Condition check (count > 0)
- Approval action (Approve/Reject, governance lead, environment list)
- Azure Management API PUT to trigger runbook on approval
- Completion notification email
- Error handling scope for failed runbook execution
- Flow variables (DataverseUrl, TenantDomain, GovernanceLeadEmail, etc.)
- Authentication patterns (Dataverse connection + Azure Management MI)

**Files:** `FSI-AgentGov-Solutions/audit-logging-compliance-automation/src/audit-remediation-approval-flow.json`
