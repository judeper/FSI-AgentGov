# Plan 02-02: Environment Variables, Connection References, and deploy.py Orchestrator

## Goal

Deploy the operational configuration layer — environment variables that externalize runtime parameters, connection references for Power Automate integration, and the orchestrator script that runs the full deployment pipeline. Together with Plan 02-01, this completes the Python deployment infrastructure.

## Tasks

### Task 1: Create create_environment_variables.py

Create `content-moderation-monitor/scripts/create_environment_variables.py`.

**Environment Variables (fsi_CMM_* prefix):**

| Schema Name | Display Name | Type | Default | Purpose |
|------------|-------------|------|---------|---------|
| `fsi_CMM_GracePeriodHours` | CMM - Grace Period (Hours) | Decimal (100000001) | 48 | Hours to exclude newly provisioned environments |
| `fsi_CMM_ScanFrequencyHours` | CMM - Scan Frequency (Hours) | Decimal (100000001) | 24 | Automated scan interval |
| `fsi_CMM_IncludeSandbox` | CMM - Include Sandbox Environments | String (100000000) | false | Whether to include sandbox environments in validation |
| `fsi_CMM_IncludeDrafts` | CMM - Include Draft Agents | String (100000000) | false | Whether to include draft/unpublished agents |
| `fsi_CMM_BaselineMaxAgeDays` | CMM - Maximum Baseline Age (Days) | Decimal (100000001) | 30 | Alert threshold for stale agent baselines |
| `fsi_CMM_TeamsGroupId` | CMM - Teams Alert Group ID | String (100000000) | (blank) | Teams group GUID for violation alerts |
| `fsi_CMM_TeamsChannelId` | CMM - Teams Alert Channel ID | String (100000000) | (blank) | Teams channel GUID for violation alerts |

**Function signatures:**
- `ENV_VAR_DEFINITIONS` — list of dictionaries with schema_name, display_name, type, default_value, description
- `create_environment_variable(client, definition, dry_run)` — idempotent create with existence check
- `create_environment_variables(client, dry_run)` — iterate all definitions
- `main()` — CLI entry with auth args

**Idempotent pattern:**
```python
# Check existence
existing = client.query(
    "environmentvariabledefinitions",
    filter=f"schemaname eq '{schema_name}'"
)
if existing['value']:
    print(f"  {schema_name}: already exists, skipping")
else:
    # Create definition + default value
    definition = {
        "schemaname": schema_name,
        "displayname": display_name,
        "type": var_type,
        "defaultvalue": default_value,
        "description": description
    }
    client.create_record("environmentvariabledefinitions", definition)
```

**Acceptance Criteria:**
- [ ] 7 environment variables defined with correct Dataverse types
- [ ] Decimal type (100000001) for numeric values, String type (100000000) for text
- [ ] All variables use fsi_CMM_ prefix (matching Get-CMMEnvironmentVariable queries)
- [ ] Existence check before creation (idempotent)
- [ ] Dry-run mode previews without API calls
- [ ] `python create_environment_variables.py --dry-run` shows 7 variables

### Task 2: Create create_connection_references.py

Create `content-moderation-monitor/scripts/create_connection_references.py`.

**Connection References:**

| Logical Name | Display Name | Connector ID | Description |
|-------------|-------------|-------------|-------------|
| `fsi_cr_dataverse_moderationmonitor` | Dataverse - Content Moderation Monitor | `shared_commondataserviceforapps` | Core data operations (baselines, history, violations) |
| `fsi_cr_office365_moderationmonitor` | Office 365 - Content Moderation Monitor | `shared_office365` | Email alerts for critical moderation violations |
| `fsi_cr_teams_moderationmonitor` | Teams - Content Moderation Monitor | `shared_teams` | Teams adaptive card alerts |

**Function signatures:**
- `CONNECTION_REF_DEFINITIONS` — list of dictionaries with logical_name, display_name, connector_id, description
- `create_connection_reference(client, definition, dry_run)` — idempotent create
- `create_connection_references(client, dry_run)` — iterate all definitions
- `main()` — CLI entry with auth args

**Idempotent pattern:**
```python
existing = client.query(
    "connectionreferences",
    filter=f"connectionreferencelogicalname eq '{logical_name}'"
)
if existing['value']:
    print(f"  {logical_name}: already exists, skipping")
else:
    # Create connection reference definition
    client.create_record("connectionreferences", {
        "connectionreferencelogicalname": logical_name,
        "connectionreferencedisplayname": display_name,
        "connectorid": f"/providers/Microsoft.PowerApps/apis/{connector_id}",
        "description": description
    })
```

**Acceptance Criteria:**
- [ ] 3 connection references with fsi_cr_{connector}_{solution} naming
- [ ] Connector IDs match Power Platform connector API names
- [ ] Existence check before creation (idempotent)
- [ ] Dry-run mode works
- [ ] `python create_connection_references.py --dry-run` shows 3 references

### Task 3: Create deploy.py orchestrator

Create `content-moderation-monitor/scripts/deploy.py`.

**Orchestrator pipeline:**

```
deploy.py
├── Step 1: Test Connection (GET /api/data/v9.2/organizations)
├── Step 2: Dataverse Schema (create_dataverse_schema.create_schema)
│   ├── Shared option sets (fsi_acv_zone, fsi_acv_severity)
│   ├── fsi_ModerationBaseline (UserOwned)
│   ├── fsi_ModerationValidationHistory (OrganizationOwned)
│   └── fsi_ModerationViolation (UserOwned)
├── Step 3: Environment Variables (create_environment_variables.create_environment_variables)
│   └── 7 fsi_CMM_* variables
├── Step 4: Connection References (create_connection_references.create_connection_references)
│   └── 3 fsi_cr_*_moderationmonitor references
└── Post-Deployment Guidance
    ├── Security: Remove Write/Delete on fsi_ModerationValidationHistory
    ├── Connections: Bind connection references in Power Automate
    └── Verification: Run deploy.py --dry-run to confirm
```

**CLI arguments:**

| Argument | Type | Default | Purpose |
|----------|------|---------|---------|
| `--tenant-id` | string | CMM_TENANT_ID env var | Azure AD tenant |
| `--client-id` | string | CMM_CLIENT_ID env var | Service principal app ID |
| `--client-secret` | string | CMM_CLIENT_SECRET env var | Service principal secret |
| `--environment-url` | string | CMM_ENVIRONMENT_URL env var | Dataverse URL |
| `--interactive` | flag | false | Use interactive browser auth |
| `--dry-run` | flag | false | Preview all operations |
| `--tables-only` | flag | false | Deploy only Dataverse schema |
| `--vars-only` | flag | false | Deploy only environment variables |
| `--refs-only` | flag | false | Deploy only connection references |
| `--verbose` | flag | false | Detailed output |

**Selective deployment modes:**

| Mode | Operations |
|------|-----------|
| Default (no flags) | Schema → Env vars → Connection refs (full pipeline) |
| `--tables-only` | Schema only |
| `--vars-only` | Environment variables only |
| `--refs-only` | Connection references only |

**Post-deployment guidance output:**
```
═══════════════════════════════════════════════════════
Post-Deployment Steps
═══════════════════════════════════════════════════════

1. SECURITY — Configure fsi_ModerationValidationHistory security role:
   - Navigate to Settings > Security > Security Roles
   - Remove Write and Delete privileges for fsi_ModerationValidationHistory
   - This ensures immutable audit records (FINRA 4511, SEC 17a-3)

2. CONNECTIONS — Bind connection references in Power Automate:
   - fsi_cr_dataverse_moderationmonitor → Select Dataverse connection
   - fsi_cr_office365_moderationmonitor → Select Office 365 connection
   - fsi_cr_teams_moderationmonitor → Select Teams connection

3. VERIFY — Run dry-run to confirm deployment:
   python deploy.py --dry-run [--interactive | --client-id ...]
```

**Acceptance Criteria:**
- [ ] deploy.py orchestrates all three deployment scripts in correct order
- [ ] `--tables-only`, `--vars-only`, `--refs-only` modes work independently
- [ ] `--dry-run` previews all operations without Dataverse API calls
- [ ] Post-deployment guidance printed on success
- [ ] Connection test runs before any deployment
- [ ] Error handling: fail early with clear messages
- [ ] `python deploy.py --dry-run --interactive` completes full pipeline preview
