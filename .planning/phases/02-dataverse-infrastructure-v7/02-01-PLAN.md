# Plan 02-01: CMM Dataverse Client, Requirements, and Three-Table Schema Deployment

## Goal

Create the Python infrastructure foundation for the Content Moderation Governance Monitor — the shared Dataverse client, Python dependencies, and schema deployment script for three tables with shared option set reuse. This is the foundation all subsequent Phase 2 plans depend on.

## Tasks

### Task 1: Create cmm_client.py

Create `content-moderation-monitor/scripts/cmm_client.py` adapting the proven AAMClient pattern.

**Class CMMClient:**

| Method | Purpose |
|--------|---------|
| `__init__(tenant_id, environment_url, client_id, client_secret, interactive, dry_run)` | MSAL auth setup with retry strategy |
| `_get_token()` | Token acquisition: silent cache → interactive/SP fallback |
| `_get_headers()` | Authorization bearer, OData headers, Prefer annotations |
| `test_connection()` | GET organizations endpoint |
| `query(entity_set, select, filter, orderby, top)` | OData query with parameters |
| `create_record(entity_set, data)` | POST to entity set, extract ID from OData-EntityId header |
| `get_entity_metadata(logical_name)` | Table metadata lookup |
| `create_entity(definition)` | Create table from definition |
| `create_attribute(entity_name, definition)` | Create column |
| `get_attribute_metadata(entity_name, attribute)` | Column metadata lookup |
| `create_global_optionset(definition)` | Create global option set |
| `get_global_optionset(name)` | Option set metadata lookup |
| `check_table_exists(logical_name)` | Idempotent table existence check |
| `create_table(name, display, plural, description, ownership, columns)` | Idempotent table creation |
| `create_option_set(name, options)` | Idempotent option set creation |
| `create_column(entity, name, type, definition)` | Idempotent column creation |

**Environment variable prefix:** `CMM_` (CMM_TENANT_ID, CMM_ENVIRONMENT_URL, CMM_CLIENT_ID, CMM_CLIENT_SECRET)

**Retry strategy:** `Retry(total=3, backoff_factor=1, status_forcelist=[429, 500, 502, 503, 504])`

**CLI entry point:** `main()` with args: `--tenant-id`, `--client-id`, `--client-secret`, `--environment-url`, `--interactive`, `--test-connection`, `--dry-run`

**Acceptance Criteria:**
- [ ] CMMClient authenticates with MSAL (interactive + service principal modes)
- [ ] All mutating operations respect dry_run flag
- [ ] Retry strategy handles 429/5xx responses
- [ ] main() CLI entry point works standalone for testing
- [ ] Follows AAMClient structure exactly with CMM naming
- [ ] `python -c "from cmm_client import CMMClient; print('Import OK')"` passes

**Idempotent pattern:**
```python

existing = client.get_global_optionset("fsi_acv_zone")

    client.create_global_optionset(zone_definition)
```

```python

```
