# Phase 2, Plan 1: Dataverse Schema

## Goal

Create the `fsi_auditenvironmentcompliance` Dataverse table schema for audit environment compliance tracking, with a Python creation script and seed data documentation.

## Tasks

### Task 1: Create ALCA Dataverse Client (`alca_client.py`)
**Acceptance:** Mirrors ACV `acv_client.py` pattern — MSAL auth, retry logic, dry-run, entity/attribute/optionset CRUD, alternate key creation.
**Files:** `FSI-AgentGov-Solutions/audit-logging-compliance-automation/src/alca_client.py`

### Task 2: Create Schema Creation Script (`create_audit_compliance_schema.py`)
**Acceptance:** Defines:
- Global option set `fsi_alca_compliancestatus` (Compliant=100000000, Non-Compliant=100000001, Remediation Pending=100000002, Error=100000003)
- Table `fsi_AuditEnvironmentCompliance` (Org-owned, auditing enabled, primary column: fsi_environmentname)
- 10 columns per DVS-01 spec
- Alternate key on fsi_environmentid
- Seed data documentation printed at end
**Files:** `FSI-AgentGov-Solutions/audit-logging-compliance-automation/src/create_audit_compliance_schema.py`

### Task 3: Create Requirements File
**Acceptance:** Lists Python dependencies needed by creation script.
**Files:** `FSI-AgentGov-Solutions/audit-logging-compliance-automation/src/requirements.txt`
