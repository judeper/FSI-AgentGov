# Plan 01-02: Get-AgentModerationSettings.ps1 and Compare-ModerationCompliance.ps1

## Goal

Create the two core scripts that (1) enumerate Copilot Studio agents across Power Platform environments and retrieve their content moderation levels, and (2) compare those levels against zone-specific requirements with severity classification.

## Tasks

### Task 1: Create Get-AgentModerationSettings.ps1

Create `scripts/Get-AgentModerationSettings.ps1` — the primary data collection script that discovers all Copilot Studio agents and retrieves their content moderation configuration.

```powershell
<#
.SYNOPSIS
    Retrieves content moderation settings for all Copilot Studio agents across
    Power Platform environments.

.DESCRIPTION
    Enumerates Power Platform environments, connects to each environment's
    Dataverse instance, queries the bot table for Copilot Studio agents,
    and extracts the content moderation level from the agent's generative
    AI configuration.

    Unlike the Agent Access Monitor (v6) which queries environment-level settings,
    this script operates at agent granularity — one result per agent per environment.

.PARAMETER IncludeEnvironments
    Limit scan to specific environment IDs.

.PARAMETER ExcludeEnvironments
    Exclude specific environment IDs from scan.

.PARAMETER ExcludeSandbox
    Exclude sandbox environments.

.PARAMETER ExcludeTrial
    Exclude trial environments.

.PARAMETER ExcludeDefault
    Exclude the default environment.

.PARAMETER GracePeriodHours
    Exclude environments created within this many hours (default: 48).

.PARAMETER IncludeDrafts
    Include draft/unpublished agents (default: published only).

.PARAMETER DataverseUrl
    Optional ELM Dataverse URL for zone classification lookup.

.PARAMETER Top
    Limit total results returned (safety cap for large tenants).

.OUTPUTS
    PSCustomObject[] — One object per agent with properties:
    AgentId, AgentName, AgentStatus, ContentModerationLevel,
    EnvironmentId, EnvironmentDisplayName, EnvironmentType,
    Zone, DataverseUrl, LastPublished, RetrievedAt
#>
#Requires -Modules Microsoft.PowerApps.Administration.PowerShell
function Get-AgentModerationSettings {
    [CmdletBinding()]
    param(
        [string[]]$IncludeEnvironments,
        [string[]]$ExcludeEnvironments,
        [switch]$ExcludeSandbox,
        [switch]$ExcludeTrial,
        [switch]$ExcludeDefault,
        [int]$GracePeriodHours = 48,
        [switch]$IncludeDrafts,
        [string]$DataverseUrl,
        [int]$Top = 0
    )

    # Implementation flow:
    # 1. Validate parameters via Test-ParameterValidation
    # 2. Get-AdminPowerAppEnvironment → filter by type/age/include/exclude
    # 3. Filter to environments WITH Dataverse instances
    # 4. For each environment:
    #    a. Connect-EnvironmentDataverse → get access token
    #    b. GET /api/data/v9.2/bots?$select=botid,name,statecode,statuscode,
    #       configuration,publishedon&$filter=statecode eq 0
    #    c. For each bot: extract moderation level via Get-BotModerationLevel
    #    d. Get-ZoneClassification for the environment
    #    e. Emit PSCustomObject per agent
    # 5. Apply -Top cap if specified
    # 6. Return results array
}
```

**Key implementation details:**
- Environments without Dataverse (`linkedEnvironmentMetadata` absent) are skipped with `-Verbose` logging
- OData `$select` limits columns to: `botid`, `name`, `statecode`, `statuscode`, `configuration`, `publishedon`
- OData `$filter` defaults to `statecode eq 0` (active bots); `-IncludeDrafts` adds `statuscode` filter variations
- `Get-BotModerationLevel` from CMMClient.psm1 handles normalization of internal moderation values
- Failed environment connections emit `Write-Warning` and continue (don't abort entire scan)
- Progress reporting via `Write-Progress` for multi-environment scans

**Acceptance Criteria:**
- [ ] Enumerates all environments using Get-AdminPowerAppEnvironment (CMV-01)
- [ ] Skips environments without Dataverse instances
- [ ] Queries bot table per environment via Dataverse Web API
- [ ] Extracts content moderation level from bot configuration
- [ ] Returns per-agent PSCustomObject with full schema
- [ ] Supports IncludeEnvironments/ExcludeEnvironments filters
- [ ] Supports ExcludeSandbox/ExcludeTrial/ExcludeDefault
- [ ] Supports GracePeriodHours to skip newly created environments
- [ ] IncludeDrafts toggles published-only vs. all agents (CMV-05)
- [ ] Top parameter caps total output for large tenants
- [ ] Failed environment connections warn and continue (resilient)
- [ ] Progress bar for multi-environment scans
