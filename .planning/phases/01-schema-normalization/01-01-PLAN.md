## Goal

Create a definitive reference document that establishes the canonical option set values used across all solutions as the cross-solution standard, plus a per-solution mapping table that translates each Tier 2 solution's validation output into Compliance Dashboard `fsi_controlassessment.fsi_status` values.

## Tasks

### 1. Create SCHEMA_CONTRACT.md in cross-solution-integration/docs/

Document the canonical option set contract:

**Zone Option Set (`fsi_acv_zone`):**
- 1 = Zone 1 (Personal Productivity)
- 2 = Zone 2 (Team Collaboration)
- 3 = Zone 3 (Enterprise Managed)

**Severity Option Set (`fsi_acv_severity`):**
- 1 = Passed
- 2 = Warning
- 3 = GracePeriod
- 4 = Failed
- 5 = Error

**Note:** ACV internally may use 100000001/100000002/100000003 for zone values but the integration layer normalizes to 1/2/3.

### 2. Create STATUS_MAPPING.md in cross-solution-integration/docs/

Per-solution mapping:

| Solution | Source Table | Source Field | Source Values | → CD fsi_status | Logic |
|----------|-------------|--------------|---------------|------------------|-------|
| ACV | fsi_auditvalidationhistory | fsi_severity | Passed → Compliant; Warning/Grace → Partial; Failed/Error → Non-Compliant | 1/2/3 | Worst-severity from latest run |
| SSC | fsi_validationhistory | fsi_severity | Same mapping | 1/2/3 | Orchestrator-level severity |
| AAM | fsi_accessvalidationhistory | fsi_overall_status | Compliant → 1; Warning → 2; NonCompliant/Critical → 3 | 1/2/3 | Direct string mapping |
| CMM | fsi_moderationvalidationhistory | fsi_overall_status | compliance_rate >= 100% → 1; >= 80% → 2; < 80% → 3 | 1/2/3 | Percentage threshold |
| FUS | fsi_fileupload_validationhistory | fsi_compliance_rate | Same thresholds as CMM | 1/2/3 | Percentage threshold |

Also define:
- Solution-to-control mapping (ACV→1.7, SSC→1.23+1.11, AAM→3.8, CMM→1.8, FUS→1.14)
- `fsi_score` derivation: Compliant=100, Partial=50, Non-Compliant=0
- Evidence type: 5 (Test Result) for all automated assessments
