## Goal

Create a shared PowerShell module that provides canonical mappings, table configurations, and translation functions used by the Sync-SolutionAssessments.ps1 script and unified evidence export.

## Tasks

### 1. Create IntegrationConfig.psm1

Functions:
- `Get-SolutionControlMapping` — returns hashtable of solution → control IDs
- `ConvertTo-DashboardStatus` — translates solution-specific severity/status to CD fsi_status (1/2/3)
- `Get-SolutionTableConfig` — returns table schema names, key columns, and query patterns per solution
- `Get-EvidenceTypeId` — returns evidence type choice value for automated assessments
- `Get-CanonicalZoneValue` — normalizes zone values (handles both 1/2/3 and 100000001 formats)

### 2. Module manifest (IntegrationConfig.psd1)

Standard PowerShell module manifest exporting all functions.

### Acceptance Criteria

- [ ] Module loads without errors
- [ ] All 5 solutions have entries in every mapping function
- [ ] ConvertTo-DashboardStatus handles all known status values per solution
- [ ] Zone value normalization handles both numbering schemes
