## Tasks

### Task 1: Create verify_language_rules.py

**File:** `scripts/verify_language_rules.py` (CREATE)

**Acceptance Criteria:**
- Scans all `docs/**/*.md` files recursively
- Excludes `docs/templates/` directory (template contains placeholder text)
- Detects prohibited phrases (case-insensitive):
  - "ensures compliance"
  - "guarantees" (standalone or in phrases like "guarantees compliance")
  - "will prevent"
  - "eliminates risk"
  - "eliminates the need for"
- Reports: file path, line number, matched phrase
- Exits with code 0 if no violations, code 1 if any found
- Follows existing script patterns: uses `Path`, `re`, `sys`
- Includes Windows UTF-8 encoding fix (`sys.stdout.reconfigure`)
- Prints summary count at end

**Implementation Notes:**
- Use compiled regex patterns for performance
- Case-insensitive matching via `re.IGNORECASE`
- Process files alphabetically for deterministic output
- Skip non-text files gracefully (handle encoding errors)

```python
# Pattern structure:
PROHIBITED_PATTERNS = [
    (re.compile(r'\bensures?\s+compliance\b', re.IGNORECASE), "ensures compliance"),
    (re.compile(r'\bguarantees?\b', re.IGNORECASE), "guarantees"),
    (re.compile(r'\bwill\s+prevent\b', re.IGNORECASE), "will prevent"),
    (re.compile(r'\beliminates?\s+risk\b', re.IGNORECASE), "eliminates risk"),
    (re.compile(r'\beliminates?\s+the\s+need\s+for\b', re.IGNORECASE), "eliminates the need for"),
]
```

**Validation:**
```bash
python scripts/verify_language_rules.py
# Expected: exit 0 (no violations in current docs)
```

### Task 2: Add CI validation steps to publish_docs.yml

**File:** `.github/workflows/publish_docs.yml` (MODIFY)

**Acceptance Criteria:**
- New step "Validate Control Structure" runs `python scripts/verify_controls.py` 
- New step "Validate Language Rules" runs `python scripts/verify_language_rules.py`
- Both steps run after Python setup and MkDocs install
- Both steps run before `mkdocs build --strict`
- Build fails if either validation fails

**Implementation Notes:**
- Insert two new steps after the "Install MkDocs and Material Theme" step
- Place before "Validate Documentation" (`mkdocs build --strict`) step
- Scripts use only stdlib — no additional pip installs needed for verify_controls.py or verify_language_rules.py

**Change:**
```yaml
      - name: Validate Control Structure
        run: python scripts/verify_controls.py

      - name: Validate Language Rules
        run: python scripts/verify_language_rules.py
```

**Validation:**
```bash
# Locally verify both scripts exit 0:
python scripts/verify_controls.py
python scripts/verify_language_rules.py
mkdocs build --strict
```
