### Task 3: Add playbook existence check to verify_controls.py

**File:** `scripts/verify_controls.py` (MODIFY)

**Acceptance Criteria:**
- New function `validate_playbook_files(control_id)` checks existence of 4 standard playbook files
- Called during control validation loop
- Reports missing playbook files as validation failures
- 4 required files: `portal-walkthrough.md`, `powershell-setup.md`, `verification-testing.md`, `troubleshooting.md`
- Expected directory: `docs/playbooks/control-implementations/{control_id}/`
- Failure exits with code 1

**Implementation Notes:**

Add constant for required playbook files:
```python
REQUIRED_PLAYBOOK_FILES = [
    "portal-walkthrough.md",
    "powershell-setup.md",
    "verification-testing.md",
    "troubleshooting.md",
]

PLAYBOOKS_DIR = Path("docs/playbooks/control-implementations")
```

Add validation function:
```python
def validate_playbook_files(control_id: str) -> list[str]:
    """Validate that 4 standard playbook files exist for a control."""
    failures = []
    playbook_dir = PLAYBOOKS_DIR / control_id
    if not playbook_dir.exists():
        failures.append(f"playbook directory missing: {playbook_dir}")
        return failures
    for fname in REQUIRED_PLAYBOOK_FILES:
        if not (playbook_dir / fname).exists():
            failures.append(f"missing playbook: {playbook_dir / fname}")
    return failures
```

Integrate into `verify_consistency()`:
- After control content validation section
- Extract control ID from filename pattern `{id}-*.md`
- Call `validate_playbook_files(control_id)`
- Count and report failures

**Validation:**
```bash
python scripts/verify_controls.py
# Expected: all 62 controls pass playbook check (currently all present)
```
