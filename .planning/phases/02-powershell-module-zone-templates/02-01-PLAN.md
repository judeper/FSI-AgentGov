# Plan 02-01: FsiMimeControl Module Core + Zone Templates

## Goal

Create `scripts/governance/FsiMimeControl.psm1` with 3 exported cmdlets for Dataverse Web API MIME configuration management, plus zone template JSON files with escalating restrictions per governance zone.

## Context

- **Module pattern:** `scripts/private/CAAClient.psm1` (module-scoped session, Dataverse OData)
- **Script conventions:** `scripts/governance/Invoke-HardeningBaselineCheck.ps1` (OutputFormat/OutputPath, CheckResult, SHA-256 evidence)
- **Dataverse endpoint:** `GET/PATCH {url}/api/data/v9.2/organizations` — fields: `blockedattachments`, `blockedmimetypes`
- **Zone templates location:** `scripts/governance/mime-templates/`
- **Control 1.25 doc:** Created in Phase 1 with specific MIME type lists and cmdlet signatures

## Tasks

### Task 1: Create zone template JSON files

**Files:**
- `scripts/governance/mime-templates/zone1.json`
- `scripts/governance/mime-templates/zone2.json`
- `scripts/governance/mime-templates/zone3.json`

**Acceptance criteria:**

1. **Schema consistency** — All 3 files share identical structure: `templateVersion`, `zone`, `zoneName`, `description`, `blockedExtensions`, `blockedMimeTypes`, `allowedMimeTypes`, `flags`, `reviewCadence`, `metadata`

2. **zone1.json (Personal Productivity):**
   - `blockedExtensions`: 44 items (Microsoft default list from `Invoke-HardeningBaselineCheck.ps1` `$requiredBlockedExtensions`)
   - `blockedMimeTypes`: empty array
   - `allowedMimeTypes`: empty array (no restriction)
   - `flags`: all `false`
   - `reviewCadence`: Quarterly

3. **zone2.json (Team Collaboration):**
   - `blockedExtensions`: 45 items (Zone 1 + `ps1`)
   - `blockedMimeTypes`: 15 items (executable/script MIME types)
   - `allowedMimeTypes`: 9 items (PDF, images, plaintext, CSV, Office OpenXML)
   - `flags.requireDlpIntegration`: `true`, others `false`
   - `reviewCadence`: Monthly

4. **zone3.json (Enterprise Managed):**
   - `blockedExtensions`: 57 items (Zone 2 + PS variants, cab, gadget, isp, its, rgs, ps1xml, ps2, ps2xml, psc1, psc2)
   - `blockedMimeTypes`: 21 items (Zone 2 + shellscript, sh, csh, java-archive, ms-shortcut, xml)
   - `allowedMimeTypes`: 10 items (Zone 2 + TIFF)
   - `flags`: all `true` (requireServerSideValidation, requireDlpIntegration, requireSentinelMonitoring)
   - `reviewCadence`: Weekly

5. **Extension list alignment** — Zone 1 `blockedExtensions` is a superset of the hardening baseline's `$requiredBlockedExtensions`. Each subsequent zone is a superset of the previous.

6. **Metadata** — `controlReference: "1.25"`, `version: "1.3"`, `lastUpdated` set to current date

### Task 2: Create FsiMimeControl.psm1

**File:** `scripts/governance/FsiMimeControl.psm1`

**Acceptance criteria:**

1. **Module header:**
   - `#Requires -Version 7.0`
   - `$ErrorActionPreference = 'Stop'`
   - Comment-based help with `.SYNOPSIS`, `.DESCRIPTION`, `.NOTES`
   - Module-scoped state: `$script:DataverseUrl`, `$script:AccessToken`, `$script:Headers`, `$script:TemplateBasePath`

2. **Connection management (2 functions):**

   a. `Connect-FsiMimeDataverse` — accepts `DataverseUrl` and `AccessToken` (or falls back to `Get-AzAccessToken`). Validates connection with `GET /api/data/v9.2/organizations?$select=organizationid`. Stores URL/token/headers in `$script:` scope.

   b. `Get-FsiMimeConnection` — returns PSCustomObject with `IsConnected`, `DataverseUrl`, `TokenExpiry` (if available).

3. **Internal helper — `Resolve-DataverseHeaders`:**
   - Accepts optional `DataverseUrl`, `AccessToken` parameters
   - Priority: explicit params → module session → `Get-AzAccessToken` fallback
   - Returns hashtable with `Url`, `Headers` keys
   - OData headers: `Authorization: Bearer`, `OData-MaxVersion: 4.0`, `OData-Version: 4.0`, `Accept: application/json`

4. **Cmdlet 1 — `Get-FsiMimeConfig`:**
   - Parameters: `DataverseUrl` (string), `AccessToken` (string, optional), `OutputFormat` (`[ValidateSet('Table','JSON','Object')]`, default Object), `OutputPath` (string, optional)
   - Queries `GET {url}/api/data/v9.2/organizations?$select=organizationid,blockedattachments,blockedmimetypes,allowedmimetypes`
   - Parses semicolon-separated `blockedattachments` and `blockedmimetypes` into string arrays
   - **AllowedMimeTypes handling:** Attempts to read `allowedmimetypes` field; returns `$null` if the field does not exist on the Organization entity (graceful fallback with `Write-Verbose` note). This field may not exist in all Dataverse environments — the module treats it as optional.
   - Returns PSCustomObject: `DataverseUrl`, `OrganizationId`, `BlockedExtensions` (string[]), `BlockedMimeTypes` (string[]), `AllowedMimeTypes` (string[] or `$null`), `RawResponse` (hashtable)
   - Handles output format switch (Table/JSON/Object) and OutputPath export

5. **Cmdlet 2 — `Set-FsiMimeConfig`:**
   - `[CmdletBinding(SupportsShouldProcess)]`
   - Parameters: `DataverseUrl`, `AccessToken` (optional), `ZoneTemplate` (`[ValidateSet('zone1','zone2','zone3')]`), `BlockedExtensions` (string[]), `BlockedMimeTypes` (string[]), `AllowedMimeTypes` (string[]), `OutputFormat`, `OutputPath`
   - Parameter sets: `Template` (ZoneTemplate) and `Custom` (individual arrays), default `Template`
   - Template mode: loads `$script:TemplateBasePath/{zone}.json`, extracts arrays
   - WhatIf: calls `Get-FsiMimeConfig` for current state, displays before/after comparison via `Write-Verbose`, returns without making changes
   - Apply: `PATCH {url}/api/data/v9.2/organizations({orgId})` with Content-Type `application/json` body containing `blockedattachments` (semicolon-joined), `blockedmimetypes` (semicolon-joined). Attempts to include `allowedmimetypes` in PATCH body; if the field does not exist, catches the error, logs `Write-Warning` about unsupported field, and retries PATCH without `allowedmimetypes`.
   - Post-apply: calls `Get-FsiMimeConfig` to verify, returns PSCustomObject: `Applied` (bool), `PreviousConfig`, `NewConfig`, `Template` (if used), `AllowedMimeTypesSupported` (bool — whether the field was accepted by the API)

6. **Cmdlet 3 — `Test-FsiMimeCompliance`:**
   - Parameters: `DataverseUrl`, `AccessToken` (optional), `Zone` (`[ValidateSet(1,2,3)]`), `OutputFormat`, `OutputPath`, `IncludeEvidence` (switch)
   - Internally calls `Get-FsiMimeConfig` and loads zone template
   - Runs 6 checks using `New-CheckResult` helper:
     - MIME-01: Blocked file extensions configured (all zones)
     - MIME-02: All required extensions present — array comparison (all zones)
     - MIME-03: Blocked MIME types configured (Zone 2+ FAIL, Zone 1 INFO)
     - MIME-04: All required MIME types present (Zone 2+ FAIL, Zone 1 INFO)
     - MIME-05: Allowed MIME types configured — checks against zone template definition. If `AllowedMimeTypes` is `$null` from API (field unsupported), the check is advisory: Zone 3 WARN ("allowlist recommended but field not available"), Zone 2 INFO, Zone 1 INFO. If the field is readable, Zone 3 FAIL (missing allowlist), Zone 2 WARN, Zone 1 INFO.
     - MIME-06: Zone flags satisfied — advisory checks for DLP/Sentinel (Zone 3 WARN, others INFO)
   - `IsCompliant`: true only if no FAIL results. MIME-05 advisory mode (field unsupported) produces WARN not FAIL, so it does not block compliance.
   - SHA-256 evidence hash when `-IncludeEvidence` switch is set (follows `Invoke-HardeningBaselineCheck.ps1` pattern)
   - Returns PSCustomObject: `DataverseUrl`, `Zone`, `IsCompliant` (bool), `Checks` (CheckResult[]), `Findings` (string[]), `Summary` (PSCustomObject with PassCount, FailCount, WarnCount), `EvidenceHash` (string, nullable)

7. **`New-CheckResult` helper:**
   - Function signature: `CheckId`, `Setting`, `Status`, `Expected`, `Actual`, `Message`
   - Returns PSCustomObject matching existing pattern from `Invoke-HardeningBaselineCheck.ps1`

8. **Export statement:**
   - `Export-ModuleMember -Function @('Connect-FsiMimeDataverse', 'Get-FsiMimeConnection', 'Get-FsiMimeConfig', 'Set-FsiMimeConfig', 'Test-FsiMimeCompliance')`

9. **Console output:**
   - Cyan ASCII box banner on module load (consistent with governance scripts)
   - Color-coded status output: Green (Pass), Red (Fail), Yellow (Warning), Cyan (Info)

10. **Error handling:**
    - `try/catch` on all Dataverse API calls
    - `Write-Warning` on non-critical failures (e.g., connection validation)
    - `throw` on critical failures (e.g., PATCH failure, invalid zone template)
    - Template file not found: `throw "Zone template not found: {path}"`
