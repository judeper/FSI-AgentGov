# Plan 02-02: Pester Test Suite for FsiMimeControl

## Goal

Create `scripts/governance/FsiMimeControl.Tests.ps1` — a comprehensive Pester 5 test suite covering all exported cmdlets, zone template loading, Dataverse API mocking, and compliance check logic. This establishes the Pester testing pattern for the project (no prior test files exist).

## Context

- **Module under test:** `scripts/governance/FsiMimeControl.psm1` (created in Plan 02-01)
- **Zone templates:** `scripts/governance/mime-templates/zone{1,2,3}.json`
- **Test framework:** Pester 5.0+ with `BeforeAll`/`AfterAll`, `Describe`/`Context`/`It` blocks
- **Mock targets:** `Invoke-RestMethod` (Dataverse API), `Get-AzAccessToken` (token acquisition)
- **No existing Pester tests in repo** — this file sets the project testing pattern

## Tasks

### Task 1: Create FsiMimeControl.Tests.ps1

**File:** `scripts/governance/FsiMimeControl.Tests.ps1`

**Acceptance criteria:**

1. **Header:**
   - `#Requires -Version 7.0`
   - `#Requires -Modules Pester`
   - Comment block explaining test structure and mock strategy

2. **BeforeAll block:**
   - `Import-Module` of `FsiMimeControl.psm1` from `$PSScriptRoot`
   - Define shared mock data:
     - `$mockOrgResponse` — Organization entity response with `organizationid`, `blockedattachments` (semicolon-separated), `blockedmimetypes`
     - `$mockOrgResponseEmpty` — Organization entity with empty/null attachment and MIME fields
     - `$mockOrgResponsePartial` — Organization entity with blocked extensions but no MIME types
     - `$mockToken` — mock access token object

3. **Category 1 — Module Loading (3 tests):**

   ```
   Describe 'Module Loading' {
     It 'Imports without error'
     It 'Exports expected cmdlets (5 functions)'
     It 'Has #Requires -Version 7.0'
   }
   ```

4. **Category 2 — Zone Template Loading (6 tests):**

   ```
   Describe 'Zone Templates' {
     It 'zone1.json loads and has valid schema'
     It 'zone2.json loads and has valid schema'
     It 'zone3.json loads and has valid schema'
     It 'Zone 2 has more blocked MIME types than Zone 1'
     It 'Zone 3 has more blocked extensions than Zone 2'
     It 'Zone 3 flags are all true'
   }
   ```

   Schema validation: check for required properties (`templateVersion`, `zone`, `zoneName`, `blockedExtensions`, `blockedMimeTypes`, `allowedMimeTypes`, `flags`, `metadata`)

5. **Category 3 — Get-FsiMimeConfig (5 tests):**

   ```
   Describe 'Get-FsiMimeConfig' {
     BeforeAll { Mock Invoke-RestMethod { $mockOrgResponse } }
     It 'Returns PSCustomObject with expected properties'
     It 'Parses semicolon-separated blockedattachments into array'
     It 'Parses semicolon-separated blockedmimetypes into array'
     It 'Returns empty arrays for null/empty fields'
     It 'Handles API error with warning'
   }
   ```

   - Mock `Invoke-RestMethod` with URI matching for `organizations?` queries
   - Validate return object has: `DataverseUrl`, `OrganizationId`, `BlockedExtensions`, `BlockedMimeTypes`
   - Test empty state with `$mockOrgResponseEmpty`
   - Test error handling with `Mock Invoke-RestMethod { throw 'API error' }`

6. **Category 4 — Set-FsiMimeConfig (6 tests):**

   ```
   Describe 'Set-FsiMimeConfig' {
     BeforeAll {
       Mock Invoke-RestMethod -ParameterFilter { $Method -ne 'Patch' } { $mockOrgResponse }
       Mock Invoke-RestMethod -ParameterFilter { $Method -eq 'Patch' } { $mockOrgResponse }
     }
     It '-WhatIf does NOT invoke Patch'
     It '-WhatIf outputs planned changes to Verbose stream'
     It 'Template mode loads correct zone file'
     It 'Custom mode accepts individual arrays'
     It 'PATCH body contains semicolon-joined strings'
     It 'Returns result object with Applied = $true'
   }
   ```

   - WhatIf test: call with `-WhatIf`, assert `Invoke-RestMethod` with `Patch` method was NOT called (use `Should -Not -Invoke`)
   - Template test: call with `-ZoneTemplate zone2`, verify the PATCH body contains zone2 extension list
   - Custom test: call with explicit `-BlockedExtensions @('exe','bat')`, verify PATCH body
   - Verify `Applied` property in result

7. **Category 5 — Test-FsiMimeCompliance (8 tests):**

   ```
   Describe 'Test-FsiMimeCompliance' {
     Context 'Zone 1 compliance' {
       It 'Full blocked extensions → IsCompliant = $true'
       It 'Missing blocked extensions → IsCompliant = $false'
     }
     Context 'Zone 2 compliance' {
       It 'Extensions + MIME types → IsCompliant = $true'
       It 'Missing MIME types → IsCompliant = $false'
     }
     Context 'Zone 3 compliance' {
       It 'Missing allowlist → FAIL check'
       It 'Full config → IsCompliant = $true'
     }
     Context 'Output details' {
       It 'Missing extensions produce specific findings'
       It '-IncludeEvidence computes SHA-256 hash'
     }
   }
   ```

   - Zone 1: mock response with full extension list → `IsCompliant` should be `$true`
   - Zone 1: mock response missing required extensions → `IsCompliant` should be `$false`, `Findings` should list missing extensions
   - Zone 2: mock response with extensions + MIME types → `IsCompliant` should be `$true`
   - Zone 2: mock response without MIME types → `IsCompliant` should be `$false`
   - Zone 3: mock response without allowlist → `Checks` should contain FAIL for MIME-05
   - Zone 3: full config → `IsCompliant` should be `$true`
   - Findings test: verify `Findings` array contains human-readable gap descriptions
   - Evidence test: call with `-IncludeEvidence`, verify `EvidenceHash` property is non-null and matches SHA-256 format (64 hex chars)

8. **Category 6 — Connection Management (4 tests):**

   ```
   Describe 'Connection Management' {
     It 'Connect-FsiMimeDataverse sets module state'
     It 'Get-FsiMimeConnection returns correct status'
     It 'Token fallback to Get-AzAccessToken when no explicit token'
     It 'Connection validation fails gracefully on bad URL'
   }
   ```

   - Mock `Invoke-RestMethod` for `organizations?$select=organizationid` to simulate connection validation
   - Mock `Get-AzAccessToken` to return mock token
   - Bad URL test: mock `Invoke-RestMethod` to throw, verify `Connect-FsiMimeDataverse` returns error gracefully

9. **Total test count:** ~32 tests across 6 categories

10. **Test execution command:** documented in header comment:
    ```
    Invoke-Pester -Path ./scripts/governance/FsiMimeControl.Tests.ps1 -Output Detailed
    ```

11. **No external API calls** — all Dataverse interactions mocked via `Mock Invoke-RestMethod`

12. **Consistent assertions:**
    - Use `Should -Be`, `Should -BeOfType`, `Should -HaveCount`, `Should -Contain`
    - Use `Should -Not -Invoke` for WhatIf verification
    - Use `Should -BeTrue` / `Should -BeFalse` for boolean checks
