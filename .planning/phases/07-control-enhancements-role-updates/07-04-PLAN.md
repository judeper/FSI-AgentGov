   `!!! info "GA Feature"` admonition stating: "SharePoint Restricted Search is generally available for Microsoft 365 Copilot customers. This feature provides a positive governance model by specifying an allowed list of SharePoint sites for AI agent grounding."

   NOTE: Research (07-RESEARCH.md) confirmed GA status based on comprehensive Microsoft Learn documentation without preview disclaimers. Per user decision, originally planned as preview admonition but research showed GA — use GA admonition per research findings.

2. **Explain Restricted Search vs. Restricted Content Discovery (RCD):**
   - RCD (existing in Control 4.1/4.6) = negative governance: exclude specific sites
   - Restricted Search = positive governance: allow ONLY specific sites (up to 100)
   - Present as a comparison table:

   | Approach | Model | Scope | Use Case |
   |----------|-------|-------|----------|
   | Restricted Content Discovery (RCD) | Exclusion list (block specific sites) | Unlimited exclusions | Exclude known sensitive sites |
   | Restricted Search | Allowed list (permit specific sites only) | Up to 100 sites | Strict positive governance for regulated environments |

   - Emphasize for FSI: Restricted Search is preferred for Zone 3 regulated environments because it implements a "deny by default, allow by exception" model aligned with security best practices.

3. **Document AI Agent Grounding Impact** — this is the PRIMARY framing per user decision:
   - When Restricted Search is enabled, Microsoft 365 Copilot and AI agents can ONLY ground responses on content from allowed sites
   - All other SharePoint content is invisible to AI grounding, regardless of user permissions
   - This directly controls the "data surface area" available to AI agents
   - Include a table showing impact on different agent types:

   | Agent Type | Impact of Restricted Search | Configuration |
   |------------|---------------------------|---------------|
   | M365 Copilot | Grounds only on allowed sites | SharePoint Admin Center |
   | Copilot Studio (SharePoint knowledge) | Subject to tenant Restricted Search settings | Inherits tenant setting |
   | Agent Builder declarative agents | Grounds only on allowed sites | SharePoint Admin Center |

4. **Document the 100-site allowed list governance:**
   - Maximum 100 SharePoint sites in the allowed list
   - Governance process for adding/removing sites (approval workflow)
   - Quarterly review cadence
   - Include a "Site Selection Criteria" table:

   | Criterion | Zone 3 Guidance | Rationale |
   |-----------|----------------|-----------|
   | Content ownership | Clearly identified content owner | Accountability |
   | Sensitivity labeling | All content labeled | Data classification |
   | Access review | Quarterly access review completed | Permission hygiene |
   | Content currency | Content updated within 12 months | Data quality |
   | Regulatory clearance | Compliance officer approved for AI access | Regulatory alignment |

5. **Add "Prepare Now" checklist** per user decision (following Phase 6 pattern):
   - Audit current SharePoint site inventory for AI-relevant content
   - Identify candidate sites for the 100-site allowed list
   - Review sensitivity labeling coverage on candidate sites
   - Establish site nomination and approval workflow
   - Document current search scopes and Copilot grounding behavior
   - Train SharePoint admins on Restricted Search configuration

6. **Add inline regulatory mapping:** "SharePoint Restricted Search helps support SEC 17a-3/4 (controlling which records AI agents can access), GLBA 501(b) (limiting AI agent data surface area to approved content), FINRA 4511 (ensuring agents cite only approved, finalized documents), and OCC 2011-12 (controlling data quality for AI-grounded responses)."
