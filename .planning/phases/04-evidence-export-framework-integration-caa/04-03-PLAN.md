### Task 4: Update TROUBLESHOOTING.md
**File:** `C:/dev/FSI-AgentGov-Solutions/conditional-access-automation/docs/troubleshooting.md`

Add section: `## Evidence Export Issues`
- **Hash mismatch after export**: File modified after export; re-export from Dataverse source
- **Empty validations array**: No validation runs in date range; check FromDate/ToDate, verify daily flow is running
- **Truncated JSON**: Missing `-Depth 10`; re-run export (script already includes, but document if manual JSON manipulation occurred)
- **Dataverse authentication failure**: Certificate expired or missing; verify app registration and Graph permissions
- **Large export file**: Filter by RunId or narrow date range; consider weekly exports instead of 30-day default
