# Plan 04-01: SHA-256 Evidence Export Scripts

## Objective

Create PowerShell evidence export scripts that produce JSON files with CA policy compliance results, violations, baselines, and SHA-256 integrity hashes — enabling operators to produce verifiable evidence packages for FINRA/SEC examination support.

## Requirements Covered

- **EFR-01**: SHA-256 integrity-hashed compliance evidence export for CA policy configurations, validation results, and drift detection history

## Must-Haves Covered

| # | Must-Have | How |
|---|----------|-----|
| 1 | SHA-256 evidence export scripts | 3 scripts: main export, Dataverse query helper, hash verification utility following ACV pattern with CAA-specific schema extensions (violations, baselines) |

## Tasks

### Task 1: Create Get-CAAValidationResults.ps1 private helper
**File:** `C:/dev/FSI-AgentGov-Solutions/conditional-access-automation/scripts/private/Get-CAAValidationResults.ps1`
- Private helper that queries Dataverse via OData Web API
- Query functions for 3 tables:
  - `fsi_capolicyvalidationhistories` — immutable validation results with timestamp/zone/severity/runid filtering
  - `fsi_capolicyviolations` — active violations with date range filtering
  - `fsi_capolicybaselines` — current active baselines
- Parameters: `DataverseUrl` (M), `AccessToken` (M), `Table` (M, ValidateSet), `FromDate` (O), `ToDate` (O), `RunId` (O)
- Pagination support via `@odata.nextLink`
- Follow `Get-ValidationResults.ps1` pattern from ACV
- `#Requires -Version 5.1`
- Comment-based help

### Task 2: Create Export-CAAComplianceEvidence.ps1 main export
**File:** `C:/dev/FSI-AgentGov-Solutions/conditional-access-automation/scripts/Export-CAAComplianceEvidence.ps1`
- `#Requires -Version 5.1`
- Parameters: `DataverseUrl` (M), `OutputPath` (M), `FromDate` (O, default -30 days), `ToDate` (O, default now), `RunId` (O), `IncludeBaselines` (switch, default $true), `IncludeViolations` (switch, default $true)
- Dot-source `private/Get-CAAValidationResults.ps1`
- Authenticate via `Connect-CAADataverse` from CAAClient module
- Query all 3 tables using private helper
- Build JSON evidence with extended schema:
  - `metadata`: exportedAt, scope (always "Tenant"), tenantId, fromDate, toDate, runId, exportVersion "1.0.0", solutionVersion "1.1.0", recordCount, violationCount, baselineCount
  - `summary`: overallStatus (worst severity), validationsRun, passed/failed/warning counts, zoneBreakdown
  - `validations`: array of validation history records
  - `violations`: array of violation records (if IncludeViolations)
  - `baselines`: array of active baseline records (if IncludeBaselines)
- `ConvertTo-Json -Depth 10` (critical — NOT default depth 2)
- `Out-File -Encoding utf8` (explicit encoding)
- Generate SHA-256 companion file: `"{hash}  {filename}"` format (two spaces, sha256sum -c compatible)
- Output: `{OutputPath}/CAA-Evidence-{timestamp}.json` + `{OutputPath}/CAA-Evidence-{timestamp}.json.sha256`
- Overall status priority: Error > Failed > GracePeriod > Warning > Passed
- ShouldProcess support for WhatIf

### Task 3: Create Test-EvidenceIntegrity.ps1 hash verification
**File:** `C:/dev/FSI-AgentGov-Solutions/conditional-access-automation/scripts/Test-EvidenceIntegrity.ps1`
- `#Requires -Version 5.1`
- Parameters: `EvidencePath` (M, path to JSON file)
- Read companion `.sha256` file
- Compute `Get-FileHash -Algorithm SHA256` on JSON file
- Compare hashes (case-insensitive)
- Return `[PSCustomObject]@{ Path = $EvidencePath; Valid = $true/$false; ExpectedHash = "..."; ActualHash = "..." }`
- Exit code 0 on match, 1 on mismatch
- Comment-based help with usage examples

### Task 4: Update module manifest
**File:** `C:/dev/FSI-AgentGov-Solutions/conditional-access-automation/scripts/conditional-access-automation.psd1`
- Add `Export-CAAComplianceEvidence` and `Test-EvidenceIntegrity` to `FunctionsToExport`
- Bump module version to 1.1.0
