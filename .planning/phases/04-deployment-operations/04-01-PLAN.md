# Plan 04-01: Deployment Scripts for Detection and Remediation Flows

## Objective

Create two PowerShell deployment scripts that import the UASD Power Automate flows into a target environment, bind connection references, and configure environment variables. Both scripts must be idempotent and follow the established governance script pattern from `Invoke-SharingAudit.ps1` and `Import-ApprovedSecurityGroups.ps1`.

## Tasks

### Task 1: Create `scripts/governance/Deploy-DetectionFlow.ps1`

**Create** the detection flow deployment script following the established governance script pattern.

#### 1a. Standard Header (Comment-Based Help)

```powershell
<#
.SYNOPSIS
    Deploys the UASD detection flow to a Power Platform environment.

.DESCRIPTION
    Imports the Unrestricted Agent Sharing Detector scan flow
    (uasd-detector-scan-agents.json) into a Power Platform environment.
    Binds connection references, validates import, and configures
    the recurrence schedule.

    Idempotent — re-running against an environment that already contains
    the flow updates the existing definition.

.PARAMETER EnvironmentId
    Power Platform environment GUID for deployment.

.PARAMETER FlowDefinitionPath
    Path to the detector flow JSON file.
    Default: src/uasd-detector-scan-agents.json

.PARAMETER DataverseUrl
    Dataverse environment URL (e.g., https://org.crm.dynamics.com).

.PARAMETER ScanFrequencyHours
    Recurrence interval in hours. Default: 24.

.PARAMETER WhatIf
    Preview deployment without making changes.

.EXAMPLE
    .\Deploy-DetectionFlow.ps1 -EnvironmentId "xxx-xxx" -DataverseUrl https://org.crm.dynamics.com

.EXAMPLE
    .\Deploy-DetectionFlow.ps1 -EnvironmentId "xxx-xxx" -DataverseUrl https://org.crm.dynamics.com -ScanFrequencyHours 12 -WhatIf

.OUTPUTS
    PSCustomObject with Metadata, DeploymentResult, and ValidationChecks properties.

.NOTES
    Part of the FSI Agent Governance — Unrestricted Agent Sharing Detector.
    Controls: 1.1, 3.8
    Version: 1.0.0
    Requires: Az.Accounts, Microsoft.PowerApps.Administration.PowerShell
#>
```

#### 1b. Script Structure

- `#Requires -Version 7.0`
- `#Requires -Modules Az.Accounts`
- `[CmdletBinding(SupportsShouldProcess)]` with params: `EnvironmentId` (Mandatory), `FlowDefinitionPath` (default: `src/uasd-detector-scan-agents.json`), `DataverseUrl` (Mandatory), `ScanFrequencyHours` (default: 24)
- `$ErrorActionPreference = 'Stop'`
- ASCII banner: "UASD — Deploy Detection Flow"
- WhatIf preview block

#### 1c. Helper Functions

- `Get-DataverseToken` — reuse pattern from Import-ApprovedSecurityGroups.ps1
- `Invoke-DataverseApi` — reuse pattern from Import-ApprovedSecurityGroups.ps1
- `Import-FlowDefinition` — reads JSON, validates structure, imports via Power Automate Management API
- `Set-ConnectionReference` — binds connection references to authenticated connections
- `Test-FlowDeployment` — validates flow exists and is enabled post-import

#### 1d. Main Logic Flow

1. Validate flow definition file exists and is valid JSON
2. Read flow JSON and extract connection reference logical names
3. Check if flow already exists in target environment (idempotent check)
4. Import or update flow definition via Power Automate Management API
5. Bind connection references (`fsi_cr_dataverse_sharingdetector`, `fsi_cr_teams_sharingdetector`)
6. Update scan frequency environment variable if non-default
7. Validate deployment: flow exists, is enabled, connection references bound
8. Return PSCustomObject with deployment results

#### 1e. Output Format

```powershell
[PSCustomObject]@{
    Metadata = @{
        ScriptName    = 'Deploy-DetectionFlow.ps1'
        Version       = '1.0.0'
        ExecutedAt    = (Get-Date -Format 'o')
        EnvironmentId = $EnvironmentId
    }
    DeploymentResult = @{
        FlowName      = 'UASD — Detector: Scan Agents'
        FlowId        = $flowId
        Status        = 'Deployed' # or 'Updated', 'AlreadyExists'
        ConnectionRefs = @(...)
    }
    ValidationChecks = @(
        @{ Check = 'FlowExists'; Passed = $true }
        @{ Check = 'ConnectionsBound'; Passed = $true }
        @{ Check = 'RecurrenceSet'; Passed = $true }
    )
}
```

### Task 2: Create `scripts/governance/Deploy-RemediationFlow.ps1`

**Create** the remediation flow deployment script following the same pattern as Task 1.

#### 2a. Standard Header (Comment-Based Help)

```powershell
<#
.SYNOPSIS
    Deploys the UASD remediation flow to a Power Platform environment.

.DESCRIPTION
    Imports the Unrestricted Agent Sharing Detector remediation flow
    (uasd-remediation-apply-sharing-policy.json) into a Power Platform
    environment. Binds connection references including the Approvals
    connector, validates import, and sets the auto-remediation flag.

    Also imports the exception approval workflow
    (uasd-exception-approval-workflow.json) as a companion flow.

    Idempotent — re-running updates existing definitions.

.PARAMETER EnvironmentId
    Power Platform environment GUID for deployment.

.PARAMETER RemediationFlowPath
    Path to the remediation flow JSON file.
    Default: src/uasd-remediation-apply-sharing-policy.json

.PARAMETER ExceptionFlowPath
    Path to the exception approval flow JSON file.
    Default: src/uasd-exception-approval-workflow.json

.PARAMETER DataverseUrl
    Dataverse environment URL (e.g., https://org.crm.dynamics.com).

.PARAMETER AutoRemediatePublicLink
    Whether to auto-remediate public internet link violations without approval.
    Default: $false

.PARAMETER WhatIf
    Preview deployment without making changes.

.EXAMPLE
    .\Deploy-RemediationFlow.ps1 -EnvironmentId "xxx-xxx" -DataverseUrl https://org.crm.dynamics.com

.EXAMPLE
    .\Deploy-RemediationFlow.ps1 -EnvironmentId "xxx-xxx" -DataverseUrl https://org.crm.dynamics.com -AutoRemediatePublicLink

.OUTPUTS
    PSCustomObject with Metadata, DeploymentResults, and ValidationChecks.

.NOTES
    Part of the FSI Agent Governance — Unrestricted Agent Sharing Detector.
    Controls: 1.1, 3.8
    Version: 1.0.0
    Requires: Az.Accounts, Microsoft.PowerApps.Administration.PowerShell
#>
```

#### 2b. Additional Parameters vs Detection Script

- `RemediationFlowPath` (default: `src/uasd-remediation-apply-sharing-policy.json`)
- `ExceptionFlowPath` (default: `src/uasd-exception-approval-workflow.json`)
- `AutoRemediatePublicLink` (switch, default: $false)

#### 2c. Connection References

This script binds 3 connection references:
- `fsi_cr_dataverse_sharingdetector` (Dataverse)
- `fsi_cr_teams_sharingdetector` (Teams)
- `fsi_cr_approvals_sharingdetector` (Approvals)

#### 2d. Auto-Remediation Flag

Set `fsi_UASD_AutoRemediatePublicLink` environment variable based on `-AutoRemediatePublicLink` switch.

#### 2e. Main Logic Flow

1. Validate both flow definition files exist and are valid JSON
2. Import remediation flow (or update if exists)
3. Import exception approval flow (or update if exists)
4. Bind all 3 connection references
5. Set auto-remediation environment variable
6. Validate both flows exist and are enabled
7. Return PSCustomObject with combined deployment results
