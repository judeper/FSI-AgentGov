
   ```powershell
   $totalGaps = $complianceResults.Gaps.Count
   $driftCount = if ($complianceResults.DriftAnalysis) { $complianceResults.DriftAnalysis.Count } else { 0 }
   ```
   to just before the `if ($OutputFormat -eq 'Dataverse' -or ($DataverseUrl -and $PersistResults))` block.

**Acceptance Criteria:**

### Task 3: Fix 4.7 PowerShell SKU filter (SCF-03)

**File:** `docs/playbooks/control-implementations/4.7/powershell-setup.md`

**Problem:** `$_.SkuId -match "copilot"` will never match because `SkuId` is a GUID. Need to use `Get-MgSubscribedSku` to resolve `SkuPartNumber` first.

**Changes:**

Replace the "Inventory Copilot Licenses" code block with:
```powershell
# Step 1: Find Copilot SKU IDs from tenant subscriptions
$copilotSkus = Get-MgSubscribedSku -All | Where-Object {
    $_.SkuPartNumber -match 'Copilot'
} | Select-Object -ExpandProperty SkuId

if ($copilotSkus.Count -eq 0) {
    Write-Warning "No Copilot SKUs found in tenant subscriptions"
} else {
    Write-Host "Found $($copilotSkus.Count) Copilot SKU(s)"
}

# Step 2: Filter users assigned those SKUs
$licensedUsers = Get-MgUser -Filter "assignedLicenses/any()" -All |
    Where-Object {
        $_.AssignedLicenses | Where-Object {
            $_.SkuId -in $copilotSkus
        }
    }

Write-Host "Found $($licensedUsers.Count) users with Copilot licenses"

# Export for documentation
$licensedUsers | Select-Object DisplayName, UserPrincipalName, Id |
    Export-Csv -Path "Copilot-Licensed-Users.csv" -NoTypeInformation
```

**Acceptance Criteria:**
- No instances of `SkuId -match "copilot"` remain in the file
- Filter uses `Get-MgSubscribedSku` → `SkuPartNumber` → `SkuId -in $copilotSkus` pattern
- `mkdocs build --strict` passes

### Task 4: Annotate non-existent cmdlets in promotion gates (SCF-04)

**Files:**

- `docs/playbooks/advanced-implementations/agent-blueprint-promotion-gates/index.md`

**Changes:**

   - `Get-DataverseRecords` → same
   - `Send-EscalationNotification` → same
   - `Send-ReminderNotification` → same

3. **index.md:** Add `# PSEUDOCODE` comments on lines ~L113-L115 where `Get-AdminPowerAppAgent` and `Get-AdminPowerAppAgentMetadata` are referenced.
