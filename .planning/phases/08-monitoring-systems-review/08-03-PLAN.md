```markdown
# Monitoring Architecture

Overview of the FSI-AgentGov unified monitoring system for tracking Microsoft documentation and regulatory changes.

## System Overview

[ASCII diagram showing the unified monitoring architecture:
Learn Monitor + Regulatory Monitor → Shared Utilities → Reports → AI-Assisted Review]

## Components

### Learn Monitor
- Script: `scripts/learn_monitor.py`
- Workflow: `.github/workflows/learn-monitor.yml`
- Cadence: Daily at 6:00 AM UTC
- Scope: 209 Microsoft Learn URLs
- State: `data/learn-monitor-state.json`
- Reports: `reports/learn-changes/`

### Regulatory Monitor
- Script: `scripts/regulatory_monitor.py`
- Workflow: `.github/workflows/regulatory-monitor.yml`
- Cadence: Weekly (Monday 7:00 AM UTC)
- Scope: Federal Register (SEC, CFTC, OCC, Fed), FINRA Notices
- State: `data/regulatory-monitor-state.json`
- Reports: `reports/regulatory-changes/`

### Shared Utilities
- Module: `scripts/monitoring_shared.py`
- Functions: fetch, normalize, hash, classify, state management, control mapping

### AI-Assisted Review
- Skill: `/review-learn-changes`
- Design: `docs/reference/learn-monitor-ai-enhancement.md`
- Scope: Analyzes change reports, drafts documentation updates

## Change Classification

[4-tier table: CRITICAL, HIGH, MEDIUM, NOISE with triggers and actions for each monitor type]

## Maintenance Procedures

### Weekly Review Cadence (~30 min/week)
1. Monday AM: Check for Regulatory Monitor PR (if created)
2. Daily: Scan Learn Monitor PRs (auto-created when changes detected)
3. Weekly: Run `/review-learn-changes` on accumulated reports
4. Monthly: Review state files for stale entries

### Adding URLs to Learn Monitor Watchlist
[Steps to add new Microsoft Learn URLs to docs/reference/microsoft-learn-urls.md]

### Adding Regulatory Sources
[Steps to add new agencies or FINRA feeds to regulatory_monitor.py]

### Troubleshooting

| Symptom | Cause | Resolution |
|---------|-------|------------|
| Monitor exits with code 2 | Script error | Check logs, verify dependencies installed |
| State file corrupt | Concurrent writes or disk issue | Delete state file, next run creates baseline |
| Too many false positives | Dynamic content not filtered | Add noise patterns to classification rules |
| Federal Register API returns 0 results | Date range issue | Check state file last_checked date |
| FINRA page structure changed | Website redesign | Update BeautifulSoup selectors in regulatory_monitor.py |
| PR not created | GitHub token permissions | Check workflow permissions: contents: write, pull-requests: write |

## Monitoring Approach Evaluation (MON-03)

### Approach Chosen: Automated Hash-Based Detection + AI-Assisted Review

**Why this approach:**
- Scales to hundreds of URLs with zero daily manual effort
- 4-tier classification reduces noise and prioritizes human review time
- AI-assisted review drafts documentation updates, reducing manual work
- Configurable cadence per source type (daily for Learn, weekly for regulatory)

### Alternatives Evaluated

| Alternative | Pros | Cons | Decision |
|-------------|------|------|----------|
| Manual checking | No infrastructure | Doesn't scale, inconsistent | Rejected |
| Third-party monitoring service | Managed, reliable | Cost, vendor dependency, limited customization | Rejected |
| RSS-only monitoring | Simple, lightweight | Not all sources provide RSS (FINRA doesn't) | Partial use (Federal Register) |
| Full-text semantic comparison | Better change detection | Complex, expensive (LLM per comparison), overkill for current scale | Deferred |

### State AI Law Monitoring (Manual for Now)
- Colorado, Texas, Illinois, California, NYC tracked manually
- Quarterly review cadence recommended
- Automation deferred: state legislature sites vary in structure, low change frequency doesn't justify complexity
- Reassess annually or if review burden exceeds 30 min/quarter

## Configuration

### Cadence Configuration
| Source | Default Cadence | Configurable Via |
|--------|----------------|------------------|
| Microsoft Learn | Daily (6 AM UTC) | `.github/workflows/learn-monitor.yml` cron |
| Federal Register | Weekly (Monday 7 AM UTC) | `.github/workflows/regulatory-monitor.yml` cron |
| FINRA Notices | Weekly (Monday 7 AM UTC) | Same workflow as Federal Register |
| State AI Laws | Quarterly (manual) | N/A |

### Environment Variables
| Variable | Purpose | Default |
|----------|---------|---------|
| LEARN_MONITOR_DEBUG | Enable debug logging | false |
```
