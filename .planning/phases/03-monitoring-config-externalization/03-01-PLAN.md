<task type="auto">
  <name>Task 2: Add config loading infrastructure to monitoring_shared.py</name>
  <files>scripts/monitoring_shared.py</files>
  <action>
Add config loading functions to `monitoring_shared.py` after the existing imports:

1. **Add import for yaml:**
   ```python
   import yaml
   ```

2. **Add module-level config cache:**
   ```python
   _CONFIG = None
   _CONFIG_PATH = None
   ```

3. **Add `load_monitoring_config()` function:**
   - Takes `config_path: Path` parameter
   - Uses `yaml.safe_load()` (NOT `yaml.load()`)
   - Fails hard if file missing with clear error message
   - Fails hard if YAML syntax invalid with line/column info
   - Calls `_validate_patterns()` to check all regex patterns
   - Returns parsed config dict

4. **Add `_validate_patterns()` function:**
   - Iterates through all pattern sections: `learn.critical_patterns`, `learn.high_patterns`, etc.
   - Also validates `regulatory.critical_patterns`, `regulatory.high_patterns`, `regulatory.medium_patterns`
   - For each pattern entry, tries `re.compile(pattern)`
   - On failure, prints specific error with:
     - Config file path
     - YAML path (e.g., `learn.critical_patterns[2].pattern`)
     - Pattern string that failed
     - Regex error message
   - Calls `sys.exit(2)` on any invalid pattern

5. **Add `get_monitoring_config()` function:**
   - Returns cached config if already loaded
   - Otherwise loads from default path: `Path(__file__).parent / 'config' / 'monitoring-config.yaml'`
   - Caches result in `_CONFIG`

6. **Add `set_config_path()` function:**
   - Allows overriding default config path (for `--config` CLI flag)
   - Clears cached config so next `get_monitoring_config()` reloads

7. **Update `__all__` to export new functions:**
   - Add `'load_monitoring_config'`, `'get_monitoring_config'`, `'set_config_path'`

**Important:** Do NOT modify the existing `classify_change()` function yet - that's Task 1 of Plan 02.
