!!! tip "Agent 365 Architecture Update"
    Agent 365 Unified Registry (preview) offers a future architecture that consolidates all agent types -- Copilot Studio, Agent Builder, Azure AI Foundry, and SharePoint agents -- into a single registry with automatic discovery, rich metadata, and Graph API export. **Control 1.11 (Conditional Access):**
```markdown
!!! tip "Agent 365 Architecture Update"
    Entra Agent ID extends Conditional Access to agent identities with agent-specific risk signals and custom security attributes. Agents are now first-class identities subject to risk-based policies, replacing per-platform identity models (service principals, managed identities). See [Unified Agent Governance](../../framework/agent-identity-architecture.md) for agent Conditional Access policy examples and configuration guidance.
```

**Control 2.12 (FINRA 3110 Supervision):**
```markdown
!!! tip "Agent 365 Architecture Update"
    Entra Agent ID's sponsorship model provides enforced human accountability for agent lifecycle, aligning with FINRA 3110 supervision requirements. The three-role model (Owners, Sponsors, Managers) creates separation of duties where sponsors provide business oversight without technical modification rights. See [Unified Agent Governance](../../framework/agent-identity-architecture.md) for sponsorship model configuration and FINRA 3110 alignment details.
```

**Control 3.6 (Orphaned Agent Detection):**
```markdown
!!! tip "Agent 365 Architecture Update"
    Agent 365 lifecycle governance automates orphan detection through Entra ID Lifecycle Workflows. When sponsors leave the organization, workflows automatically flag agents for reassignment or suspension -- replacing manual PowerShell scripts that query multiple platforms. See [Unified Agent Governance](../../framework/agent-identity-architecture.md) for lifecycle workflow configuration and sponsor departure handling.
```
