- This is supplementary validation — organization-level is the primary check

**Header:**
- `#Requires -Version 7.0`
- `#Requires -Modules @{ ModuleName="ExchangeOnlineManagement"; ModuleVersion="3.7.0" }`
- Comment-based help (.SYNOPSIS: "Validates Purview audit retention policies against FSI regulatory requirements", .DESCRIPTION explaining zone-specific retention requirements, .PARAMETER, .EXAMPLE showing `-Zone Zone3`, .NOTES listing SEC 17a-4, FINRA 4511 references)
- [CmdletBinding()] with params: `-Zone` (ValidateSet "Zone1","Zone2","Zone3", mandatory), `-Interactive` (switch), `-TenantId`, `-ClientId`, `-CertificateThumbprint`

Dot-source helper:

```powershell
$scriptRoot = $PSScriptRoot
. "$scriptRoot\private\Connect-AuditServices.ps1"
```

**Constants (define at top of function):**
```powershell
$ZoneMinimumDays = @{
    "Zone1" = 180    # 6 months - Personal Productivity
    "Zone2" = 365    # 1 year - Team Collaboration
    "Zone3" = 730    # 2 years - Enterprise Managed (SEC 17a-4 communications minimum)
}

$RequiredRecordTypes = @("CopilotInteraction", "PowerPlatformAdmin")

$RetentionDurationMap = @{
    "ThreeMonths" = 90
    "SixMonths"   = 180
    "NineMonths"  = 270
    "OneYear"     = 365
    "TwoYears"    = 730
    "ThreeYears"  = 1095
    "FiveYears"   = 1825
    "SevenYears"  = 2555
    "TenYears"    = 3650
}
```

**Main function `Test-PurviewRetention`:**

Step 1 — Connect to Security & Compliance:
- Call `Connect-ComplianceSession` from the auth helper (NOT Connect-ExchangeOnline — retention policies require Security & Compliance PowerShell)
- Handle connection failures

Step 2 — Retrieve all retention policies (PVAL-01):
- `$policies = Get-UnifiedAuditLogRetentionPolicy -ErrorAction Stop`
- If $null or empty: this means only the default 90-day policy exists (not returned by this cmdlet per research finding)
- Record this finding: "No custom retention policies found. Default 90-day retention applies."

Step 3 — Validate retention meets zone minimums (PVAL-02):
- For each policy: map `RetentionDuration` to days using `$RetentionDurationMap`
- Compare against `$ZoneMinimumDays[$Zone]`
- Track: policies that meet minimum, policies that fall short
- If no custom policies exist, the effective retention is 90 days — compare against zone minimum
- Severity mapping:
  - Retention < zone minimum: "Critical"
  - Retention = zone minimum: "Passed"
  - Retention > zone minimum: "Passed" (with note)

Step 4 — Check record type coverage (PVAL-03):
- For each required record type in `$RequiredRecordTypes`:
  - Filter `$policies | Where-Object { $_.RecordTypes -contains $recordType }`
  - If no policy covers it: gap found (Severity="High")
  - If covered but retention too short: gap found (Severity="Critical")
  - If covered and meets minimum: Passed
- Also check for any policies with `RecordTypes` = $null or empty (these are "catch-all" policies that apply broadly)
- A catch-all policy DOES cover record types not explicitly listed

Step 5 — Build gap analysis:
- For each gap, create a PSCustomObject with: RecordType, Issue, CurrentRetentionDays, RequiredRetentionDays, Severity, Recommendation
- Recommendations should use proper regulatory language ("helps support" not "ensures")

Step 6 — Disconnect in finally block

**Return object structure (PSCustomObject):**
```
@{
    Timestamp          = (Get-Date -Format "o")
    ValidationType     = "PurviewRetention"
    Zone               = $Zone
    MinimumRequiredDays = $ZoneMinimumDays[$Zone]
    Checks             = @(
        @{ Name = "RetentionPoliciesExist"; Status = "Passed|Warning"; PolicyCount = N }
        @{ Name = "RetentionMeetsMinimum"; Status = "Passed|Failed"; Details = @(...) }
        @{ Name = "CopilotInteractionCoverage"; Status = "Passed|Failed"; RetentionDays = N }
        @{ Name = "PowerPlatformAdminCoverage"; Status = "Passed|Failed"; RetentionDays = N }
    )
    Gaps               = @(...)  # Array of gap objects
    OverallStatus      = "Passed|Failed|Warning"
    Confidence         = "HIGH"
    Reason             = "Summary"
}
```

IMPORTANT: The script connects to Security & Compliance PowerShell (Connect-IPPSSession / Connect-ComplianceSession), NOT Exchange Online PowerShell. This is correct for retention policy cmdlets.
