**Main logic:**

Build a common auth splat hashtable from the parameters to pass to each validator:
```powershell
$authParams = @{}
if ($Interactive) { $authParams.Interactive = $true }
if ($TenantId) { $authParams.TenantId = $TenantId }
if ($ClientId) { $authParams.ClientId = $ClientId }
if ($CertificateThumbprint) { $authParams.CertificateThumbprint = $CertificateThumbprint }
```

**Execute validators with isolation:**

Each validator runs inside its own try-catch so one failure doesn't block the others:

```powershell
$results = @{
    Timestamp = (Get-Date -Format "o")
    Zone = $Zone
    Validators = @{}
    OverallStatus = "Unknown"
}

# Validator 1: Unified Audit Log
Write-Host "`n=== Unified Audit Log Validation ===" -ForegroundColor Cyan
try {
    $ualParams = $authParams.Clone()
    if ($SkipCanaryValidation) { $ualParams.SkipCanaryValidation = $true }
    $ualParams.GracePeriodHours = $GracePeriodHours
    $ualParams.CanaryWaitSeconds = $CanaryWaitSeconds
    $results.Validators.UnifiedAuditLog = Test-UnifiedAuditLog @ualParams
    # Display status to console
}
catch {
    $results.Validators.UnifiedAuditLog = @{
        Status = "Error"
        Reason = $_.Exception.Message
    }
    Write-Warning "Unified Audit Log validation failed: $($_.Exception.Message)"
}

# Validator 2: Mailbox Audit (same pattern)
# Validator 3: Purview Retention (same pattern, pass -Zone)
```

**Compute overall status:**
- If ANY validator returns "Failed" or "Error": OverallStatus = "Failed"
- If ANY validator returns "Warning" or "GracePeriod" (but none Failed): OverallStatus = "Warning"
- If ALL validators return "Passed": OverallStatus = "Passed"
