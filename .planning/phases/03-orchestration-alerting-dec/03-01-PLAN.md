# Plan 03-01: DEC-DailyOrchestrator Power Automate Flow Definition

## Objective

Create the Power Automate flow definition JSON for the DEC-DailyOrchestrator that automates daily deny event extraction, correlation, and alert routing. Create the companion FLOW_SETUP.md guide for administrators to import, configure, and verify the flow.

## Context

Invoke-DailyDenyReport.ps1 already orchestrates all 3 extraction scripts, correlation, and (after Plan 03-03) alert evaluation. The Power Automate flow wraps this script in Azure Automation, adds scheduling, output parsing, alert routing, and error handling.

**Requirement:** ORC-01 — DEC-DailyOrchestrator Power Automate flow

**Dependency:** Plan 03-03 must complete first — the flow parses the alert evaluation output structure defined there.

## Tasks

### Task 1: Create dec-daily-orchestrator-flow.json

Create the Power Automate cloud flow definition as an exportable JSON template.

**Flow architecture:**

```
Trigger: Recurrence (daily, 06:00 UTC)

Variables:
  - varRunId (string): Unique run identifier
  - varTimestamp (string): ISO 8601 timestamp
  - varAlertRequired (boolean): false

Scope: Scope_Try
  │
  ├─ Initialize variables
  │
  ├─ Create Azure Automation Job
  │   - Runbook: Invoke-DailyDenyReport
  │   - Parameters:
  │     TenantId: @{triggerBody()?['DEC_TENANT_ID']}
  │     ClientId: @{triggerBody()?['DEC_CLIENT_ID']}
  │     KeyVaultName: @{triggerBody()?['DEC_KeyVaultName']}
  │     AppInsightsAppId: @{triggerBody()?['DEC_AppInsightsAppId']}
  │     WriteToDataverse: true
  │     DaysBack: 1
  │
  ├─ Do Until: Job.Status in ['Completed','Failed','Stopped','Suspended']
  │   └─ Get Job → Delay 60 seconds
  │
  ├─ Condition: Job.Status = 'Completed'
  │   ├─ Yes:
  │   │   ├─ Get Job Output
  │   │   ├─ Parse JSON (output schema matches Invoke-DailyDenyReport return object)
  │   │   │
  │   │   ├─ Create Dataverse record: fsi_denyvalidationhistory (audit-first)
  │   │   │   - Type: 'DailyOrchestration'
  │   │   │   - RecordsProcessed: @{body('Parse_JSON')?['TotalEventCount']}
  │   │   │   - Details: full parsed output
  │   │   │
  │   │   ├─ Condition: AlertResult.AlertsGenerated > 0
  │   │   │   ├─ Yes:
  │   │   │   │   ├─ Set varAlertRequired = true
  │   │   │   │   │
  │   │   │   │   ├─ Apply to each: AlertResult.Alerts
  │   │   │   │   │   ├─ Switch on Severity:
  │   │   │   │   │   │   ├─ Critical/High:
  │   │   │   │   │   │   │   ├─ Post adaptive card to Teams channel
  │   │   │   │   │   │   │   └─ Send email notification
  │   │   │   │   │   │   ├─ Warning:
  │   │   │   │   │   │   │   └─ Send email notification only
  │   │   │   │   │   │   └─ Info:
  │   │   │   │   │   │       └─ (no notification — logged in Dataverse only)
  │   │   │   └─ No: (no alerts — routine completion)
  │   │   │
  │   │   └─ Compose: Run summary for run history
  │   │
  │   └─ No (Job failed):
  │       ├─ Get Job error stream
  │       └─ Send CRITICAL email: "DEC Daily Orchestrator — Automation Job Failed"
  │
  └─ Timeout handler: If Do Until exceeds 30 min → Send CRITICAL email

Scope: Scope_Catch (runAfter: Scope_Try [Failed, TimedOut])
  ├─ Send CRITICAL email: "DEC Daily Orchestrator — Flow Failure"
  │   Body: Error details from Scope_Try result
  └─ Create Dataverse record: fsi_denyvalidationhistory
      - Type: 'FlowFailure'
      - Details: error information
```

**Connection references used:**
- `fsi_cr_dataverse_denyeventcorrelation` — Dataverse reads/writes
- `fsi_cr_office365_denyeventcorrelation` — Email notifications
- `fsi_cr_teams_denyeventcorrelation` — Teams adaptive cards

**Environment variable references:**
- `fsi_DEC_TeamsGroupId` — Target Teams group for adaptive cards
- `fsi_DEC_TeamsChannelId` — Target Teams channel for adaptive cards

### Task 2: Create FLOW_SETUP.md

Create the setup guide for administrators to import and configure the DEC-DailyOrchestrator flow.

**Document structure:**

```markdown
# DEC-DailyOrchestrator Flow Setup Guide

## Prerequisites
- Power Automate Premium license (Azure Automation connector)
- Azure Automation account with PowerShell 7.x runtime
- Runbook: Invoke-DailyDenyReport.ps1 published in Azure Automation
- Modules in Automation account: Az.Accounts, Az.KeyVault, ExchangeOnlineManagement
- DECClient.psm1 uploaded as Automation module
- Connection references bound in Power Platform admin center
- Teams group and channel created for alert delivery

## Import Flow
1. Navigate to Power Automate → My flows → Import
2. Upload `dec-daily-orchestrator-flow.json`
3. Map connection references to existing connections
4. Enable the flow

## Configure Environment Variables
1. Navigate to Power Platform admin center → Environments → {env} → Environment variables
2. Set `fsi_DEC_TeamsGroupId` and `fsi_DEC_TeamsChannelId`

## Azure Automation Setup
1. Create Automation account (if not exists)
2. Upload PowerShell runbook: Invoke-DailyDenyReport.ps1
3. Upload supporting scripts: all Export-*.ps1, Invoke-DenyEventCorrelation.ps1, Invoke-DECAlertEvaluation.ps1
4. Upload module: DECClient.psm1 (as zip)
5. Import required modules from Gallery: Az.Accounts, Az.KeyVault, ExchangeOnlineManagement
6. Configure Run As account or Managed Identity

## Verify
1. Trigger flow manually → Monitor → confirm Automation job starts
2. Verify Dataverse validation history record created
3. Verify Teams adaptive card (if alerts generated)
4. Verify email notification (if Critical/High alerts)

## Troubleshooting
- Job timeout: Check Automation account activity for hung jobs
- Connection errors: Re-authorize connection references
- No alerts: Verify fsi_DEC_AnomalyThresholdSigma environment variable
- Teams errors: Verify group/channel ID environment variables
```
