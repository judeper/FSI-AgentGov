# Phase 4, Plan 1: Remediation Runbook Core

## Goal

Create `Enable-AuditLogging.ps1` with parameters, MI authentication, remediation flow (tenant Purview, org-level Dataverse, entity-level audit), and compliance record updates.

## Tasks

### Task 1: Runbook Parameters and Requires
**Acceptance:** CmdletBinding with SupportsShouldProcess, 5 parameters per REM-01, #Requires -Version 7.2 + module requires.

### Task 2: MI Authentication
**Acceptance:** Power Platform via Add-PowerAppsAccount with MI token, Exchange Online via Connect-ExchangeOnline -ManagedIdentity, Dataverse token via Get-DataverseToken.

### Task 3: Target Determination
**Acceptance:** If EnvironmentId provided, target that specific environment. Otherwise query Dataverse for fsi_compliancestatus=100000001 (Non-Compliant).

### Task 4: Tenant-Wide Purview Enablement
**Acceptance:** If EnableTenantUnifiedAudit switch is set, call Set-AdminConfig with tenant-wide change warning.

### Task 5: Per-Environment Remediation
**Acceptance:** Org-level audit via PATCH /api/data/v9.2/organizations({id}), entity-level via PUT EntityDefinitions for 6 entities.

### Task 6: Compliance Record Update
**Acceptance:** After successful remediation, update Dataverse record to Compliant via Write-DataverseComplianceRecord.
