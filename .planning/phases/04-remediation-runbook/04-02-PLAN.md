# Phase 4, Plan 2: Remediation Output and Error Handling

## Goal

Integrate output formatting, WhatIf simulation, post-remediation validation, error handling, and CSV export into the Enable-AuditLogging.ps1 runbook.

## Tasks

### Task 1: WhatIf Logic
**Acceptance:** When -WhatIf is set, output "[WHATIF] Would enable..." messages without making changes.

### Task 2: Validation Pass
**Acceptance:** After 5-second wait, re-read org settings and entity settings to confirm changes. Validation failures set status="Validation Failed".

### Task 3: Console Output
**Acceptance:** Numbered progress steps, per-environment status, remediation summary.

### Task 4: CSV Export
**Acceptance:** Export results to $env:TEMP with timestamp in filename.

### Task 5: Error Handling
**Acceptance:** Per-environment try/catch (continue processing), finally block disconnects Exchange Online and Power Platform.
