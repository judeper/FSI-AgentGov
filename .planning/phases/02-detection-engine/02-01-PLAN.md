# Plan 02-01: Detector Flow JSON + Adaptive Card Template

## Objective

Create `src/uasd-detector-scan-agents.json` implementing the full UASD detection flow as an importable Power Automate cloud flow, and `src/adaptive-card-uasd-alert.json` as the Teams alert template. The flow enumerates agents via BAP API, evaluates 5 violation rules against Dataverse reference data, creates violation records, and posts adaptive card alerts to Teams.

## Tasks

### Task 1: Create `src/uasd-detector-scan-agents.json`

**Create** the detector flow JSON following the exact structural pattern from `src/caa-daily-compliance-flow.json`.

**Top-level structure:**
```json
{
  "properties": {
    "connectionReferences": { ... },
    "definition": {
      "$schema": "...",
      "contentVersion": "1.0.0.0",
      "parameters": { "$connections", "$authentication" },
      "triggers": { ... },
      "actions": { ... }
    },
    "displayName": "fsi-UASD-Detector-ScanAgents",
    "description": "Scans Copilot Studio agents for unsafe sharing configurations and records violations in Dataverse.",
    "state": "Started"
  },
  "schemaVersion": "1.0.0.0"
}
```

#### 1a. Connection References (2)

| Logical Name | Connector ID | Source |
|---|---|---|
| `fsi_cr_dataverse_sharingdetector` | `shared_commondataserviceforapps` | Invoker |
| `fsi_cr_teams_sharingdetector` | `shared_teams` | Invoker |

#### 1b. Trigger — Daily Recurrence

```json
"Recurrence_Daily_0600_UTC": {
  "type": "Recurrence",
  "recurrence": {
    "frequency": "Day",
    "interval": 1,

```

Default 24h. Administrators adjust recurrence post-import per `fsi_UASD_ScanFrequencyHours`.

#### 1c. Variable Initialization (8 variables, sequential chain)

| Order | Variable | Type | Default | Description |
|-------|----------|------|---------|-------------|
| 1 | `DataverseUrl` | string | "" | Dataverse environment URL |
| 2 | `HomeTenantId` | string | "" | Home tenant GUID for cross-tenant rule |
| 3 | `TeamsGroupId` | string | "" | Teams group for alert notifications |
| 4 | `TeamsChannelId` | string | "" | Teams channel for alert notifications |
| 5 | `ScanRunId` | string | `@{guid()}` | Unique ID for this scan run |
| 6 | `ViolationCards` | array | [] | Accumulator for adaptive card violation elements |
| 7 | `TotalAgents` | integer | 0 | Counter for scanned agents |
| 8 | `ViolationCount` | integer | 0 | Counter for violations found |

Each uses `runAfter` on the preceding variable.

#### 1d. Scope_Try — Main Detection Logic

**Action sequence inside Scope_Try:**

1. **Generate_Scan_Run_Id** — `Compose` action: `@{guid()}`

2. **Load_Approved_Groups** — Dataverse `ListRecords` on `fsi_approvedsecuritygroups`:
   - `$filter`: `fsi_is_active eq true`
   - `$select`: `fsi_entraid_group_id,fsi_group_display_name,fsi_zone`

3. **Initialize_Approved_Group_Ids** — `Compose` to extract group IDs array:
   - `@{body('Load_Approved_Groups')?['value']}` (used for in-memory matching)

4. **Load_Sharing_Policy** — Dataverse `ListRecords` on `fsi_sharingpolicies`:
   - `$filter`: `fsi_is_active eq true`
   - `$top`: 1
   - `$select`: `fsi_max_individual_shares,fsi_governance_zone`

5. **Set_Max_Individual_Shares** — `Compose`:
   - `@{first(body('Load_Sharing_Policy')?['value'])?['fsi_max_individual_shares']}` (default 100)

6. **List_Environments** — HTTP action to BAP API:
   - Method: `GET`
   - URI: `https://api.bap.microsoft.com/providers/Microsoft.BusinessAppPlatform/scopes/admin/environments?api-version=2016-11-01`
   - Authentication: `ManagedServiceIdentity`, audience `https://api.bap.microsoft.com`

7. **Apply_to_Each_Environment** — `Foreach` over environment list:
   - `foreach`: `@{body('List_Environments')?['value']}`
   - `operationOptions`: `Sequential`
   - Contains nested actions:

   7a. **Set_Environment_Id** — `Compose`: `@{items('Apply_to_Each_Environment')?['name']}`

   7b. **Set_Environment_Name** — `Compose`: `@{items('Apply_to_Each_Environment')?['properties']?['displayName']}`

   7c. **List_Agents_In_Environment** — HTTP action to BAP API:
   - Method: `GET`
   - URI: `https://api.bap.microsoft.com/providers/Microsoft.BusinessAppPlatform/scopes/admin/environments/@{outputs('Set_Environment_Id')}/bots?api-version=2021-04-01`
   - Authentication: MSI, audience `https://api.bap.microsoft.com`

   7d. **Apply_to_Each_Agent** — nested `Foreach`:
   - `foreach`: `@{body('List_Agents_In_Environment')?['value']}`
   - `operationOptions`: `Sequential`
   - Contains:

     7d-i. **Set_Agent_Id** — `Compose`: `@{items('Apply_to_Each_Agent')?['properties']?['name']}`

     7d-ii. **Set_Agent_Name** — `Compose`: `@{items('Apply_to_Each_Agent')?['properties']?['displayName']}`

     7d-iii. **Get_Agent_Principals** — HTTP action to BAP API:
     - Method: `GET`
     - URI: `https://api.bap.microsoft.com/providers/Microsoft.BusinessAppPlatform/scopes/admin/environments/@{outputs('Set_Environment_Id')}/bots/@{outputs('Set_Agent_Id')}/permissions?api-version=2021-04-01`
     - Authentication: MSI, audience `https://api.bap.microsoft.com`

     7d-iv. **Parse_Principals** — `ParseJson` on response body

     7d-v. **Compute_Sharing_Scope** — `Compose` to classify highest sharing scope from principals (Organization > Public > SecurityGroup > Individual)

     7d-vi. **Compute_Evidence_Hash** — `Compose` to create SHA-256 hash of principals JSON

     7d-vii. **Upsert_Agent_Sharing_Setting** — Dataverse `CreateRecord` (or update) on `fsi_agentsharingsettings`:
     - `fsi_agent_id`: agent ID
     - `fsi_agent_name`: agent display name
     - `fsi_environment_id`: environment ID
     - `fsi_environment_name`: environment display name
     - `fsi_sharing_scope`: computed scope value
     - `fsi_principal_count`: `@{length(body('Parse_Principals')?['value'])}`
     - `fsi_principals_json`: `@{string(body('Parse_Principals')?['value'])}`
     - `fsi_auth_mode`: from agent properties if available
     - `fsi_last_scanned`: `@{utcNow()}`

     7d-viii. **Increment_Total_Agents** — `IncrementVariable` on `TotalAgents`

     7d-ix. **Rule_Evaluation_Scope** — `Scope` containing 5 condition branches:

     **Rule 1: Check_ORG_WIDE_SHARING** — `Condition`:
     - Expression: any principal where `type == "Organization"`
     - True branch: Check for existing Open violation → Check for active exception → `Create_Violation_ORG_WIDE`:
       - `fsi_violation_type`: 0
       - `fsi_severity`: 4 (Failed/Critical)
       - `fsi_description`: "Agent '{name}' in environment '{env}' is shared with the entire organization"
       - `fsi_evidence_json`: principals JSON
       - `fsi_evidence_hash`: SHA-256
       - Increment ViolationCount, Append to ViolationCards

     **Rule 2: Check_PUBLIC_INTERNET_LINK** — `Condition`:
     - Expression: any principal with public/anonymous scope
     - True branch: same violation creation pattern
       - `fsi_violation_type`: 1
       - `fsi_severity`: 4 (Failed/Critical)

     **Rule 3: Check_UNAPPROVED_GROUP** — `Condition`:
     - Expression: any Group-type principal whose ID NOT in approved groups list
     - True branch: same pattern
       - `fsi_violation_type`: 2
       - `fsi_severity`: 5 (Error/High)

     **Rule 4: Check_EXCESSIVE_INDIVIDUAL** — `Condition`:
     - Expression: count of User-type principals > Max_Individual_Shares
     - True branch: same pattern
       - `fsi_violation_type`: 3
       - `fsi_severity`: 2 (Warning/Medium)

     **Rule 5: Check_CROSS_TENANT_ACCESS** — `Condition`:
     - Expression: any principal with tenant ID ≠ HomeTenantId
     - True branch: same pattern
       - `fsi_violation_type`: 4
       - `fsi_severity`: 5 (Error/High)

8. **Check_Violations_Found** — `Condition`: `ViolationCount > 0`
   - True branch:
     - **Compose_Scan_Summary** — summary object with TotalAgents, ViolationCount, ScanRunId, timestamp
     - **Compose_Adaptive_Card** — build card from template with summary + ViolationCards array
     - **Post_Teams_Alert** — OpenApiConnection to Teams `PostCardToConversation`:
       - `body/recipient/groupId`: `@{variables('TeamsGroupId')}`
       - `body/recipient/channelId`: `@{variables('TeamsChannelId')}`
       - `body/messageBody`: `@{string(outputs('Compose_Adaptive_Card'))}`

#### 1e. Scope_Catch — Error Handling

```json
"Scope_Catch": {
  "type": "Scope",
  "runAfter": { "Scope_Try": ["Failed", "TimedOut"] },
  "actions": {
    "Compose_Error_Card": { ... },
    "Post_Error_Notification": {
      "type": "OpenApiConnection",
      "inputs": {
        "parameters": {
          "poster": "Flow bot",
          "location": "Channel",
          "body/recipient/groupId": "@variables('TeamsGroupId')",
          "body/recipient/channelId": "@variables('TeamsChannelId')",
          "body/messageBody": "..."
        },
        "host": {
          "apiId": "/providers/Microsoft.PowerApps/apis/shared_teams",
          "connectionName": "shared_teams",
          "operationId": "PostCardToConversation"
        }
      }
    }
  }
}
```

**Exception check pattern** (used before each violation creation):

1. **Check_Active_Exception_{RuleN}** — Dataverse `ListRecords` on `fsi_sharingexceptions`:
   - `$filter`: `fsi_agent_id eq '{agentId}' and fsi_violation_type eq {violationType} and fsi_exception_status eq 1 and fsi_expires_at ge {utcNow()}`
   - `$top`: 1

2. **Has_Active_Exception_{RuleN}** — `Condition`: length of exception results > 0
   - True: skip violation creation
   - False: proceed with duplicate check → creation

3. **Check_Existing_Violation_{RuleN}** — Dataverse `ListRecords` on `fsi_sharingviolations`:
   - `$filter`: `fsi_agent_id eq '{agentId}' and fsi_violation_type eq {violationType} and fsi_violation_status eq 0`
   - `$top`: 1

4. **Is_Duplicate_{RuleN}** — `Condition`: length > 0
   - True: skip creation
   - False: create violation record

### Task 2: Create `src/adaptive-card-uasd-alert.json`

**Create** the UASD adaptive card template following the exact pattern from `src/adaptive-card-caa-alert.json`.

**Card structure:**

```
AdaptiveCard v1.4
├── headerSection (Container, style="${SeverityStyle}")
│   ├── Title: "[ALERT] Agent Sharing Violation — ${OverallStatus}"
│   ├── Subtitle: "Unrestricted Agent Sharing Detector · ${ScannedAt}"
│   └── Severity Badge: "${SeverityBadge}"
├── scanSummarySection (Container)
│   └── ColumnSet with 2 FactSets:
│       FactSet 1: Status, Scanned, Scan Run ID
│       FactSet 2: Total Agents, Violations, Environments
├── violationsSection (Container, $when: ${ViolationCount} > 0)
│   ├── Header: "Sharing Violations (${ViolationCount})"
│   └── Repeating violationItem template:
│       ├── ColumnSet: ViolationType | AgentName | EnvironmentName
│       └── FactSet: Severity, Description, Principal Details, Detected At
├── Actions:
│   ├── "View in PPAC" → Action.OpenUrl (PPAC admin portal)
│   ├── "Run Audit Script" → Action.OpenUrl (link to Invoke-SharingAudit.ps1 docs)
│   └── "View Documentation" → Action.OpenUrl (deployment guide)
└── _metadata (documentation section — not rendered):
    ├── templateName, version, solution
    ├── Severity color/style mappings
    ├── Template variable inventory
    └── Flow integration notes
```

**Severity mapping for card styling:**

| Severity | Container Style | TextBlock Color | Badge |
|----------|----------------|-----------------|-------|
| Critical (Failed/4) | attention | Attention | 🔴 |
| High (Error/5) | warning | Warning | 🟠 |
| Medium (Warning/2) | accent | Accent | 🟡 |
| Low (GracePeriod/3) | default | Default | 🟢 |

**Template variables (scalar):**

| Variable | Type | Source |
|----------|------|--------|
| `SeverityStyle` | string | Container style from highest severity |
| `SeverityColor` | string | TextBlock color from highest severity |
| `SeverityBadge` | string | Emoji badge from highest severity |
| `OverallStatus` | string | "ViolationsFound" or "Clean" |
| `ScannedAt` | string | ISO 8601 timestamp |
| `ScanRunId` | string | GUID for the scan run |
| `TotalAgents` | integer | Agents scanned |
| `ViolationCount` | integer | Total violations |
| `EnvironmentsScanned` | integer | Environments scanned |

**Template variables (per violation):**

| Variable | Type | Source |
|----------|------|--------|
| `ViolationType` | string | Human-readable rule name |
| `AgentName` | string | Agent display name |
| `EnvironmentName` | string | Environment display name |
| `Severity` | string | Critical/High/Medium/Low |
| `Description` | string | Violation description |
| `PrincipalDetails` | string | Relevant principal info |
| `DetectedAt` | string | Detection timestamp |

**`msteams` width:** `"Full"` for full-width rendering.
