# Phase 3 Plan A: Detection Runbook Core

## Goal

Create the detection runbook that authenticates via Managed Identity, scans all Power Platform environments, determines audit compliance status, and writes results to Dataverse.

## Tasks

### Task 1: Runbook parameters and requires

- DataverseEnvironmentUrl (mandatory)
- TenantDomain (mandatory)
- NotificationFromAddress (optional)
- NotificationToAddresses (optional, comma-separated)
- SendEmail (switch, default false)
- #Requires PowerShell 7.2
- #Requires Microsoft.PowerApps.Administration.PowerShell 2.0+
- #Requires ExchangeOnlineManagement 3.0+

### Task 2: MI Authentication

- Get-ManagedIdentityToken for Power Platform
- Add-PowerAppsAccount with MI token
- Connect-ExchangeOnline -ManagedIdentity -Organization $TenantDomain

### Task 3: Environment scanning

- Get-AdminPowerAppEnvironment to enumerate all environments
- Per-environment: detect Dataverse provisioned status
- Check Purview unified audit via Get-AdminConfig
- Check Dataverse audit via Web API /api/data/v9.2/organizations
- Search-UnifiedAuditLog for recent events (last 7 days)

### Task 4: Compliance determination

- Dataverse environments: require BOTH Purview + Dataverse audit enabled
- Non-Dataverse environments: require Purview only
- Write compliance record via Write-DataverseComplianceRecord
