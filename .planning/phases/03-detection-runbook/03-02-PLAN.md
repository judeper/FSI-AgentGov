# Phase 3 Plan B: Output, Email, Error Handling

## Goal

Add output formatting, CSV export, email notification, and error handling to the detection runbook.

## Tasks

### Task 1: Console output
- Numbered progress steps (Step 1/N format)
- Per-environment status table
- Compliance summary at end

### Task 2: CSV export
- Export results to $env:TEMP with timestamped filename
- Include all environment fields

### Task 3: HTML email notification
- Conditional on -SendEmail switch
- HTML summary table with compliance counts
- CSV file as attachment via Send-ComplianceNotification

### Task 4: Error handling
- Per-environment try/catch: set ComplianceStatus=Error, capture error message, continue
- Fatal auth failures: throw immediately
- Finally block: Disconnect-ExchangeOnline, Remove-PowerAppsAccount
