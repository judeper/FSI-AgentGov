  <action>
Create new script for manual drift detection with the following specifications:

**Parameters:**
```powershell
param(
    [Parameter(Mandatory = $true)]
    [string]$Environment,              # Dataverse environment URL

    [Parameter(Mandatory = $false)]
    [string]$AgentId,                   # Optional: scan single agent; if omitted, scan all

    [Parameter(Mandatory = $false)]
    [int]$Minutes = 15,                 # Lookback window (default 15 per CONTEXT.md)

    [Parameter(Mandatory = $false)]
    [string]$TenantId = $env:AZURE_TENANT_ID,

    [Parameter(Mandatory = $false)]
    [string]$ClientId = $env:AZURE_CLIENT_ID,

    [Parameter(Mandatory = $false)]
    [string]$ClientSecret = $env:AZURE_CLIENT_SECRET
)
```

**Main logic:**

1. **Get active scopes from Dataverse**:
   - Query `fsi_agentscopes?$filter=fsi_status eq 2` (Active status)
   - If AgentId provided, add filter for specific agent
   - Extract allowed resources from each scope (JSON arrays)

2. **Query audit events**:
   - Use Office 365 Management API (same pattern as New-AgentBaseline.ps1)
   - Time window: now minus $Minutes to now
   - Filter for CopilotInteraction events (RecordType 261)

3. **Compare baseline vs actual** (per RESEARCH.md Pattern 4):
   - For each audit event:
     - Match event to agent scope via agent ID + environment ID
     - If no scope found: log "No Baseline Defined" violation type
     - Parse accessed resources from event
     - Compare each resource against allowed lists
     - Create violation record if resource not in allowed list

4. **Create violation records in Dataverse**:
   - POST to `fsi_scopeviolations` table
   - Include: fsi_name, fsi_agentscopeid, fsi_violationtype, fsi_resourcename, fsi_resourceurl, fsi_severity, fsi_status (1=Open), fsi_detectedon, fsi_auditrecordid, fsi_accessdetails

5. **Severity assignment** (per README.md):
   - Connector violation: High (2)
   - SharePoint site violation: Medium (3)
   - Dataverse table violation: Medium (3)
   - External API violation: High (2)
   - No baseline: High (2)

6. **Output**:
   - Write-Host summary: "Scanned X agents, found Y violations"
   - Return violation objects for pipeline use
   - Exit 0 if successful (even if violations found)

**Header:**
```powershell
#Requires -Version 7.0

<#
.SYNOPSIS
    Performs manual drift detection scan for AI agents.

.DESCRIPTION
    Queries the Unified Audit Log for CopilotInteraction events and compares
    accessed resources against declared agent scopes. Creates violation records
    for any out-of-scope access.

.PARAMETER Environment
    The Dataverse environment URL (e.g., https://contoso.crm.dynamics.com).

.PARAMETER AgentId
    Optional. The Copilot Studio agent ID to scan. If omitted, scans all active agents.

.PARAMETER Minutes
    Lookback window in minutes. Default: 15.

.EXAMPLE
    .\Invoke-DriftScan.ps1 -Environment "https://contoso.crm.dynamics.com"
    Scans all active agents for the last 15 minutes.

.EXAMPLE
    .\Invoke-DriftScan.ps1 -Environment "https://contoso.crm.dynamics.com" -AgentId "12345..." -Minutes 60
    Scans specific agent for the last 60 minutes.
#>
```
