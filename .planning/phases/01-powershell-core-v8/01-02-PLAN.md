# Plan 01-02: Compliance Comparison and Content Moderation Cross-Check

## Objective

Build Compare-FileUploadCompliance.ps1 that evaluates each agent's file upload settings against zone baselines with severity classification. Implement content moderation cross-check (FUS-05): agents with file uploads enabled must meet minimum moderation level.

## Requirements Covered

- **FUS-03**: Compliance comparison with severity classification
- **FUS-05**: Content moderation cross-check for file upload agents

## Actions

1. Build Compare-FileUploadCompliance.ps1:
   - Accept pipeline input from Get-AgentFileUploadSettings
   - Load zone baselines from fileupload-baseline.json
   - Compare each agent's FileUploadEnabled status against zone policy
   - Classify violations by severity (Critical/High/Medium/Warning)
   - Include regulatory context (FINRA 4511, SEC 17a-3, GLBA 501(b))

2. Implement content moderation cross-check:
   - For agents with file uploads enabled, check content moderation level
   - Zone 2: require High or Highest moderation
   - Zone 3: require Highest moderation (if file uploads are enabled at all)
   - Generate separate finding for insufficient moderation on file-upload-enabled agents

3. Build Get-ExpectedFileUploadPolicy.ps1 helper:
   - Load baseline JSON
   - Return expected policy for a given zone
   - Include severity matrix for violations

## Success Criteria

- [ ] Compare-FileUploadCompliance.ps1 evaluates settings against zone baselines
- [ ] Severity classification (Critical/High/Medium/Warning) operational
- [ ] Content moderation cross-check flags insufficient moderation on file-upload agents
- [ ] Regulatory context included in violation output
