# Plan 01-01: Solution Scaffold, FUSClient Module, and Zone Lookup

## Objective

Create the file-upload-security solution scaffold in FSI-AgentGov-Solutions following the Tier 2 pattern (mirrors content-moderation-monitor structure). Build the FUSClient.psm1 module for Dataverse bot table queries to retrieve per-agent file upload status, and implement zone classification lookup.

## Requirements Covered

- **FUS-01**: Agent enumeration and file upload status retrieval
- **FUS-02**: Zone classification for file upload policy
- **INF-01**: Tier 2 scaffold with shared helpers

## Actions

1. Create solution directory structure:
   ```
   file-upload-security/
   ├── README.md
   ├── CHANGELOG.md
   ├── docs/
   ├── flows/.gitkeep
   ├── scripts/
   │   ├── private/
   │   │   ├── FUSClient.psm1
   │   │   ├── Connect-EnvironmentDataverse.ps1
   │   │   ├── Get-ZoneClassification.ps1
   │   │   ├── Test-ParameterValidation.ps1
   │   │   └── Get-ExpectedFileUploadPolicy.ps1
   │   └── Get-AgentFileUploadSettings.ps1
   ├── src/
   │   └── dataverse/
   │       ├── tables/.gitkeep
   │       ├── environment-variables/.gitkeep
   │       └── connection-references/.gitkeep
   └── templates/
       └── fileupload-baseline.json
   ```

2. Build FUSClient.psm1 with:
   - Connect-FUSDataverse (auth wrapper)
   - Get-AgentFileUploadStatus (query bot table for file upload enabled/disabled)
   - Baseline CRUD operations
   - Validation history writes
   - Violation record management

3. Build Get-AgentFileUploadSettings.ps1:
   - Enumerate environments via Get-AdminPowerAppEnvironment
   - Per-environment: query Dataverse bot table for file upload status
   - Return structured objects with agent name, environment, zone, file upload enabled status

4. Build zone lookup helper and baseline template

## Success Criteria

- [ ] Solution scaffold matches Tier 2 pattern
- [ ] FUSClient.psm1 provides Dataverse queries for file upload metadata
- [ ] Get-AgentFileUploadSettings.ps1 enumerates agents with file upload status
- [ ] Zone classification operational
- [ ] Baseline template defines zone-specific file upload policies
