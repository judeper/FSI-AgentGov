# Plan 01-01: Dataverse Schema Script + Option Sets

## Objective

Create `scripts/create_uasd_dataverse_schema.py` implementing the full 5-table Dataverse schema for the Unrestricted Agent Sharing Detector solution, including 6 solution-specific option sets, shared option set reuse, inline agent identity fields, and seed data insertion for the default sharing policy.

## Tasks

### Task 1: Create `scripts/create_uasd_dataverse_schema.py`

**Create** `scripts/create_uasd_dataverse_schema.py` following the exact pattern from `scripts/create_dataverse_schema.py` (CAA schema script).

**Structure:**
- Module docstring listing all 5 tables with usage examples
- Import block: `argparse`, `logging`, `sys`, `typing`, `CAAClient`
- Shared option set reference dict (`SHARED_OPTIONSETS_REFERENCED`)
- Solution-specific option set dict (`SOLUTION_OPTIONSETS`)
- Column helper functions (reuse identical pattern: `_label`, `_string_col`, `_memo_col`, `_boolean_col`, `_datetime_col`, `_integer_col`, `_picklist_col`, plus new `_local_picklist_col` for solution-specific option sets)
- Table definition functions (5 tables)
- Column definition functions (5 tables)
- Schema orchestration: `create_solution_optionsets()`, `create_schema()`
- Seed data function: `seed_default_policy()`
- CLI entry point with identical args to CAA script

### Task 2: Define 6 Solution-Specific Option Sets

Define `SOLUTION_OPTIONSETS` dictionary with these option sets:

1. **`fsi_UASD_sharingscope`** — Individual (0), SecurityGroup (1), Organization (2), Public (3)
2. **`fsi_UASD_violationtype`** — ORG_WIDE_SHARING (0), PUBLIC_INTERNET_LINK (1), UNAPPROVED_GROUP (2), EXCESSIVE_INDIVIDUAL (3), CROSS_TENANT_ACCESS (4)
3. **`fsi_UASD_violationstatus`** — Open (0), Remediated (1), Exception_Granted (2), False_Positive (3)
4. **`fsi_UASD_exceptionstatus`** — Pending (0), Approved (1), Denied (2), Expired (3)
5. **`fsi_UASD_authmode`** — ManualAuthentication (0), NoAuthentication (1)
6. **`fsi_UASD_dataclassification`** — Public (0), Internal (1), Confidential (2), HighlyConfidential (3)

### Task 3: Define 5 Table Definitions with All Columns

**Table 1: `fsi_AgentSharingSetting`** (Organization-owned, mutable current state)
- Primary name: `fsi_agent_name`
- Agent identity: `fsi_agent_id` (Text 100, required), `fsi_agent_name` (Text 200, required), `fsi_environment_id` (Text 100, required)
- Sharing: `fsi_sharing_scope` (picklist → `fsi_UASD_sharingscope`, required), `fsi_principal_count` (Integer), `fsi_principals_json` (Memo — raw BAP principal array)
- Auth: `fsi_auth_mode` (picklist → `fsi_UASD_authmode`)
- Metadata: `fsi_last_scanned` (DateTime, required), `fsi_environment_name` (Text 200)

**Table 2: `fsi_SharingViolation`** (Organization-owned, append-only audit trail)
- Primary name: `fsi_violation_name` (auto-generated: `{agent_name}-{violation_type}-{date}`)
- Agent identity: `fsi_agent_id`, `fsi_agent_name`, `fsi_environment_id`
- Violation: `fsi_violation_type` (picklist → `fsi_UASD_violationtype`, required), `fsi_violation_status` (picklist → `fsi_UASD_violationstatus`, required)
- Severity: `fsi_severity` (picklist → `fsi_acv_severity`, required)
- Details: `fsi_description` (Memo), `fsi_evidence_json` (Memo — principals snapshot), `fsi_evidence_hash` (Text 64 — SHA-256)
- Remediation: `fsi_remediated_at` (DateTime), `fsi_remediated_by` (Text 256)
- Metadata: `fsi_detected_at` (DateTime, required), `fsi_scan_run_id` (Text 100)

**Table 3: `fsi_SharingException`** (Organization-owned, mutable status transitions)
- Primary name: `fsi_exception_name`
- Agent identity: `fsi_agent_id`, `fsi_agent_name`, `fsi_environment_id`
- Exception: `fsi_exception_status` (picklist → `fsi_UASD_exceptionstatus`, required), `fsi_violation_type` (picklist → `fsi_UASD_violationtype`, required)
- Justification: `fsi_business_justification` (Memo, required), `fsi_data_classification` (picklist → `fsi_UASD_dataclassification`, required)
- Approval: `fsi_requested_by` (Text 256, required), `fsi_approved_by_security` (Text 256), `fsi_approved_by_data_owner` (Text 256)
- Lifecycle: `fsi_requested_at` (DateTime, required), `fsi_approved_at` (DateTime), `fsi_expires_at` (DateTime, required)

**Table 4: `fsi_ApprovedSecurityGroup`** (Organization-owned, admin-managed)
- Primary name: `fsi_group_display_name`
- Group: `fsi_entraid_group_id` (Text 100, required), `fsi_group_display_name` (Text 200, required)
- Scope: `fsi_zone` (picklist → `fsi_acv_zone`, required)
- Status: `fsi_is_active` (Boolean, default true), `fsi_added_by` (Text 256), `fsi_added_at` (DateTime)

**Table 5: `fsi_SharingPolicy`** (Organization-owned, threshold tuning)
- Primary name: `fsi_policy_name`
- Policy: `fsi_max_individual_shares` (Integer, required — default 100), `fsi_governance_zone` (picklist → `fsi_acv_zone`, required)
- Auto-remediation: `fsi_auto_remediate_public_link` (Boolean, default false)
- Status: `fsi_is_active` (Boolean, default true), `fsi_updated_by` (Text 256), `fsi_updated_at` (DateTime)

### Task 4: Implement Seed Data Function

Create `seed_default_policy()` that inserts the default `fsi_SharingPolicy` row:
- `fsi_policy_name`: "Default Sharing Policy"
- `fsi_max_individual_shares`: 100
- `fsi_governance_zone`: 0 (All/Unclassified)
- `fsi_auto_remediate_public_link`: false
- `fsi_is_active`: true
- Idempotent: check by name before inserting
