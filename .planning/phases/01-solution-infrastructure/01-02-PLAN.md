# Plan 01-02: Environment Variables + Connection References

## Objective

Create `scripts/create_uasd_environment_variables.py` and `scripts/create_uasd_connection_references.py` implementing the environment variables and connection references required by the Unrestricted Agent Sharing Detector solution flows and scripts.

## Tasks

### Task 1: Create `scripts/create_uasd_environment_variables.py`

**Create** `scripts/create_uasd_environment_variables.py` following the exact pattern from `scripts/create_environment_variables.py` (CAA environment variables script).

**4 environment variables:**

| Schema Name | Display Name | Type | Default | Description |
|------------|-------------|------|---------|-------------|
| `fsi_UASD_AutoRemediatePublicLink` | UASD - Auto Remediate Public Link | String (100000000) | "false" | Whether public internet link violations are auto-remediated without approval |
| `fsi_UASD_ScanFrequencyHours` | UASD - Scan Frequency (Hours) | Decimal (100000001) | "24" | Detector flow recurrence interval in hours |
| `fsi_UASD_HomeTenantId` | UASD - Home Tenant ID | String (100000000) | "" | Home tenant GUID for cross-tenant access detection |
| `fsi_UASD_DefaultExceptionDays` | UASD - Default Exception Days | Decimal (100000001) | "90" | Default exception duration before expiration |

**Structure:**
- Module docstring with usage examples
- `ENVIRONMENT_VARIABLES` list of dicts with `schema_name`, `display_name`, `type`, `default_value`, `description`
- `create_environment_variable()` — single var (idempotent)
- `create_environment_variables()` — all vars with counts
- CLI entry point with identical args to CAA script

**Acceptance criteria:**
- [ ] 4 environment variables defined with correct types and defaults
- [ ] Idempotent: checks existence before creating
- [ ] `--dry-run` mode prints `[DRY-RUN] Would create ...`
- [ ] Same CLI args as existing environment variables script
- [ ] Script runs without import errors

### Task 2: Create `scripts/create_uasd_connection_references.py`

**Create** `scripts/create_uasd_connection_references.py` following the exact pattern from `scripts/create_connection_references.py` (CAA connection references script).

**2 connection references:**

| Logical Name | Display Name | Connector ID | Description |
|-------------|-------------|-------------|-------------|
| `fsi_cr_dataverse_sharingdetector` | Dataverse - Sharing Detector | `shared_commondataserviceforapps` | Table CRUD for sharing settings, violations, exceptions, policies |
| `fsi_cr_teams_sharingdetector` | Teams - Sharing Detector | `shared_teams` | Adaptive card alert delivery for sharing violations |

**Structure:**
- Module docstring with usage examples
- `CONNECTION_REFERENCES` list of dicts with `logical_name`, `display_name`, `connector_id`, `description`
- `create_connection_reference()` — single ref (idempotent, HTTP error handling)
- `create_connection_references()` — all refs with counts
- CLI entry point with identical args to CAA script

**Acceptance criteria:**
- [ ] 2 connection references defined with correct connector IDs
- [ ] Naming follows `fsi_cr_{connector}_{solution}` convention
- [ ] Idempotent: checks existence before creating
- [ ] HTTP error handling for invalid connector IDs (400/404)
- [ ] `--dry-run` mode supported
- [ ] Same CLI args as existing connection references script
