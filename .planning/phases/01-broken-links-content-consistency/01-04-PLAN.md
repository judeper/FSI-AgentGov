## Tasks

### Task 1: High-Instance Playbooks (4 files, ~29 instances)

These files have the most Tier references and require careful per-instance conversion.

**2.2/portal-walkthrough.md** (11 instances):
- Zone definition text: `Tier 1/2/3` → `Zone 1/2/3`
- Environment group names: `Tier 1`/`Tier 2`/`Tier 3` → `Zone 1`/`Zone 2`/`Zone 3`
- Section headers: `### Tier 1 - Personal Productivity Rules` → `### Zone 1 - Personal Productivity Rules` (and Tier 2, Tier 3)
- YAML examples: `(Tier 3)` → `(Zone 3)`
- Inline: `Tier 2/3 groups` → `Zone 2/3 groups`

**1.5/portal-walkthrough.md** (10 instances):
- Policy labels: `**Tier 1**: Audit only` → `**Zone 1**: Audit only` (and Tier 2, 3)
- Inline: `Tier 1-2:` → `Zone 1-2:`
- Table rows: `Tier 1`/`Tier 2`/`Tier 3` → `Zone 1`/`Zone 2`/`Zone 3`

**1.11/verification-testing.md** (4 instances):
- Validation steps: `Validate Tier 3 auth details` → `Validate Zone 3 auth details`
- Steps: `Export Tier 3 sign-in record` → `Export Zone 3 sign-in record`
- Steps: `Sign in as Tier 3 agent creator` → `Sign in as Zone 3 agent creator`
- Table header: `Tier 1 | Tier 2 | Tier 3` → `Zone 1 | Zone 2 | Zone 3`

**2.1/portal-walkthrough.md** (4 instances):
- Table rows: `Tier 1 | Disabled | Disabled` → `Zone 1 | Disabled | Disabled` (and Tier 2, 3)
- Header: `Baseline (Tier 1) | Recommended (Tier 2) | Regulated (Tier 3)` → Zone equivalent

**Acceptance criteria:**
- Zero Tier governance-zone references in these 4 files
- Contextual meaning preserved in all conversions
