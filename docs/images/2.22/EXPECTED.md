# Control 2.22: Inactivity Timeout Enforcement - Screenshot Specifications

## Required Screenshots

### Screenshot 1: PPAC Privacy + Security Settings Page

**Portal Path:** Power Platform Admin Center → Environments → [Environment] → Settings → Privacy + Security
**What to capture:** Full Privacy + Security settings page showing the Session Expiration section with the inactivity timeout toggle, duration field, and warning duration field.

### Screenshot 2: Inactivity Timeout Toggle and Duration Configuration

**Portal Path:** Power Platform Admin Center → Environments → [Environment] → Settings → Privacy + Security → Session Expiration
**What to capture:** Close-up of the Session Expiration section showing: (a) "Set inactivity timeout" toggle in On position, (b) timeout duration value (e.g., 60 minutes), (c) warning duration value (e.g., 5 minutes).

### Screenshot 3: Dataverse Compliance Records

**Portal Path:** Power Apps → Tables → fsi_inactivitytimeout_compliance → Data
**What to capture:** Table view showing compliance records from a completed scan run. Include columns: environment name, compliance status (Compliant/Non-Compliant/Unknown), timeout duration, zone maximum, scan run ID, and created date.

### Screenshot 4: Non-Compliance Notification Email

**Portal Path:** Outlook / Teams notification
**What to capture:** Example notification email or Teams message generated by the compliance flow when non-compliant environments are detected. Should show: environment name, zone classification, current timeout value, required maximum, and remediation guidance link.
