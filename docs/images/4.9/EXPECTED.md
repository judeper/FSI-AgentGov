# Control 4.9: Embedded File Content Governance - Screenshot Specifications

## Required Screenshots

### Screenshot 1: Agent with embedded files
**Portal Path:** M365 admin center -> Copilot -> Agents -> [Agent]
**What to capture:**
- Embedded file indicator
- Sensitivity label visibility
- Data & tools or overview tab

### Screenshot 2: SharePoint Embedded container listing
**Portal Path:** SharePoint admin center -> Embedded containers or related view
**What to capture:**
- Declarative Agent container
- Container metadata
- Associated application context

### Screenshot 3: Sensitivity label or access enforcement
**Portal Path:** M365 admin center or Purview label view
**What to capture:**
- Applied label
- Extract-rights or access requirement
- User access outcome

### Screenshot 4: IB assessment evidence
**Portal Path:** Compliance review record or administrative screen
**What to capture:**
- Documented information-barrier assessment
- Approver or sign-off metadata
- Date/timestamp

---

## Notes for Verification
- Capture from a pre-production or demo tenant when possible
- Include timestamps to demonstrate currency
- Redact tenant-specific sensitive values before retaining screenshots
- Re-verify after major Microsoft portal changes

---

## Screenshot Naming Convention

Save screenshots with the following naming format:
```
4.9_Screenshot-[Number]_[Description]_[YYYYMMDD].png
```

Store screenshots in the `docs/images/4.9/` directory for local maintainer verification.
